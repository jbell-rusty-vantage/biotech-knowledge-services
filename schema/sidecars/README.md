# schema/sidecars (pointer only)

The workspace inputs ("sidecars": domains, terminology, task routes, identity rules, ingestion rules, aliases) are part
of the upstream schema release since biotech-schema-v2.0.0 (FU-09). There is one authority:

- **Authority (edit here):** `schema/source/<release>/workspace-inputs/*.yaml` in this repository (owner decision
  SV-D10, 2026-10-24; current release biotech-schema-v2.1.0, see `schema/source/README.md`). v2.0.x were authored in the
  now-absent `biotech-meta/docs/schema/releases/<release>/workspace-inputs/`.
  `identity-rules.yaml` and `aliases.yaml` are regenerated by `node scripts/release/bootstrap-workspace-inputs.mjs`;
  the other four are hand-authored upstream.
- **Pinned, byte-verified copy (read by the services):** `schema/pinned/release/workspace-inputs/` in this repository,
  written only by `pnpm schema:pin -- --release <dir>` and checked on every load (`loadRelease()`).

To change a sidecar: edit it in a new source release, run `node scripts/release/generate.mjs --release schema/source/<release>`
(re-release), then `pnpm schema:pin -- --release schema/source/<release>` and `pnpm workspace:build`. Never edit `schema/pinned/**` by hand.

The v1 sidecar files that lived here (keyed to fragments W00..W23) are retired; they remain in Git history at
431c8a7, and every old id they used resolves through `workspace-inputs/aliases.yaml`.
