## Conventions (final SDL)

The packet macros are written out inline, so each block runs as printed.

- Parameters: `$recAt` (recorded-time slice, default `datetime()`), plus the question's own parameters.
- `ASOF(e)` on an asserted edge: `e.recordedFrom <= $recAt AND (e.recordedTo IS NULL OR e.recordedTo > $recAt)`. In the final SDL `REVISES` carries `RevisionEdgeProperties`; `RENDITION_OF`, `STATED_IN`, `ADMINISTERS`, `MEASURES` and `OPERATIONALIZED_BY` carry `AssertedRecordedProperties`.
- `LIVE(a)` on a kernel Assertion: `a.status = 'ACCEPTED' AND a.recordedAt <= $recAt AND (a.recordedTo IS NULL OR a.recordedTo > $recAt)`.
- `TRACE`: the kernel provenance tail (directive 3.10) is kept. It is a scoped `CALL (x) { … }` subquery: Assertion → `HAS_EVIDENCE {role: 'SUPPORTS'}` → SourceLocator ← `HAS_LOCATOR` ← SourceSnapshot ← `HAS_SNAPSHOT` ← Source, plus the asserter and the open `CAPTURE_FIDELITY` Adjudication. Its inner variables are prefixed `t` so that they never shadow outer ones. It aggregates, so a row with no evidence still returns, with an empty trace.

## CQ-EV-05

- rulings: **R-42** (one (scheme, issuer, normalized value) identifies at most one Subjectable; no cross-type joins through a shared Identifier); **R-43** (RENDITION_OF has kernel meaning: Source → Publication, declared on `Publication.renditions`, direction IN, `AssertedRecordedProperties`, asserted with recorded time only); **R-44** (REVISES when the revising work is identified, `revisionKind` typed by K `SourceRevisionKind`; K `HAS_REVISION_STATUS` only on Sources, for a flag with no identified notice, one per authority; `Publication.revisionStatus` is the single work-level cache; CQ-EV-05 reads both branches).
- what changed: the packet reached the status-flag Source (statement 1, branch 2) and the captured renditions (statement 2, branch 1) through `(p:Publication)-[:HAS_IDENTIFIER]->(:Identifier)<-[:HAS_IDENTIFIER]-(src:Source)`. Under R-42 the DOI or PMID Identifier belongs to the Publication only, so that join returns nothing. Both joins now read `(p)<-[ro:RENDITION_OF]-(src:Source)` through `ASOF(ro)` (R-43). The `HAS_REVISION_STATUS` value is `SourceRevisionKind` text in `valueString`, so both branches return one vocabulary. The flag branch now returns a full `TRACE` of its Assertion instead of only `hs.uid`. Both branches also return the `Publication.revisionStatus` cache and its method version next to the per-asserter authority (R-45). Statement 2's UNION aliasing is the owner's close-out fix. It adds a `rendition` column (`src.uid`).
- how the question is answered now: in full; nothing is lost. A status-only flag (OpenAlex `is_retracted`, a PubMed flag) is found only when its Source has a `RENDITION_OF` edge to the Publication. Writers must therefore assert that edge for every scholarly record Source they flag. Fixture coverage of `RENDITION_OF` Source → Publication is still open: FX-10 (K rows) and FU-03 (D9 rows' class).

```cypher
// @id CQ-EV-05#1
// revisions of publication p per asserter: identified notices (D3 REVISES) UNION status-only flags (kernel HAS_REVISION_STATUS on a rendition Source)
MATCH (p:Publication {uid: $publication})<-[rv:REVISES]-(n:Publication)
WHERE rv.recordedFrom <= $recAt AND (rv.recordedTo IS NULL OR rv.recordedTo > $recAt)
MATCH (a:Assertion {uid: rv.assertionUid})-[:ASSERTED_BY]->(who)
CALL (a) {
  MATCH (a)-[tev:HAS_EVIDENCE]->(tloc:SourceLocator)<-[:HAS_LOCATOR]-(tsnap:SourceSnapshot)<-[:HAS_SNAPSHOT]-(tsrc:Source)
  WHERE tev.role = 'SUPPORTS'
  OPTIONAL MATCH (a)-[:ASSERTED_BY]->(twho)
  OPTIONAL MATCH (tadj:Adjudication {adjudicationKind: 'CAPTURE_FIDELITY'})-[:ASSESSES]->(a) WHERE tadj.recordedTo IS NULL
  RETURN collect({assertion: a.uid, status: a.status, asserter: twho.uid, selectorKind: tloc.selectorKind,
                  selector: tloc.selectorJson, exact: tloc.exact, start: tloc.startOffset, end: tloc.endOffset,
                  page: tloc.page, snapshot: tsnap.contentHash, retrievedAt: tsnap.retrievedAt,
                  uri: tsrc.canonicalUri, verdict: tadj.verdict}) AS trace
}
RETURN 'REVISES' AS mechanism, n.uid AS notice, n.publicationKind AS publicationKind, n.publishedAt AS publishedAt,
       null AS flaggedSource, who.uid AS asserterUid, who.name AS asserter, rv.revisionKind AS revisionKind,
       [q IN a.qualifiers WHERE q STARTS WITH 'reason:' | substring(q, 7)] AS reasons,
       p.revisionStatus AS cachedRevisionStatus, p.revisionStatusMethodVersion AS cacheMethod, trace
UNION
MATCH (p:Publication {uid: $publication})<-[ro:RENDITION_OF]-(src:Source)
      <-[:HAS_SUBJECT]-(hs:Assertion {predicate: 'HAS_REVISION_STATUS'})-[:ASSERTED_BY]->(who)
WHERE ro.recordedFrom <= $recAt AND (ro.recordedTo IS NULL OR ro.recordedTo > $recAt)
  AND hs.status = 'ACCEPTED' AND hs.recordedAt <= $recAt AND (hs.recordedTo IS NULL OR hs.recordedTo > $recAt)
CALL (hs) {
  MATCH (hs)-[tev:HAS_EVIDENCE]->(tloc:SourceLocator)<-[:HAS_LOCATOR]-(tsnap:SourceSnapshot)<-[:HAS_SNAPSHOT]-(tsrc:Source)
  WHERE tev.role = 'SUPPORTS'
  OPTIONAL MATCH (hs)-[:ASSERTED_BY]->(twho)
  OPTIONAL MATCH (tadj:Adjudication {adjudicationKind: 'CAPTURE_FIDELITY'})-[:ASSESSES]->(hs) WHERE tadj.recordedTo IS NULL
  RETURN collect({assertion: hs.uid, status: hs.status, asserter: twho.uid, selectorKind: tloc.selectorKind,
                  selector: tloc.selectorJson, exact: tloc.exact, start: tloc.startOffset, end: tloc.endOffset,
                  page: tloc.page, snapshot: tsnap.contentHash, retrievedAt: tsnap.retrievedAt,
                  uri: tsrc.canonicalUri, verdict: tadj.verdict}) AS trace
}
RETURN 'HAS_REVISION_STATUS' AS mechanism, null AS notice, null AS publicationKind, null AS publishedAt,
       src.uid AS flaggedSource, who.uid AS asserterUid, who.name AS asserter, hs.valueString AS revisionKind,
       [q IN hs.qualifiers WHERE q STARTS WITH 'reason:' | substring(q, 7)] AS reasons,
       p.revisionStatus AS cachedRevisionStatus, p.revisionStatusMethodVersion AS cacheMethod, trace;

// @id CQ-EV-05#2
// downstream: assertions, assessments and reports citing a locator on any rendition of p, plus the D3 elements p states
MATCH (p:Publication {uid: $publication})<-[ro:RENDITION_OF]-(src:Source)
      -[:HAS_SNAPSHOT]->(:SourceSnapshot)-[:HAS_LOCATOR]->(loc:SourceLocator)<-[:HAS_EVIDENCE]-(dep)
WHERE ro.recordedFrom <= $recAt AND (ro.recordedTo IS NULL OR ro.recordedTo > $recAt)
  AND (dep:Assertion OR dep:Assessment OR dep:Report)
OPTIONAL MATCH (up)-[:DERIVED_FROM]->(dep) WHERE up:Assessment OR up:Report
RETURN labels(dep)[0] AS kind, dep.uid AS uid, dep.predicate AS predicate, dep.recordedAt AS recordedAt,
       src.uid AS rendition, collect(DISTINCT up.uid) AS dependants
UNION
MATCH (e)-[st:STATED_IN]->(p:Publication {uid: $publication})
OPTIONAL MATCH (up)-[:DERIVED_FROM]->(:Assertion {uid: st.assertionUid})
RETURN labels(e)[0] AS kind, e.uid AS uid, 'STATED_IN' AS predicate, st.recordedFrom AS recordedAt,
       null AS rendition, collect(DISTINCT up.uid) AS dependants
```

## Q-D3-04

- rulings: **R-44** (enum `PublicationRevisionStatus` deleted; `Publication.revisionStatus` retyped to K `SourceRevisionKind`, null = none known); R-45 (the cache may be filtered by a question; Q-D3-04 is its deciding question). The pattern is otherwise unchanged by R-70 (`OPERATIONALIZED_BY` Target → Biomarker | Condition | Metric | Outcome) and R-53.
- what changed: `rec.revisionStatus = 'RETRACTED'` (a PublicationRevisionStatus value) becomes `rec.revisionStatus = 'RETRACTION'` (the SourceRevisionKind value). The packet excluded only retracted work and did not exclude WITHDRAWN; that behavior is kept, so `WITHDRAWAL` is **not** excluded. Excluding it would be the owner's choice: `rec.revisionStatus IN ['RETRACTION', 'WITHDRAWAL']`. `OPERATIONALIZED_BY` is asserted in the final SDL, so it is now read through `ASOF(op)` like every other asserted edge (D3 convention). `TRACE(st)` is expanded inline and runs after `LIMIT`, so the provenance subquery runs for at most 25 rows. The ranking method id `d3-evidence-rank/v1` is returned as a column.
- how the question is answered now: in full; nothing is lost. Open items that still bear on it (not ruling breaks): OD-11 (R-14 per-field predicates on RegistrationVersion payloads), FX-01 (no fixture of a condition-coded outcome reaching a Target) and MD-D10-04 (derived `ciExcludesNull`).

```cypher
// @id Q-D3-04
MATCH (t:Target {uid: $target})-[op:OPERATIONALIZED_BY]->(y)                      // (seam) D5; or bind y = $outcomeConcept
WHERE op.recordedFrom <= $recAt AND (op.recordedTo IS NULL OR op.recordedTo > $recAt)
MATCH (od:OutcomeDefinition)-[me:MEASURES]->(y)
WHERE me.recordedFrom <= $recAt AND (me.recordedTo IS NULL OR me.recordedTo > $recAt)
MATCH (s:Study)-[:HAS_OUTCOME]->(od)<-[:RESULT_FOR]-(r:StudyResult)-[st:STATED_IN]->(rec)
WHERE st.recordedFrom <= $recAt AND (st.recordedTo IS NULL OR st.recordedTo > $recAt)
  AND r.comparisonKind = 'BETWEEN_ARM' AND r.subgroupLabel IS NULL
  AND NOT (rec:Publication AND rec.revisionStatus = 'RETRACTION')                // R-44: SourceRevisionKind cache, null = none known
MATCH (r)-[:RESULT_FOR_ARM]->(:StudyArm)-[:HAS_COMPONENT]->(c:InterventionComponent {componentRole: 'ACTIVE'})-[ad:ADMINISTERS]->(m)
WHERE ad.recordedFrom <= $recAt AND (ad.recordedTo IS NULL OR ad.recordedTo > $recAt)
  AND (m.uid = $intervention OR EXISTS { (m)-[:REALIZES_SUBSTANCE]->({uid: $intervention}) })
MATCH (s)-[:HAS_POPULATION]->(pop:StudyPopulation) WHERE pop.ncbiTaxonId = '9606'
WITH DISTINCT s, r, od, pop, rec, st,
  CASE s.studyKind WHEN 'META_ANALYSIS' THEN 0 WHEN 'SYSTEMATIC_REVIEW' THEN 0 WHEN 'INTERVENTIONAL_RANDOMIZED' THEN 1
                   WHEN 'INTERVENTIONAL_NONRANDOMIZED' THEN 2 WHEN 'OBSERVATIONAL_COHORT' THEN 3 ELSE 4 END AS designRank,
  CASE r.analysisKind WHEN 'PRIMARY_PRESPECIFIED' THEN 0 WHEN 'SECONDARY_PRESPECIFIED' THEN 1 ELSE 2 END AS confirmatoryRank,
  CASE od.measureKind WHEN 'CLINICAL_EVENT' THEN 0 WHEN 'SURVIVAL' THEN 0 WHEN 'BIOMARKER' THEN 2 ELSE 1 END AS directnessRank
OPTIONAL MATCH (rob:Assessment {assessmentKind: 'QUALITY'})-[:ASSESSES]->(s) WHERE rob.recordedTo IS NULL
WITH s, r, od, pop, st, rob, designRank, confirmatoryRank, directnessRank
ORDER BY designRank, confirmatoryRank, directnessRank, r.sampleSize DESC
LIMIT 25
CALL (st) {
  MATCH (ta:Assertion {uid: st.assertionUid})-[tev:HAS_EVIDENCE]->(tloc:SourceLocator)<-[:HAS_LOCATOR]-(tsnap:SourceSnapshot)<-[:HAS_SNAPSHOT]-(tsrc:Source)
  WHERE tev.role = 'SUPPORTS'
  OPTIONAL MATCH (ta)-[:ASSERTED_BY]->(twho)
  OPTIONAL MATCH (tadj:Adjudication {adjudicationKind: 'CAPTURE_FIDELITY'})-[:ASSESSES]->(ta) WHERE tadj.recordedTo IS NULL
  RETURN collect({assertion: ta.uid, status: ta.status, asserter: twho.uid, selectorKind: tloc.selectorKind,
                  selector: tloc.selectorJson, exact: tloc.exact, start: tloc.startOffset, end: tloc.endOffset,
                  page: tloc.page, snapshot: tsnap.contentHash, retrievedAt: tsnap.retrievedAt,
                  uri: tsrc.canonicalUri, verdict: tadj.verdict}) AS trace
}
RETURN s.uid AS study, s.studyKind AS studyKind, r.sampleSize AS sampleSize, od.name AS outcome, od.measureKind AS measureKind,
       r.resultKind AS resultKind, r.estimate AS estimate, r.intervalLower AS intervalLower, r.intervalUpper AS intervalUpper,
       r.statisticalConclusion AS statisticalConclusion, r.direction AS direction, pop.sexScope AS sexScope,
       pop.minAgeYears AS minAgeYears, pop.maxAgeYears AS maxAgeYears, rob.verdict AS riskOfBias,
       'd3-evidence-rank/v1' AS rankMethod, trace
ORDER BY designRank, confirmatoryRank, directnessRank, sampleSize DESC
```
