## Conventions (final SDL)

- **R-30 verbatim wording.** D6 `ComponentLineProperties` keeps `relationshipUid`, `assertionUid`, `recordedFrom`, `recordedTo`, `orderIndex`, `parentOrderIndex`, `lineRole`, `amount`, `unitCode`, `amountReferent`, `massBasis`, `amountBasis` and `dailyValuePercent`. The removed `declaredNameVerbatim`, `formVerbatim` and `statementVerbatim` live on the line's own Assertion `(la:Assertion {uid: c.assertionUid})` (subject the LabelVersion, object the line target, asserter the transcribing source): as the qualifiers `declaredName:<text>`, `form:<text>` and `statement:<text>` (`Assertion.qualifiers: [String!]`), and as the located panel-row text `SourceLocator.exact` reached by `HAS_EVIDENCE`. The patterns read a qualifier with `head([q IN coalesce(la.qualifiers, []) WHERE q STARTS WITH 'declaredName:' | trim(substring(q, size('declaredName:')))])` and return the located spans next to it, so a line written before the fixture edit (FU-03: the D6 fixtures still carry the edge fields) is still answered from its locator.
- **As-of / as-recorded.** Unchanged from the packet header: `AS_OF(r, $V)` is `(r.validFrom IS NULL OR r.validFrom <= $V) AND (r.validTo IS NULL OR r.validTo > $V)` on the `HAS_LABEL_VERSION` episode (`AssertedEdgeProperties`); current lines are `c.recordedTo IS NULL` (lines carry recorded time only; their valid time is the label episode).
- **TRACE.** The kernel provenance chain is kept: `(a:Assertion)-[:HAS_EVIDENCE]->(:SourceLocator)<-[:HAS_LOCATOR]-(:SourceSnapshot)<-[:HAS_SNAPSHOT]-(:Source)`, plus `(a)-[:ASSERTED_BY]->(who)`, `(a)-[:WAS_GENERATED_BY]->(:Activity)` and `(adj:Adjudication)-[:ASSESSES]->(a)`. Every pattern returns the uids it needs (`lineAssertion`, the `HAS_LABEL_VERSION` episode Assertion); CQ-PF-01 statement 2 is the TRACE statement for any of them.

## Q-D6-01

- rulings: **R-30** (verbatim fields leave ComponentLineProperties; the line name is the line Assertion's `declaredName:` qualifier or its locator's exact text).
- status: rewritten. The packet bug in the same block (`r.validObservedAt` on HAS_LABEL_VERSION) is the owner's fix and is kept as written (`ea.validObservedAt` from the episode's Assertion).
- packet pattern: A6 `packets/D6/03-retrieval-patterns.md` section line 56 (lint: block L61, relProperty L76, pendingEdit R-30).
- pattern: label history of one package, newest first, each version with its lines and a field diff to the predecessor computed in the query.

```cypher
// @id Q-D6-01#1
MATCH (pk:Package {uid: $package})-[r:HAS_LABEL_VERSION]->(lv:LabelVersion)
WHERE r.recordedTo IS NULL                                          // current belief; add AS_OF(r,$V) for "at V"
OPTIONAL MATCH (ea:Assertion {uid: r.assertionUid})                 // validObservedAt is an Assertion field (owner fix)
WITH pk, lv, min(coalesce(r.validFrom, ea.validObservedAt, lv.firstObservedAt)) AS since,
     collect({assertion: r.assertionUid, from: r.validFrom, to: r.validTo, basis: r.validFromBasis}) AS episodes
WITH pk, lv, since, episodes ORDER BY since DESC
WITH pk, collect({lv: lv, since: since, episodes: episodes}) AS hist
UNWIND range(0, size(hist) - 1) AS i
WITH hist[i] AS cur, CASE WHEN i + 1 < size(hist) THEN hist[i + 1] ELSE null END AS prev
CALL (cur) {
  WITH cur.lv AS lv
  MATCH (lv)-[c:DECLARES_COMPONENT]->(t) WHERE c.recordedTo IS NULL
  OPTIONAL MATCH (la:Assertion {uid: c.assertionUid})               // R-30: the line's own Assertion carries the printed wording
  WITH c, t, la
  ORDER BY c.orderIndex
  RETURN collect({order: c.orderIndex, parent: c.parentOrderIndex, role: c.lineRole,
                  name: head([q IN coalesce(la.qualifiers, []) WHERE q STARTS WITH 'declaredName:' | trim(substring(q, size('declaredName:')))]),
                  nameSpans: COLLECT { MATCH (la)-[:HAS_EVIDENCE]->(loc:SourceLocator) RETURN loc.exact },
                  amount: c.amount, unit: c.unitCode, referent: c.amountReferent, massBasis: c.massBasis, target: t.uid,
                  lineAssertion: c.assertionUid}) AS lines
}
RETURN cur.lv.uid, cur.lv.labelVersionCode, cur.since, cur.episodes, cur.lv.servingSizeVerbatim,
       cur.lv.minDailyServings, cur.lv.maxDailyServings, cur.lv.directionsText, cur.lv.seals, cur.lv.containsAllergens,
       lines,
       prev.lv.compositionDigest = cur.lv.compositionDigest AS sameComposition,
       prev.lv.maxDailyServings <> cur.lv.maxDailyServings AS directionsChanged,
       [s IN cur.lv.seals WHERE NOT s IN coalesce(prev.lv.seals, [])] AS sealsAdded,
       [s IN coalesce(prev.lv.seals, []) WHERE NOT s IN cur.lv.seals] AS sealsRemoved;
```

- trace: TRACE on each `HAS_LABEL_VERSION` episode Assertion (`cur.episodes[*].assertion`) and on each line Assertion (`lines[*].lineAssertion`; `nameSpans` is its located panel-row text): DSLD JSON locators (`productVersionCode`, `statements[...]`), retailer table locators.
- bitemporal episode needed on: `HAS_LABEL_VERSION`.
- EXPLAIN: ok on Neo4j 5.26.31 community (1/1 statement); final-SDL static check clean (labels, types, pairs, properties, enum values, predicates)
