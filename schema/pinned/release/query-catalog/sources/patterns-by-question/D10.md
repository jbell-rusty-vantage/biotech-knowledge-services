**Conventions.** Names, labels and directions are those of the final SDL:

- Assertion subject and object: `(a:Assertion)-[:HAS_SUBJECT|HAS_OBJECT]->(x)`; asserter `(a)-[:ASSERTED_BY]->(who)`; container `(a)-[:OCCURS_IN]->(w:MediaWork)` (R-19).
- Assessment and Report "about": `(s:Assessment|r:Report|i:ReportItem)-[:ASSESSES]->(x)`; inputs `(s|r|i)-[:DERIVED_FROM]->(Assertion|Assessment)`.
- Report rows: `(r:Report)-[:HAS_ITEM]->(i:ReportItem)-[:BLOCKED_BY]->(UseConstraint|Assessment)`; a UseConstraint resolves to its Assertions through `(ua:Assertion)-[:RESOLVES_TO_CONSTRAINT]->(uc)`.
- Entry by uid is `(x:Entity {uid: $x})` (seek through `entity_uid`; `final/query-patterns.md` conventions). KIND(x) is the first label that is not `Entity | Occurrence | InformationArtifact | EvidenceAssessment`.
- AS-OF (recorded time) and VALID-AT (valid time on the Assertion) are the packet's ASOF and VALIDAT fragments, unchanged.
- Kernel trace kept on every row: TRACE(a) is P-01b, `(a)-[:HAS_EVIDENCE]->(SourceLocator)<-[:HAS_LOCATOR]-(SourceSnapshot)<-[:HAS_SNAPSHOT]-(Source)`, plus the current `Adjudication` that `ASSESSES` the Assertion (ADJ). STRACE(s) is an Assessment's own located spans plus the spans of the Assertions it is `DERIVED_FROM`, and its producing Activity.

Shared fragments (expanded by the validator; the trace variables carry a `t` prefix so they never capture an outer variable):

```cypher-macros
ASOF(x) = x.recordedAt <= $asOf AND (x.recordedTo IS NULL OR x.recordedTo > $asOf)
VALIDAT(a) = ($validAt IS NULL OR ((a.validFrom IS NULL OR a.validFrom <= $validAt) AND (a.validTo IS NULL OR a.validTo > $validAt)))
KIND(x) = [lbl IN labels(x) WHERE NOT lbl IN ['Entity', 'Occurrence', 'InformationArtifact', 'EvidenceAssessment']][0]
TRACE(a) = COLLECT { MATCH (a)-[tev:HAS_EVIDENCE]->(tloc:SourceLocator)<-[:HAS_LOCATOR]-(tsnap:SourceSnapshot)<-[:HAS_SNAPSHOT]-(tsrc:Source)
    RETURN {via: a.uid, role: tev.role, origin: tev.origin, selectorKind: tloc.selectorKind, exact: tloc.exact, page: tloc.page,
            startOffset: tloc.startOffset, contentHash: tsnap.contentHash, retrievedAt: tsnap.retrievedAt, uri: tsrc.canonicalUri} }
ADJ(a) = COLLECT { MATCH (tadj:Adjudication)-[:ASSESSES]->(a) WHERE ASOF(tadj)
    RETURN tadj {.uid, .verdict, .adjudicationKind, .methodVersion} }
STRACE(s) = COLLECT { MATCH (s)-[tev:HAS_EVIDENCE]->(tloc:SourceLocator)<-[:HAS_LOCATOR]-(tsnap:SourceSnapshot)<-[:HAS_SNAPSHOT]-(tsrc:Source)
      RETURN {via: s.uid, role: tev.role, exact: tloc.exact, contentHash: tsnap.contentHash, uri: tsrc.canonicalUri} AS e
    UNION
    MATCH (s)-[:DERIVED_FROM]->(tin:Assertion)-[tev:HAS_EVIDENCE]->(tloc:SourceLocator)<-[:HAS_LOCATOR]-(tsnap:SourceSnapshot)<-[:HAS_SNAPSHOT]-(tsrc:Source)
      RETURN {via: tin.uid, role: tev.role, exact: tloc.exact, contentHash: tsnap.contentHash, uri: tsrc.canonicalUri} AS e }
```

## Q-D10-03

*What is the evidence against using X for target T — null, inconsistent, or harmful verdicts with certainty and scope.* Answer kind: retrieved.

- **Ruling: R-83 (recommendations).** The packet's third-party branch read `RECOMMENDS_AGAINST` together with an optional Target. R-83: only D5's goal predicates take a Target object; a recommendation's subject is the means and its goal is the qualifier `target:<key>`; D10's guideline branch becomes `WORSENS_TARGET | NO_EFFECT_ON_TARGET` (or `USE_CONSTRAINED_IN` for population guidance) with speechAct `CAUTIONS | RECOMMENDS`. The rewrite therefore has four statement branches:
  1. the goal predicates `WORSENS_TARGET | NO_EFFECT_ON_TARGET` with subject X and, when `$targetKey` is given, object that Target; `kind` says GUIDELINE when the speech act is `CAUTIONS | RECOMMENDS`, else ASSERTED_EFFECT;
  2. `USE_CONSTRAINED_IN` with subject X and a guideline speech act (population guidance; object a D2 Condition, scope in `population:` qualifiers);
  3. D9 `RECOMMENDS_AGAINST` with subject X and speechAct `RECOMMENDS`, filtered on `target:<key>` when `$targetKey` is given (never a Target object);
  4. `CHARACTERIZES_EVIDENCE_STRENGTH`, whose registered subject is the `Claim` (predicate registry, registrar D10), so it is reached through the claim occurrences about X instead of `HAS_SUBJECT → X` (registry alignment, not a ruling change).
- Scope stays in the Assertion `qualifiers` and in the assessment's ASSESSES targets; certainty comes from the Assessment's `certainty` / `gradeScheme` / `grade` (final kernel fields) besides `verdict`. Per R-34 the support or contradiction of an assessment's inputs is in its `facets` (`input:<uid>=SUPPORTS|CONTRADICTS|QUALIFIES`), returned as is.
- Evidence reports keep the packet branch (EVIDENCE_REPORT → Claim ← occurrence → X) and now carry AS-OF on the Report.
- The three packet OPTIONAL MATCHes multiplied each other's rows; they become independent `COLLECT` subqueries (same answer, no cross product).

```cypher
// @id Q-D10-03
// @param targetKey:string
MATCH (x:Entity {uid: $x})
RETURN x.uid AS subjectUid, x.name AS subject, KIND(x) AS subjectKind,
  // BellLabs assessments with a negative or null direction / verdict about X (and about T when given)
  COLLECT { MATCH (s:Assessment)-[:ASSESSES]->(x)
            WHERE s.status = 'ACCEPTED' AND ASOF(s)
              AND (s.effectDirection IN ['NO_EFFECT', 'HARM', 'MIXED']
                   OR s.verdict IN ['CONTRADICTED', 'NOT_SUPPORTED', 'MIXED_OR_CONFLICTING', 'INSUFFICIENT_EVIDENCE'])
              AND ($targetKey IS NULL OR EXISTS { MATCH (s)-[:ASSESSES]->(:Target {key: $targetKey}) })
            RETURN s {.uid, .assessmentKind, .assessmentSubkind, .verdict, .effectDirection, .certainty, .gradeScheme, .grade,
                      .facets, .summary, .methodVersion,
                      producer: head(COLLECT { MATCH (s)-[:WAS_GENERATED_BY]->(tact:Activity) RETURN tact.uid }),
                      trace: STRACE(s)} } AS assessments,
  // evidence reports that failed to confirm a claim about X
  COLLECT { MATCH (r:Report {reportKind: 'EVIDENCE_REPORT'})-[:ASSESSES]->(c:Claim)<-[:OCCURRENCE_OF]-(occ:Assertion)-[:HAS_SUBJECT]->(x)
            WHERE r.verdict IN ['CONTRADICTED', 'NOT_SUPPORTED', 'MIXED_OR_CONFLICTING', 'INSUFFICIENT_EVIDENCE'] AND ASOF(r)
            RETURN DISTINCT r {.uid, .verdict, .worldCorrectness, .publishedAt, claim: c.uid, proposition: c.proposition} } AS reports,
  // third-party null / negative statements (R-83: goal predicates with a Target object; recommendations with a target qualifier)
  COLLECT { MATCH (n:Assertion)-[:HAS_SUBJECT]->(x)
            WHERE n.predicate IN ['WORSENS_TARGET', 'NO_EFFECT_ON_TARGET'] AND ASOF(n)
              AND ($targetKey IS NULL OR EXISTS { MATCH (n)-[:HAS_OBJECT]->(:Target {key: $targetKey}) })
            RETURN n {.uid, .predicate, .speechAct, .status, .qualifiers, .valueString,
                      kind: CASE WHEN n.speechAct IN ['CAUTIONS', 'RECOMMENDS'] THEN 'GUIDELINE' ELSE 'ASSERTED_EFFECT' END,
                      trace: TRACE(n), adjudications: ADJ(n)} AS st
          UNION
            MATCH (n:Assertion {predicate: 'USE_CONSTRAINED_IN'})-[:HAS_SUBJECT]->(x)
            WHERE n.speechAct IN ['CAUTIONS', 'RECOMMENDS'] AND ASOF(n)
            RETURN n {.uid, .predicate, .speechAct, .status, .qualifiers, .valueString, kind: 'GUIDELINE_POPULATION',
                      condition: head(COLLECT { MATCH (n)-[:HAS_OBJECT]->(tc:Condition) RETURN tc.uid }),
                      trace: TRACE(n), adjudications: ADJ(n)} AS st
          UNION
            MATCH (n:Assertion {predicate: 'RECOMMENDS_AGAINST', speechAct: 'RECOMMENDS'})-[:HAS_SUBJECT]->(x)
            WHERE ASOF(n) AND ($targetKey IS NULL OR ('target:' + $targetKey) IN coalesce(n.qualifiers, []))
            RETURN n {.uid, .predicate, .speechAct, .status, .qualifiers, .valueString, kind: 'RECOMMENDED_AGAINST',
                      trace: TRACE(n), adjudications: ADJ(n)} AS st
          UNION
            MATCH (x)<-[:HAS_SUBJECT]-(:Assertion {assertionKind: 'CLAIM'})-[:OCCURRENCE_OF]->(c:Claim)
                  <-[:HAS_SUBJECT]-(n:Assertion {predicate: 'CHARACTERIZES_EVIDENCE_STRENGTH'})
            WHERE ASOF(n)
            RETURN n {.uid, .predicate, .speechAct, .status, .qualifiers, .valueString, kind: 'EVIDENCE_STRENGTH', claim: c.uid,
                      trace: TRACE(n), adjudications: ADJ(n)} AS st } AS statements
```

- trace: every assessment carries STRACE (own spans plus input spans, producer Activity); every statement carries TRACE and its current adjudications; a report is traced through its `DERIVED_FROM` citations (P-01b) and its `bodyDigest` / `ledgerDigest`.
- bitemporal episode needed on: none (AS-OF on Assertion, Assessment and Report records).

## Q-D10-08

*What should a person pursuing target T avoid, by severity and certainty, including "recommend against" statements.* Answer kind: retrieved (published variant = HARMS_AND_AVOIDANCE rows of a profile or comparison).

- **Ruling: R-83 (recommendations).** The packet's guideline branch matched `(a:Assertion {predicate: 'RECOMMENDS_AGAINST'})-[:HAS_OBJECT]->(t)`; R-83 rejects a Target object on a recommendation. The guideline reason is now:
  - `WORSENS_TARGET | NO_EFFECT_ON_TARGET` → T with speechAct `CAUTIONS | RECOMMENDS` (basis `guideline`); the asserted-effect branch keeps `WORSENS_TARGET` with any other speech act, so a statement is counted once;
  - `USE_CONSTRAINED_IN` population guidance (speechAct `CAUTIONS | RECOMMENDS`, object a Condition) on the means asserted to serve T (`IMPROVES_TARGET | INTENDED_FOR_TARGET` → T) (basis `guidelinePopulation`);
  - the "recommend against" statements the question names: D9 `RECOMMENDS_AGAINST`, speechAct `RECOMMENDS`, subject the means, goal in the qualifier `target:<T key>` (basis `recommendedAgainst`).
- `$population` (optional) narrows the guideline branches to the asker's population (`population:<code>` or `population:UNSPECIFIED` qualifiers), the packet's "for a population matching the asker".
- Certainty of an assessment reason is the final `Assessment.certainty`, falling back to the verdict as in the packet. Published BLOCKED rows keep the packet branch; the blocking record (`UseConstraint | Assessment`, both final BLOCKED_BY targets) is traced through `RESOLVES_TO_CONSTRAINT` or `DERIVED_FROM` to its Assertions' locators.
- Packet rule "rows with no locator are not returned" is applied (`size(trace) > 0`).

```cypher
// @id Q-D10-08
// @param population:string
MATCH (t:Target {key: $targetKey})
CALL (t) {
  // means asserted to worsen T (D5 goal predicate), non-guideline speech acts
  MATCH (t)<-[:HAS_OBJECT]-(a:Assertion {predicate: 'WORSENS_TARGET'})-[:HAS_SUBJECT]->(m)
  WHERE ASOF(a) AND VALIDAT(a) AND NOT coalesce(a.speechAct, 'STATES') IN ['CAUTIONS', 'RECOMMENDS']
  RETURN m, 'assertion' AS basis, a.uid AS uid, a.predicate AS detail, a.qualifiers AS scope, null AS certainty, TRACE(a) AS trace
  UNION
  // BellLabs harm assessments about a means and the target
  MATCH (t)<-[:ASSESSES]-(s:Assessment {effectDirection: 'HARM'})-[:ASSESSES]->(m)
  WHERE m <> t AND s.status = 'ACCEPTED' AND ASOF(s)
  RETURN m, 'assessment' AS basis, s.uid AS uid, s.assessmentKind AS detail, s.facets AS scope,
         coalesce(s.certainty, s.verdict) AS certainty, STRACE(s) AS trace
  UNION
  // R-83 guideline branch: goal predicates with a guideline speech act (no RECOMMENDS_AGAINST -> Target)
  MATCH (t)<-[:HAS_OBJECT]-(a:Assertion)-[:HAS_SUBJECT]->(m)
  WHERE a.predicate IN ['WORSENS_TARGET', 'NO_EFFECT_ON_TARGET'] AND a.speechAct IN ['CAUTIONS', 'RECOMMENDS']
    AND ASOF(a) AND VALIDAT(a)
    AND ($population IS NULL OR any(q IN coalesce(a.qualifiers, []) WHERE q IN ['population:' + $population, 'population:UNSPECIFIED']))
  RETURN m, 'guideline' AS basis, a.uid AS uid, a.predicate + '/' + a.speechAct AS detail, a.qualifiers AS scope, null AS certainty,
         TRACE(a) AS trace
  UNION
  // R-83 population guidance: USE_CONSTRAINED_IN on the means asserted to serve T
  MATCH (t)<-[:HAS_OBJECT]-(g:Assertion)-[:HAS_SUBJECT]->(m)
  WHERE g.predicate IN ['IMPROVES_TARGET', 'INTENDED_FOR_TARGET'] AND ASOF(g)
  WITH DISTINCT m
  MATCH (m)<-[:HAS_SUBJECT]-(a:Assertion {predicate: 'USE_CONSTRAINED_IN'})-[:HAS_OBJECT]->(cond:Condition)
  WHERE a.speechAct IN ['CAUTIONS', 'RECOMMENDS'] AND ASOF(a) AND VALIDAT(a)
    AND ($population IS NULL OR any(q IN coalesce(a.qualifiers, []) WHERE q IN ['population:' + $population, 'population:UNSPECIFIED']))
  RETURN m, 'guidelinePopulation' AS basis, a.uid AS uid, cond.name AS detail, a.qualifiers AS scope, null AS certainty,
         TRACE(a) AS trace
  UNION
  // D9 recommendations against a means for this goal (R-83: subject = means, goal = qualifier target:<key>)
  MATCH (a:Assertion {predicate: 'RECOMMENDS_AGAINST', speechAct: 'RECOMMENDS'})-[:HAS_SUBJECT]->(m)
  WHERE ('target:' + t.key) IN coalesce(a.qualifiers, []) AND ASOF(a) AND VALIDAT(a)
  RETURN m, 'recommendedAgainst' AS basis, a.uid AS uid, a.predicate AS detail, a.qualifiers AS scope, null AS certainty,
         TRACE(a) AS trace
  UNION
  // published BLOCKED rows whose report is about T
  MATCH (t)<-[:ASSESSES]-(r:Report)-[:HAS_ITEM]->(i:ReportItem {disposition: 'BLOCKED'})-[:ASSESSES]->(m)
  WHERE ASOF(r)
  MATCH (i)-[:BLOCKED_BY]->(b)
  RETURN m, 'publishedBlock' AS basis, b.uid AS uid, KIND(b) AS detail, null AS scope, null AS certainty,
         COLLECT { MATCH (b:UseConstraint)<-[:RESOLVES_TO_CONSTRAINT]-(tua:Assertion)-[tev:HAS_EVIDENCE]->(tloc:SourceLocator)
                         <-[:HAS_LOCATOR]-(tsnap:SourceSnapshot)<-[:HAS_SNAPSHOT]-(tsrc:Source)
                   RETURN {via: tua.uid, role: tev.role, exact: tloc.exact, contentHash: tsnap.contentHash, uri: tsrc.canonicalUri} AS e
                   UNION
                   MATCH (b:Assessment)-[:DERIVED_FROM]->(tua:Assertion)-[tev:HAS_EVIDENCE]->(tloc:SourceLocator)
                         <-[:HAS_LOCATOR]-(tsnap:SourceSnapshot)<-[:HAS_SNAPSHOT]-(tsrc:Source)
                   RETURN {via: tua.uid, role: tev.role, exact: tloc.exact, contentHash: tsnap.contentHash, uri: tsrc.canonicalUri} AS e } AS trace
}
WITH m, basis, uid, detail, scope, certainty, trace WHERE size(trace) > 0
WITH m, collect({basis: basis, uid: uid, detail: detail, scope: scope, certainty: certainty, trace: trace}) AS reasons
RETURN KIND(m) AS meansKind, m.uid AS meansUid, m.name AS means, reasons, size(reasons) AS nReasons
ORDER BY nReasons DESC
LIMIT 100
```

- EXPLAIN: ok on Neo4j 5.26.31 community (1/1 statement); final-SDL static check clean (labels, types, pairs, properties, enum values, predicates)
- Ordering: severity from the D5 constraint Assertions' `severity` qualifier, certainty from the assessment (`certainty`, else `verdict`), as in the packet; the caller sorts the `reasons` list.
- trace: each reason carries its locator chain (TRACE / STRACE / constraint inputs); adjudications per Assertion uid through P-01b.
- bitemporal episode needed on: none.
- `final/query-patterns.md` P-07 is the wider cross-domain form of this question (adds CAUSES_ADVERSE_EFFECT, UseConstraint scope and parent targets).

## Q-D10-21

*Which named people recommend X, where, and does any recommender have a financial interest in X valid at the time.* Answer kind: retrieved (no RECOMMENDS projection is stored, directive 3.9).

- **Ruling: R-94 (seam hygiene).** The packet trace named "D9 Episode/Publication" (no `Episode` type exists in the final schema). R-94: the container comes from `OCCURS_IN`. The rewrite reads `(a)-[:OCCURS_IN]->(w:MediaWork)` (final pair Assertion → MediaWork) and returns it as the "where"; the Source's `RENDITION_OF` work (`MediaWork | Publication`, final pairs) is returned only as the source family, as `Report.independentSourceFamilyCount` defines it.
- **R-19 (statement time).** The overlap test used `a.validFrom`; R-19 sets the statement time T to the container's `publishedAt`, falling back to the snapshot when there is no container. The overlap is classified (OVERLAPS / DISJOINT / UNKNOWN) instead of filtering, so a null T or a null bound is reported, not silently dropped; it also returns the interest Assertion's `validObservedAt` (R-19 overlap rule).
- **R-83.** A recommendation is a CLAIM occurrence with speechAct `RECOMMENDS` and predicate `RECOMMENDS_USE` whose **subject** is the recommended means, so the packet's `HAS_SUBJECT|HAS_OBJECT` becomes `HAS_SUBJECT` and the predicate is pinned.
- **R-78 / R-89 (interest families).** The packet's free parameter `$d7InterestPredicates` becomes the registered D7 families `HOLDS_ROLE | HOLDS_STAKE | RECEIVES_VALUE_FROM` (authorizing Assertions carry the type name as predicate, R-53). The recommender is a `Person` (the question asks for named people). `$makersOfX` stays a caller-supplied list as in the packet (P-09 in `final/query-patterns.md` computes the organizations behind X in-query).

```cypher
// @id Q-D10-21
// @param makersOfX:strings
MATCH (x:Entity {uid: $x})<-[:HAS_SUBJECT]-(a:Assertion {assertionKind: 'CLAIM', speechAct: 'RECOMMENDS', predicate: 'RECOMMENDS_USE'})
      -[:ASSERTED_BY]->(p:Person)
WHERE ASOF(a)
MATCH (a)-[ev:HAS_EVIDENCE]->(loc:SourceLocator)<-[:HAS_LOCATOR]-(snap:SourceSnapshot)<-[:HAS_SNAPSHOT]-(src:Source)
OPTIONAL MATCH (a)-[:OCCURS_IN]->(w:MediaWork)                       // R-94 / R-19: the container
WITH x, a, p, ev, loc, snap, src, w, coalesce(w.publishedAt, snap.publishedAt, snap.observedAt) AS saidAt
RETURN p.uid AS recommenderUid, p.name AS recommender, a.uid AS occurrenceUid, a.qualifiers AS scope,
       w {.uid, .name, .workKind, .publishedAt, .canonicalUrl} AS container, saidAt,
       COLLECT { MATCH (src)-[:RENDITION_OF]->(fam:MediaWork|Publication) RETURN fam.uid } AS sourceFamily,
       {role: ev.role, selectorKind: loc.selectorKind, exact: loc.exact, mediaStartSeconds: loc.mediaStartSeconds,
        contentHash: snap.contentHash, retrievedAt: snap.retrievedAt, uri: src.canonicalUri} AS trace,
       ADJ(a) AS adjudications,
       COLLECT { MATCH (fi:Assertion)-[:HAS_SUBJECT]->(p)
                 WHERE fi.predicate IN ['HOLDS_ROLE', 'HOLDS_STAKE', 'RECEIVES_VALUE_FROM'] AND ASOF(fi)
                   AND EXISTS { MATCH (fi)-[:HAS_OBJECT]->(org:Organization) WHERE org.uid IN $makersOfX }
                 RETURN fi {.uid, .predicate, .validFrom, .validTo, .validObservedAt,
                            overlap: CASE
                              WHEN saidAt IS NULL THEN 'UNKNOWN'
                              WHEN (fi.validTo IS NOT NULL AND fi.validTo <= saidAt) OR (fi.validFrom IS NOT NULL AND fi.validFrom > saidAt) THEN 'DISJOINT'
                              WHEN fi.validFrom IS NOT NULL AND fi.validFrom <= saidAt
                                   AND (fi.validTo > saidAt OR (fi.validTo IS NULL AND fi.validObservedAt >= saidAt)) THEN 'OVERLAPS'
                              ELSE 'UNKNOWN' END,
                            trace: TRACE(fi)} } AS interests
ORDER BY saidAt DESC
```

- EXPLAIN: ok on Neo4j 5.26.31 community (1/1 statement); final-SDL static check clean (labels, types, pairs, properties, enum values, predicates)
- trace: TRACE(a) is the row's own locator → snapshot → Source; the D9 container is `OCCURS_IN` (R-94), the source family the Source's `RENDITION_OF` work; each interest carries its own TRACE.
- bitemporal episode needed on: none on D10 edges (the D7 interest edges carry episodes in D7; this pattern reads their authorizing Assertions).
