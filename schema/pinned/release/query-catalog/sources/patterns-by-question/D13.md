## Q-D13-04

- question: which events on F are breakthroughs by a stated definition rather than press language.
- rulings: **R-66**. The `designationType` literals `BREAKTHROUGH_THERAPY | RMAT | PRIME | SAKIGAKE` become the D8 RegulatoryPathway values `US_BREAKTHROUGH_THERAPY | US_RMAT | EU_PRIME | JP_SAKIGAKE` (`breakthroughCriteria` BC-DESIGNATION in final/vocabularies/frontiers.yaml). The `approvalPathway <> 'CLEARANCE_510K'` exclusion becomes `US_DEVICE_510K` (BC-FIRST-APPROVAL). The pattern-lint did not flag that `<>` literal. BC-FIRST-APPROVAL in frontiers.yaml keeps 510(k) clearances on a diagnostic frontier, so the exclusion takes `$diagnosticFrontier` (the caller sets it; Frontier has no diagnostic flag). R-66 makes the D8 RegulatoryRecord the owner of the act, and the Event fields are caches (R-45), so BC-DESIGNATION also accepts a designation whose DOCUMENTED_BY_RECORD record carries the pathway while the Event cache is still unset.
- answer kind: unchanged (retrieved BC-DESIGNATION..BC-FIRST-POSITIVE-PIVOTAL plus kernel Assessment BC-ANALYST).

```cypher
CALL () {
  // (a) BC-DESIGNATION: the regulator's own designation, D8 RegulatoryPathway values (R-66)
  MATCH (e:Event {eventKind: 'REGULATORY_DESIGNATION'})-[of:ON_FRONTIER]->(:Frontier {key: $frontierKey})
  WHERE of.recordedTo IS NULL
  OPTIONAL MATCH (e)-[dr:DOCUMENTED_BY_RECORD]->(rec:RegulatoryRecord)
    WHERE dr.recordedTo IS NULL
  WITH e, collect(DISTINCT rec) AS recs
  WHERE e.designationType IN ['US_BREAKTHROUGH_THERAPY', 'US_RMAT', 'EU_PRIME', 'JP_SAKIGAKE']
     OR any(r IN recs WHERE r.pathway IN ['US_BREAKTHROUGH_THERAPY', 'US_RMAT', 'EU_PRIME', 'JP_SAKIGAKE'])
  RETURN 'BC-DESIGNATION' AS criterion, e, [r IN recs | r.uid] AS recordUids, null AS assessmentUid
  UNION
  // (b) BC-FIRST-*: firstness restricted to the criterion kinds; first approval is per jurisdiction,
  //     510(k) clearances excluded unless the frontier is diagnostic (R-66: US_DEVICE_510K; BC-FIRST-APPROVAL)
  // @param diagnosticFrontier:bool
  MATCH (f:Frontier {key: $frontierKey})<-[of:ON_FRONTIER]-(e:Event)
  WHERE of.recordedTo IS NULL AND e.eventStatus = 'OCCURRED'
    AND (e.eventKind = 'TRIAL_START'
         OR (e.eventKind = 'APPROVAL' AND (e.approvalPathway IS NULL OR e.approvalPathway <> 'US_DEVICE_510K' OR $diagnosticFrontier))
         OR (e.eventKind = 'READOUT' AND e.readoutStage IN ['TOPLINE', 'PRIMARY'] AND e.primaryEndpointStatement = 'MET'))
  WITH e ORDER BY coalesce(e.startedAt, e.announcedAt)
  WITH CASE e.eventKind WHEN 'TRIAL_START' THEN 'BC-FIRST-IN-HUMAN' WHEN 'APPROVAL' THEN 'BC-FIRST-APPROVAL'
            ELSE 'BC-FIRST-POSITIVE-PIVOTAL' END AS criterion,
       CASE e.eventKind WHEN 'APPROVAL' THEN e.jurisdiction ELSE null END AS scope,
       collect(e)[0] AS e
  RETURN criterion, e, [] AS recordUids, null AS assessmentUid
  UNION
  // (c) BC-ANALYST: a kernel Assessment, never an Event property
  MATCH (as:Assessment)-[:ASSESSES]->(e:Event)-[of:ON_FRONTIER]->(:Frontier {key: $frontierKey})
  WHERE of.recordedTo IS NULL
    AND as.assessmentKind = 'BREAKTHROUGH_JUDGMENT' AND as.conclusionCode = 'MEETS_CRITERION'
    AND as.status = 'ACCEPTED' AND as.recordedTo IS NULL
  RETURN 'BC-ANALYST' AS criterion, e, [] AS recordUids, as.uid AS assessmentUid
}
// T(e): clock assertions plus the FIELD assertion behind the cached designationType / approvalPathway
CALL (e) {
  OPTIONAL MATCH (a:Assertion)-[:HAS_SUBJECT]->(e)
  WHERE a.uid IN [e.timeAssertionUid, e.announcementAssertionUid, e.effectiveAssertionUid, e.scheduleAssertionUid]
     OR (a.predicate IN ['DESIGNATION_TYPE', 'APPROVAL_PATHWAY'] AND a.recordedTo IS NULL)
  OPTIONAL MATCH (a)-[:HAS_EVIDENCE {role: 'SUPPORTS'}]->(l:SourceLocator)<-[:HAS_LOCATOR]-(s:SourceSnapshot)<-[:HAS_SNAPSHOT]-(src:Source)
  OPTIONAL MATCH (a)-[:ASSERTED_BY]->(who)
  RETURN collect(DISTINCT {assertion: a.uid, predicate: a.predicate, value: a.valueString, assertedBy: who.uid,
                           exact: l.exact, selectorJson: l.selectorJson, contentHash: s.contentHash,
                           publishedAt: s.publishedAt, source: src.canonicalUri}) AS trace
}
// BC-ANALYST: the Assessment's own located evidence and method version
OPTIONAL MATCH (asm:Assessment {uid: assessmentUid})-[:HAS_EVIDENCE]->(al:SourceLocator)
WITH criterion, e, recordUids, assessmentUid, trace,
     collect(DISTINCT {locator: al.uid, exact: al.exact, selectorJson: al.selectorJson, methodVersion: asm.methodVersion}) AS assessmentEvidence
RETURN criterion, e.uid, e.name, e.eventKind, e.startedAt, e.jurisdiction, e.designationType, e.approvalPathway,
       recordUids, assessmentUid, assessmentEvidence, trace
ORDER BY criterion, coalesce(e.startedAt, e.announcedAt)
```

- EXPLAIN: ok on Neo4j 5.26.31 community (1/1 statement); final-SDL static check clean (labels, types, pairs, properties, enum values, predicates)
- trace: T(e) per row (clock Assertions). For BC-DESIGNATION, also the DESIGNATION_TYPE FIELD Assertion: the sponsor's release gives the grant date, and the FDA BT approvals list is later corroboration (FC4). When a D8 record documents the act, its ISSUED_BY / ADDRESSED_TO Assertions apply too (Q-D13-12 shape). For BC-ANALYST, the Assessment's HAS_EVIDENCE locators and `methodVersion`. Press language stays a separate column built from claim occurrences (Q-D13-17). It is never merged into these rows.

## Q-D13-12

- question: accelerated or conditional approvals on F and the status of their confirmatory obligations.
- rulings: **R-66**. `approvalPathway IN ['ACCELERATED', 'CONDITIONAL']` becomes `['US_ACCELERATED_APPROVAL', 'EU_CONDITIONAL_MA']` (regulatoryPathwayMapping). The D8 RegulatoryRecord that documents the act (DOCUMENTED_BY_RECORD) is read for its `pathway` when the Event cache is unset. Regulator and holder come only from the record's ISSUED_BY / ADDRESSED_TO, because R-66 has the executor keep INVOLVES {REGULATOR, APPLICANT} off once the record exists. The pattern was already shaped this way. Each record link and each party link now also carries its authorizing Assertion uid.
- answer kind: unchanged (retrieved).

```cypher
MATCH (e:Event {eventKind: 'APPROVAL'})-[of:ON_FRONTIER]->(:Frontier {key: $frontierKey})
WHERE of.recordedTo IS NULL
  AND (e.approvalPathway IN ['US_ACCELERATED_APPROVAL', 'EU_CONDITIONAL_MA']
       OR EXISTS {
         MATCH (e)-[d0:DOCUMENTED_BY_RECORD]->(r0:RegulatoryRecord)
         WHERE d0.recordedTo IS NULL AND r0.pathway IN ['US_ACCELERATED_APPROVAL', 'EU_CONDITIONAL_MA']
       })
// the contingency statement (FC3 quote 3) and the confirmatory studies it names
OPTIONAL MATCH (e)<-[:HAS_SUBJECT]-(c:Assertion {predicate: 'CONTINGENT_ON'})
  WHERE c.recordedTo IS NULL
OPTIONAL MATCH (c)-[:HAS_OBJECT]->(st:Study)
OPTIONAL MATCH (c)-[:HAS_EVIDENCE]->(cl:SourceLocator)<-[:HAS_LOCATOR]-(cs:SourceSnapshot)
WITH e,
     collect(DISTINCT {assertion: c.uid, exact: cl.exact, selectorJson: cl.selectorJson, contentHash: cs.contentHash}) AS contingencies,
     collect(DISTINCT {study: st.uid, status: st.overallStatus, viaAssertion: c.uid}) AS confirmatory
// the D8 record of the act (R-66): regulator and holder are the record's
OPTIONAL MATCH (e)-[dr:DOCUMENTED_BY_RECORD]->(rec:RegulatoryRecord)
  WHERE dr.recordedTo IS NULL
OPTIONAL MATCH (rec)-[ib:ISSUED_BY]->(regulator:Organization)
  WHERE ib.recordedTo IS NULL
OPTIONAL MATCH (rec)-[at:ADDRESSED_TO]->(holder:Organization)
  WHERE at.recordedTo IS NULL
WITH e, contingencies, confirmatory,
     collect(DISTINCT {record: rec.uid, kind: rec.recordKind, pathway: rec.pathway, number: rec.recordNumber,
                       issuedAt: rec.issuedAt, issuedBy: regulator.name, addressedTo: holder.name,
                       link: dr.assertionUid, issuedByAssertion: ib.assertionUid, addressedToAssertion: at.assertionUid}) AS regulatoryRecords
// T(e): clock assertions plus the APPROVAL_PATHWAY FIELD assertion
CALL (e) {
  OPTIONAL MATCH (a:Assertion)-[:HAS_SUBJECT]->(e)
  WHERE a.uid IN [e.timeAssertionUid, e.announcementAssertionUid, e.effectiveAssertionUid, e.scheduleAssertionUid]
     OR (a.predicate = 'APPROVAL_PATHWAY' AND a.recordedTo IS NULL)
  OPTIONAL MATCH (a)-[:HAS_EVIDENCE {role: 'SUPPORTS'}]->(l:SourceLocator)<-[:HAS_LOCATOR]-(s:SourceSnapshot)<-[:HAS_SNAPSHOT]-(src:Source)
  OPTIONAL MATCH (a)-[:ASSERTED_BY]->(who)
  RETURN collect(DISTINCT {assertion: a.uid, predicate: a.predicate, value: a.valueString, assertedBy: who.uid,
                           exact: l.exact, selectorJson: l.selectorJson, contentHash: s.contentHash,
                           publishedAt: s.publishedAt, source: src.canonicalUri}) AS trace
}
RETURN e.uid, e.name, e.startedAt, e.jurisdiction,
       coalesce(e.approvalPathway, head([r IN regulatoryRecords WHERE r.pathway IS NOT NULL | r.pathway])) AS pathway,
       contingencies, confirmatory, regulatoryRecords, trace
ORDER BY e.startedAt
```

- EXPLAIN: ok on Neo4j 5.26.31 community (1/1 statement); final-SDL static check clean (labels, types, pairs, properties, enum values, predicates)
- trace: T(e). The CONTINGENT_ON Assertion's locator (FC3 quote 3: "Continued approval for this indication may be contingent upon verification and description of clinical benefit in ongoing confirmatory trials."). T(link) on `dr.assertionUid` (fixture a16, rule event-record-match/v1). The record's own ISSUED_BY / ADDRESSED_TO Assertions (`issuedByAssertion`, `addressedToAssertion`). The D3 study status cites its own registry Assertions; `overallStatus` is a projection cache (R-45).

## Q-D13-14

- question: after a safety signal, hold or failed readout on F, how did sponsor, regulator and market respond, in order.
- rulings: **R-44**. EventRole loses PUBLISHER and AUTHOR, so `inv.role IN [..., 'PUBLISHER']` drops PUBLISHER. A publisher's response survives by another route. Under R-44 a publisher's act on a work is a D3 REVISES episode (notice → work), asserted per asserter. A RETRACTION Event is only a curated milestone, EVENT_ABOUT the Publication. So the publisher is the asserter of the primary REVISES episode, the one not DERIVED_FROM another (R-21). Relays such as Retraction Watch and NLM are DERIVED_FROM it and are not shown as actors. R-44 reaches the publisher "through the Publication"; the final Publication has no publisher edge (only `venueName`), so the row also carries `work.venueName`. **R-66** is unchanged here: a regulator documented by a D8 record is read from ISSUED_BY. The INVOLVES role list adds APPLICANT and LEAD_INVESTOR, both final EventRole values, and filters INVOLVES to current episodes.
- answer kind: unchanged (retrieved). Nothing is lost.

```cypher
MATCH (stim:Event {uid: $stimulusUid})
MATCH p = (resp:Event)-[:RESPONDS_TO*1..3]->(stim)
WHERE all(r IN relationships(p) WHERE r.recordedTo IS NULL)
// event-role actors (R-44: no PUBLISHER / AUTHOR role)
OPTIONAL MATCH (resp)-[inv:INVOLVES]->(actor)
  WHERE inv.recordedTo IS NULL
    AND inv.role IN ['SPONSOR', 'APPLICANT', 'REGULATOR', 'INVESTOR', 'LEAD_INVESTOR', 'LENDER']
WITH stim, resp, p, collect(DISTINCT CASE WHEN actor IS NULL THEN null
                                     ELSE {actor: actor.name, role: inv.role, assertion: inv.assertionUid} END) AS roleActors
// a regulator documented by a D8 record is read from the record (R-66)
OPTIONAL MATCH (resp)-[dr:DOCUMENTED_BY_RECORD]->(rec:RegulatoryRecord)-[ib:ISSUED_BY]->(regulator:Organization)
  WHERE dr.recordedTo IS NULL AND ib.recordedTo IS NULL
WITH stim, resp, p, roleActors,
     collect(DISTINCT CASE WHEN regulator IS NULL THEN null
                      ELSE {actor: regulator.name, role: 'REGULATOR', record: rec.recordNumber, assertion: ib.assertionUid} END) AS recordActors
// a publisher's act (R-44): RETRACTION milestone EVENT_ABOUT a D3 Publication; publisher = asserter of the primary REVISES episode
OPTIONAL MATCH (resp)<-[:HAS_SUBJECT]-(ab:Assertion {predicate: 'EVENT_ABOUT'})-[:HAS_OBJECT]->(work:Publication)<-[rv:REVISES]-(notice:Publication)
  WHERE resp.eventKind = 'RETRACTION' AND ab.recordedTo IS NULL AND rv.recordedTo IS NULL
OPTIONAL MATCH (rva:Assertion {uid: rv.assertionUid})-[:ASSERTED_BY]->(reviser)
  WHERE NOT (rva)-[:DERIVED_FROM]->(:Assertion)
WITH stim, resp, p, roleActors, recordActors,
     collect(DISTINCT CASE WHEN reviser IS NULL THEN null
                      ELSE {actor: reviser.name, role: 'REVISES asserter (' + rv.revisionKind + ')', work: work.uid,
                            notice: notice.uid, venue: work.venueName, assertion: rva.uid} END) AS revisionActors
// market moves are attributed to their reporter, never to BellLabs
OPTIONAL MATCH (resp)<-[:HAS_SUBJECT]-(mm:Assertion {predicate: 'REPORTED_MARKET_MOVE'})-[:ASSERTED_BY]->(reporter)
  WHERE mm.recordedTo IS NULL
WITH stim, resp, p, roleActors + recordActors + revisionActors AS actors,
     collect(DISTINCT CASE WHEN mm IS NULL THEN null
                      ELSE {move: mm.valueString, reportedBy: reporter.name, assertion: mm.uid} END) AS marketMoves
// T(link): each RESPONDS_TO hop's authorizing Assertion, its locator and its SUPPORT adjudication (R-22 gate)
CALL (p) {
  UNWIND relationships(p) AS r
  OPTIONAL MATCH (la:Assertion {uid: r.assertionUid})-[:HAS_EVIDENCE {role: 'SUPPORTS'}]->(l:SourceLocator)<-[:HAS_LOCATOR]-(s:SourceSnapshot)
  OPTIONAL MATCH (adj:Adjudication {adjudicationKind: 'SUPPORT'})-[:ASSESSES]->(la)
    WHERE adj.recordedTo IS NULL
  RETURN collect({assertion: r.assertionUid, exact: l.exact, selectorJson: l.selectorJson, contentHash: s.contentHash,
                  verdict: adj.verdict}) AS linkTrace
}
// T(e) for the response event's clocks
CALL (resp) {
  OPTIONAL MATCH (a:Assertion)-[:HAS_SUBJECT]->(resp)
  WHERE a.uid IN [resp.timeAssertionUid, resp.announcementAssertionUid, resp.effectiveAssertionUid, resp.scheduleAssertionUid]
  OPTIONAL MATCH (a)-[:HAS_EVIDENCE {role: 'SUPPORTS'}]->(l:SourceLocator)<-[:HAS_LOCATOR]-(s:SourceSnapshot)<-[:HAS_SNAPSHOT]-(src:Source)
  RETURN collect(DISTINCT {assertion: a.uid, predicate: a.predicate, exact: l.exact, selectorJson: l.selectorJson,
                           contentHash: s.contentHash, source: src.canonicalUri}) AS trace
}
RETURN resp.uid, resp.eventKind, resp.startedAt, length(p) AS hops, actors,
       [r IN relationships(p) | r.assertionUid] AS stated, linkTrace, marketMoves, trace
ORDER BY coalesce(resp.startedAt, resp.announcedAt)
```

- EXPLAIN: ok on Neo4j 5.26.31 community (1/1 statement); final-SDL static check clean (labels, types, pairs, properties, enum values, predicates)
- trace: T(link) for every RESPONDS_TO hop (FC6 quote 1), with its SUPPORT adjudication. Market moves cite the reporting source's locator (FC6 quote 3) and are attributed to that asserter. A publisher actor cites its REVISES Assertion (lesne a09 shape). T(e) for each response.

## Q-D13-22

- question: events resting on a single non-primary source or only a press release (corroboration gap).
- rulings: **R-21**. The independence rule no longer reads the unregistered qualifier `derivedFrom=<uid>`. An Assertion's origin is the asserter at the end of its kernel DERIVED_FROM chain, where every relaying Assertion has `basisKind: CITED_FROM_PRIOR_WORK`. An Assertion with no such chain is its own origin (its asserter). The authority-record test is unchanged: a typed DOCUMENTED_BY_RECORD (R-66) or an authority genre.
- answer kind: unchanged (retrieved). Fixture note (open-questions FX-D13-01 (a), (d)): intent contract v1 cannot write an Assertion → Assertion DERIVED_FROM (OD-09). Lesne a02 was dropped, so Retraction Watch's corroboration of the lesne RETRACTION now sits on its REVISES episode a10 (DERIVED_FROM a09) and not on an Event date Assertion. On the lesne Event this pattern sees one origin, the publisher, which is also the authority of record, so the Event is not flagged. bioage stays flagged (one origin, no 8-K).

```cypher
MATCH (e:Event)-[of:ON_FRONTIER]->(:Frontier {key: $frontierKey})
WHERE of.recordedTo IS NULL
MATCH (e)<-[:HAS_SUBJECT]-(a:Assertion)
WHERE a.predicate IN ['EVENT_OCCURRED', 'EVENT_ANNOUNCED'] AND a.recordedTo IS NULL
MATCH (a)-[:ASSERTED_BY]->(who)
MATCH (a)-[:HAS_EVIDENCE]->(:SourceLocator)<-[:HAS_LOCATOR]-(:SourceSnapshot)<-[:HAS_SNAPSHOT]-(src:Source)
// independence rule (R-21): an Assertion counts with its ORIGIN, the asserter at the end of its DERIVED_FROM chain
// of retellings (basisKind CITED_FROM_PRIOR_WORK); with no chain it is its own origin
OPTIONAL MATCH chain = (a)-[:DERIVED_FROM*1..4]->(root:Assertion)
  WHERE NOT (root)-[:DERIVED_FROM]->(:Assertion)
    AND all(n IN nodes(chain)[0..-1] WHERE n.basisKind = 'CITED_FROM_PRIOR_WORK')
OPTIONAL MATCH (root)-[:ASSERTED_BY]->(rootWho)
WITH e, a, who, src, coalesce(rootWho.uid, who.uid) AS origin, root
OPTIONAL MATCH (e)-[dr:DOCUMENTED_BY_RECORD]->(:RegulatoryRecord)
  WHERE dr.recordedTo IS NULL
WITH e, collect(DISTINCT origin) AS origins, collect(DISTINCT who.uid) AS asserters,
     collect(DISTINCT src.sourceKind) AS sourceKinds, collect(DISTINCT src.genre) AS genres, count(dr) > 0 AS hasRecord,
     collect(DISTINCT CASE WHEN root IS NULL THEN null ELSE {assertion: a.uid, derivedFrom: root.uid} END) AS relays,
     collect(DISTINCT a.uid) AS assertionUids
WITH e, origins, asserters, sourceKinds, genres, relays, assertionUids,
     hasRecord OR any(g IN genres WHERE g IN ['REGULATORY_FILING', 'REGULATORY_RECORD', 'RETRACTION_NOTICE']) AS authorityRecord
RETURN e.uid, e.eventKind, e.startedAt, size(origins) AS independentOrigins, size(asserters) AS asserters,
       sourceKinds, genres, authorityRecord, relays, assertionUids,
       CASE WHEN size(origins) = 1 AND NOT authorityRecord THEN 'single origin, no authority record'
            WHEN size(origins) = 1 THEN 'single origin (the authority of record)' END AS gap
ORDER BY independentOrigins, e.startedAt DESC
```

- EXPLAIN: ok on Neo4j 5.26.31 community (1/1 statement); final-SDL static check clean (labels, types, pairs, properties, enum values, predicates)
- trace: the per-asserter Assertions (`assertionUids`) and their Sources. Each relay cites its DERIVED_FROM target (`relays`). T(e) applies to the Event's clocks as in Q-D13-04.
