## B. Problems and workarounds (for 08-sources-and-tools and the action space)

1. `curl` from Git Bash cannot write to MSYS-style paths (`/c/...`): exit 23 "Failed writing received data"; use `C:/...` paths.
2. `python -I` ignores `PYTHONIOENCODING`; use `sys.stdout.reconfigure(encoding="utf-8")`.
3. Shared-IP quota exhaustion is a team-level failure mode (FDC DEMO_KEY, Semantic Scholar unkeyed, OpenAlex daily USD budget). Keys are needed before a multi-agent run, not per agent.
4. Three different "what a registry knew" clocks appear in one trial: CT.gov `studyFirstSubmitDate` 2016-09-29, ICTRP "Last refreshed on: 12 December 2016", CT.gov `dataTimestamp` 2026-10-08. The kernel must keep publisher time, observation time and retrieval time apart (already in SourceSnapshot).
