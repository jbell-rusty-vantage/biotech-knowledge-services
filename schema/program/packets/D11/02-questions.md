# D11 — high-value questions

D11 is cross-cutting: its questions are about whether an answer can be *reached, identified, located and trusted* — the tooling, identifier and capture layer under every other domain. Sources column uses ids from `tooling/action-space.yaml`. Rows that reuse a competency question keep its `CQ-*` id and say so in the question text. Polarity `harm` covers harm, risk, avoidance and disconfirmation. 30 rows; 15 are `harm` (50 %). Adversarial review (2026-10-08): six ids another packet also declares (CQ-AX-04 and CQ-AX-07 owned by K, CQ-ID-04 by D1, CQ-PV-02/04/05 by D9) now carry the owner's question text, audience, value and polarity verbatim (D11 had re-scored CQ-AX-04 and CQ-PV-05 as harm, CQ-ID-04 and CQ-PV-02 as value 1); how the synthesizer merges shared catalog ids is 11-open-questions item 37. CQ-AX-14 and CQ-PV-03 are declared by no other packet. Model stage (2026-10-08): ids unchanged; answer shapes and sources updated to the published kernel (ResolutionHypothesis → Assessment RESOLUTION; SourceRevisionEvent → SourceSnapshot.revisionKind + D3 REVISES) and to the one D11 node type CaptureAttempt (Q-D11-01, Q-D11-07, Q-D11-17, CQ-AX-04, Q-D11-20; since the adversarial review it records only FAILED / PARTIAL requests); Q-D11-07, Q-D11-17 and CQ-AX-04 now have a fixture.
