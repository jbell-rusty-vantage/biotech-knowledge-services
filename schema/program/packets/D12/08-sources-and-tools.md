## What broke (fixtures stage)

- FDC API `DEMO_KEY` rate limit: HTTP 429 after the research stage's calls (`X-Ratelimit-Limit: 10`); a team run needs its own key. Values were re-verified through the undocumented portal endpoint; the snapshots of record stay the research-stage API captures.
- Firecrawl markdown is not byte-stable across scrapes with different options or page chrome (FDA acrylamide 59,934 → 66,680 bytes; Phenol-Explorer 23,597 → 25,375 bytes). Every quote was re-found verbatim, at shifted offsets; selectors therefore carry exact + 32-character prefix/suffix and the offsets of the capture they were cut from.
- Firecrawl failed on a PMC supplementary PDF URL; PMC answers curl with a proof-of-work challenge page ("Preparing to download ...", cookie `cloudpmc-viewer-pow`); Europe PMC refuses supplementary files of non-OA articles. The publisher CDN served the PDF.
- intent v1 cannot carry Assertion amounts/roles on `edge.assert`, cannot bind an object to a predicate-only Assertion, and has no claim or CALCULATED fields (OQ-D12-23). All five intents validate against `IngestionIntent`; none was planned against a database (the executor's pinned schema has no D12 types).

## Custom tooling D12 needs (priority order)

1. **Entity resolution for foods** (P1): normalized names across FDC, menus, Phenol-Explorer and Open Food Facts; candidate index; RESOLUTION / EQUIVALENCE assessments; menu-page URL discovery per chain.
2. **FDC loader** (P1): bulk download (not the rate-limited API) → FoodItem, FOOD_CONTAINS with derivation code, n, min, max on the Assertion, portions, category, historical flag; locators that pin `foodNutrient.id`, not only the row index.
3. **Regulator table parser** (P1): FDA survey tables and attachments with group labels carried to every row, sampling windows as valid time, LOQ per table.
4. **NOVA marker classifier** (P2): versioned lexicon and CALCULATED assertion writer (`nova-markers/v<n>`), with OFF's own `nova_group` kept as a separate, stated-by-OFF assertion.
5. **Supplement resolver + PDF page text** (P2): DOI → publisher supplementary files → page-addressed text for PDF_TEXT locators.
6. **Phenol-Explorer composition parser** (P2): food × compound × mean/n/SD/method rows instead of report prose.
