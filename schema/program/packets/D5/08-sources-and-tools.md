## What broke, and what needs custom tooling

- **Broke / degraded in this stage:** Wayback CDX offline on every retry (change point between the 2021 and 2026 observations stays unbounded); Wayback replay silently served a different capture than requested (read `Memento-Datetime`); a 2023 replay of the Webflow page had no content; extracted SPL XML members carry the publisher's mtimes (retrieval time must come from the downloaded zip); Tavily needs `PYTHONUTF8=1` on Windows; `python -I` ignores `PYTHONUTF8` (use `-X utf8`).
- **Intent contract gaps (OQ-D5-27):** `biotech-knowledge-intent.v1` has no proposal kind for a predicate-only Assertion that has an object node (every D5 safety and target predicate), and `AssertionCore` carries no `qualifiers`, `valueString` or `supersedesUid`, so the mandatory `population:` qualifier and the directive level cannot be written; the four fixture intents validate against the schema but carry these in `rationale`.
- **Custom tooling needed:** (1) protocol step extractor → canonical step payload → `payloadHash` + `stepKey` aligner across in-place editions, with disclosure/sponsor text routed to D7 instead of the payload; (2) UseConstraint identity projection (`tool:ks-projection`, rule `use-constraint-key/v2`, which adds the timing component, and emits STATES_CONSTRAINT from the protocol author's caution assertions); (3) query-time dose-vs-limit comparator (unit, period, intake scope, population, elemental-vs-salt mass) for Q-D5-06; (4) SPL version differ over DailyMed archived zips for Q-D5-24; (5) label sub-section splitter for openFDA section blobs; (6) Discourse author/edit-date join for forum snapshots; (7) CAERS reaction-term normalizer before any count.
- **Snapshot hash basis (adversarial review):** every Tavily snapshot's `contentHash` is sha256 over the UTF-8 bytes of the extractor output exactly as stored, with no normalization (the NFC + whitespace normalization in the generator applies only to quote and selector hashes). The fixtures stage labeled these `NORMALIZED_TEXT`; they are now `EXTRACTED_TEXT_BYTES` with a note on each snapshot, and the code is requested from the kernel (OQ-D5-46). curl captures (openFDA, DailyMed, E-utilities, Discourse, Wayback) stay `RAW_BYTES`.
