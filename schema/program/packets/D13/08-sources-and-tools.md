## What was exercised in the fixtures stage

- **Re-fetched and re-verified:** all 22 distinct snapshots behind the five fixtures (23 snapshot slots; the Madrigal submissions index is shared by two fixtures) were captured fresh on 2026-10-08 (scratch `ft/D13/fx/raw/`, not committed). Within that session EDGAR, openFDA and Crossref bytes were identical to the research captures; Tavily markdown was textually identical but saved with LF (new sha256); the Firecrawl Nature notice differed only by a trailing newline. **Adversarial-review correction:** "identical" held only inside the authoring session. A later re-fetch of EDGAR HTML returns other raw bytes (per-client `<script src>` injected by sec.gov) with the same h2t-v1 projection, and the Wayback `id_` capture returned other bytes too; so EDGAR HTML snapshots are now identified by the projection hash (contentHashBasis NORMALIZED_TEXT, reproducible), and every other snapshot records `refetchReproducible` (live API records and scraper outputs are not reproducible; the stored artifact is the evidence and needs durable storage, 11-open-questions.md). The adversarial-review pass added one capture (ClinicalTrials.gov NCT03900429, for the Study side of ON_FRONTIER): 23 distinct snapshots. Every one of the 70 locators was re-selected from the captured bytes by `_notes/tools/build_fixtures.py` (49 TEXT_QUOTE, all exact and unique in their snapshot; 16 JSON_POINTER; 3 API_RECORD rule `edgar-accession/v1`; 1 HTML title; 1 WHOLE_SNAPSHOT rule).

## What broke or is missing (readiness findings)

1. **verification.v1 is not callable here.** The LEADS_TO / RESPONDS_TO projection gate rests on SUPPORT adjudications; the fixtures state expected verdicts only. Needed: a fixture-mode verifier run over `locators.yaml` (custom tooling, owner kernel/D11).
2. **Intent v1 cannot express three D13 needs** (predicate-only assertion with an object node; assertion held for adjudication before edge projection; qualifiers). Recorded in `11-open-questions.md`; owner kernel / contracts.
3. **Canonical projection for HTML filings** must be a registered, versioned artifact (h2t-v1 here) or text offsets are not reproducible across agents and operating systems (the research copy wrote CRLF on Windows).
4. **Line endings change capture digests** for text extracted by Tavily/Firecrawl: the capture artifact must be written byte-stable (UTF-8, LF) by the capture tool, not by each agent.
5. **Registry history (ClinicalTrials.gov) is 403** for scripts: status-change events need periodic snapshots.
6. **Item-heading whitespace** in EDGAR HTML (thin space) breaks naive section anchors; selectors must normalize whitespace or anchor on the heading text.
7. **Absence evidence** (no 8-K) needs a rule over a COMPLETE index capture (`edgar-form-window/v1`); a partial capture can never support it.
8. **Raw bytes are not reproducible by re-fetch** (adversarial review): sec.gov HTML carries a per-client script path, Wayback `id_` responses vary, scraper markdown varies, and live API records change. A verifier that re-fetches `canonicalUri` can reproduce only the h2t-v1 projection of EDGAR HTML; for everything else it needs the stored artifact (kernel `storageUri`), which the fixtures keep only in session scratch. Needed: durable blob storage of capture artifacts (owner kernel / D11).
9. **Positional JSON pointers into growing arrays** (EDGAR `filings/recent`) silently select another filing on a fresh capture; select by key (`edgar-accession/v1`).

## Custom tooling needed

- EDGAR fetcher with item-code routing and a registered HTML→text projection (replaces h2t-v1); SEC_ACCESSION identifier scheme.
- A fixture-mode verification.v1 runner that consumes `locators.yaml` + `assertions.yaml` and emits Adjudications.
- Intent v1 additions: `assertion.object` (predicate-only with object node), `assertion.hold` / project-on-adjudication for gated typed edges, `qualifiers` on AssertionCore.
- A frontier-curator agent implementing frontier-classification/v1 against `vocab-frontiers.yaml` with the version qualifier.
