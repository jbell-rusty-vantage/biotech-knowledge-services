## What was exercised, what broke, what needs custom tooling

- **Exercised in the fixtures stage (2026-10-08, fresh captures):** curl on fda.gov, openFDA, regulations.gov (PDFs and API v4), EUR-Lex, CAFC, Google Patents, SEC EDGAR, NSF (two sites), Amazon-hosted COA PDFs, ClinicalTrials.gov v2; Firecrawl CLI for regulations.gov PDFs (projection) and Informed Sport; `pdftotext`, `pdftoppm`; scratch extract/locate/verify scripts; `@bks/contracts` zod validation of every `intent.json`. MCP connectors (PubMed, ClinicalTrials, bioRxiv, Exa, ICD-10, NPI) were not needed for D8 fixtures; the repo `.mcp.json` servers (pubmed, pubchem, clinicaltrialsgov, edgartools) were not loaded in this session — public HTTP APIs were used instead (readiness finding).
- **Broke or misled (new or corrected in the fixtures stage):** E5 corrected — the "2029" date is printed in FDA's letter, not a parser error; E4 corrected — glyph loss was `pdftotext`'s default encoding; **E6** — Firecrawl's PDF parser misread an NCT id in an FDA footnote, producing a false "regulator mis-cited a trial" research finding; **E7** — regulations.gov attachments are fetchable with browser-like headers (no browser needed); **E8** — naive HTML-to-text keeps commented-out text that is not displayed. Unchanged blockers: FDA Data Dashboard, USPTO TSDR (keys), PatentsView (no response), Informed Sport (no raw bytes).
- **Custom tooling needed (priority order):** (1) a selector verifier that re-selects from document bytes, not from a parser projection, with versioned extractors and text hashes (prototype built); (2) PDF table reconstruction with page-render cross-check, and BOUNDING_BOX selectors for scanned regulator letters; (3) a COA row parser that emits `resultBasis` per row; (4) a recall `code_info` lot parser; (5) a warning-letter section parser and an index crawler; (6) canonical text projection hashing for pages whose bytes change per request (EUR-Lex, nsfsport); (7) scheduled re-capture plus diff for certifier pages (COVERS episodes); (8) access decisions for FDA Data Dashboard and USPTO keys (owner).
