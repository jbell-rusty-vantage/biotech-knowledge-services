## 1. What the evidence says the model must distinguish

1. **Label content vs label capture.** The same label (Tru Niagen 300 mg, version V12.3) is visible in at least four captures: the DSLD record, the iHerb Supplement Facts table, the Amazon listing text, the brand page [FC-1, FC-2, FC-3]. Questions ask about the label *version* (what it declares, since when, what changed: Q-D6-01, CQ-ID-05), not about each capture. → a D6 content node (working name `LabelVersion`) that many kernel `SourceSnapshot`s evidence, instead of the pinned `LabelSnapshot` being itself a SourceSnapshot specialization.
2. **Label change ≠ formulation change ≠ package/GTIN change.** FC-1: same UPC, same composition, directions max daily servings 1 → 3 and seals changed (NSF dropped, Alkemist added). FC-2: GTIN 850015311116 → 850015311857 and package dimensions changed, composition unchanged, while the retailer calls it a "New formulation". FC-8: net contents 360 g → 350 g with unchanged serving. FC-9: possible real composition change (brand vs crowd record disagree). → directions, servings and seals belong to the label version; composition to the formulation version; count/net quantity/GTIN to the package. A directions-only change must not mint a FormulationVersion.
3. **Identifiers are temporal and channel-specific.** One 30-count package has DSLD UPC 850015311116 (2023 and 2025 labels), brand barcode 850015311857 (already on 2025-05-20), Amazon UPC/GTIN-14 850015311857 / 00850015311857, iHerb product codes TNN-31111 and TNN-31185, a Shopify variant id, an ASIN with a parent family (`30-300MG-PARENT`), and a tracker EAN that is malformed [FC-1, FC-2, FC-3]. → identifiers need valid time and an issuing scheme; equivalence between them is an assessment (Q-D6-15), not a merge.
4. **Price is plural.** Kind (one-time, subscription tier, per count as displayed, bundle, compare-at), observer (merchant page, archive capture, tracker statistic, publisher index), seller role (brand-as-3P on Amazon with Amazon fulfilment), instant, region [FC-3, FC-4]. Tracker "average" values are derived and should not be stored as observations; "lowest ever $42.99 (Oct 31, 2024)" is a dated observation by the tracker.
5. **Harm attaches at lot, package and channel level, and arrives as free text.** Recalls name lots and channels in text; GTINs are absent [FC-5, FC-7]. Firm and agency statements conflict [FC-5]. → recall → package/lot links are assertions with locators; listing ↔ recalled product is a commerce-match assessment (Q-D6-05).
6. **Prepared foods are products with a declaring organization and no GTIN.** McDonald's: per-component ingredients and allergens, preparation note, nutrient lines with %DV, an "as of January 2022" statement, no price; a third party publishes the price series with a 2022 method change [FC-4]. → identity rule for menu items: (organization, item name, jurisdiction); the declaration is a `LabelVersion` with panel kind MENU/NUTRITION and an as-of date.
7. **Sellers are not makers.** Brand stores resell partner products (Blueprint "Partnership" items: Prenuvo scans, Eight Sleep, Withings) [S33]; the 10-K names contract manufacturers without naming them and a sole ingredient supplier [FC-6]; labels name a distributor [FC-1]. → role edges by role, with the role's source kind (label contact, filing, storefront vendor field).

## 4. Properties and enums worth keeping (with the question that filters or sorts on them)

- **Product.productKind** (Q-D6-03, Q-D6-12): the pinned enum lacks prepared foods and services as such; observed kinds: dietary supplement, packaged food (David bars, pints, canned cod), restaurant menu item (Big Mac), consumer device (Eight Sleep, Withings), diagnostic/imaging service (Prenuvo scan). Proposed values: `DIETARY_SUPPLEMENT, CONVENTIONAL_FOOD, PREPARED_FOOD, CONSUMER_DEVICE, MEDICAL_DEVICE, DIAGNOSTIC_TEST_SERVICE, DRUG, COSMETIC, OTHER`.
- **Product.status** (pinned `ProductStatus` = DISCOVERY … APPROVED) is a drug-pipeline vocabulary and wrong for consumer goods; market status is an assertion on offers/packages (discontinued as displayed, recalled lots). Recommend removing it from D6 Product (D8/D13 own pipeline status).
- **Package**: `packageKind` (SINGLE, MULTIPACK, KIT, BUNDLE), `unitCount`, `unitNoun`, `netQuantityValue`, `netQuantityUnit` (UCUM), `packageForm` (bottle, box, stick-pack carton, pouch, carton). Dimensions and weight: otherProperties only.
- **LabelVersion**: `panelKind` (SUPPLEMENT_FACTS, NUTRITION_FACTS, MENU_DECLARATION, INGREDIENT_STATEMENT), `labelVersionCode`, `jurisdiction`, `servingSizeValue`, `servingSizeUnit`, `servingsPerContainer`, `minDailyServings`, `maxDailyServings` (Q-D6-09), `asOfStatement` / `asOfDate` (McDonald's "correct as of January 2022"), `firstObservedAt`, `lastObservedAt` (derived from snapshots, read-only).
- **FormulationVersion**: `compositionDigest`, `jurisdiction`; components on the edge (amount, unitCode, amountReferent per CQ-PF-01, massBasis, order, role, blendKey).
- **Offer**: `purchaseMode` (ONE_TIME, SUBSCRIPTION), `subscriptionIntervals`, `subscriptionTermsText`, `subscriptionApp` (e.g. `ordergroove-subscribe-and-save`), `sellerAccountId` (Amazon seller id; also an identifier), `validFrom/validTo` (null end when unknown, CQ-CM-05).
- **PriceObservation**: `amount`, `currency`, `observedAt` (+ `observedAtPrecision` DAY for tracker dates), `priceKind` (proposed: `ONE_TIME, SUBSCRIPTION, COUPON_ADJUSTED, LIST_OR_COMPARE_AT, BUNDLE, PER_UNIT_AS_DISPLAYED, TRACKER_LOW, TRACKER_HIGH`), `observerKind` (`MERCHANT_PAGE, ARCHIVE_CAPTURE, PRICE_TRACKER, PUBLISHED_INDEX, REGULATOR_RECORD`), `region`, `availabilityObserved` (pinned ObservedAvailability is fine; it already has `DISCONTINUED_AS_DISPLAYED`), `unitQuantity/unitCode` when the page shows a per-unit price. Do not store averages; do not store price per dose.
- **MerchantListing**: `hostItemId`, `listingKind` (MARKETPLACE_DETAIL_PAGE, RETAILER_ITEM, DTC_PRODUCT, MENU_ITEM_PAGE), `title` (as displayed; not label truth, CQ-PF-02).
- Commerce-match assessment kinds (for the kernel/D10 assessment node): `LISTING_TO_PACKAGE`, `IDENTIFIER_EQUIVALENCE`, `RECALL_SCOPE`, `AUTHORIZED_CHANNEL`, `CHANGE_KIND` (CQ-ID-05 verdict: LABEL_ONLY, PACKAGE_ONLY, FORMULATION, IDENTITY, UNKNOWN).
- Identifier schemes D6 emits (for the kernel identifier registry): GTIN-12/UPC-A, GTIN-13/EAN, GTIN-14, ASIN, Amazon seller id, iHerb product code, retailer item id, Shopify product id / variant id / SKU, DSLD label id, DSLD productVersionCode, openFDA recall_number / event_id, lot code (D8), NSF listing id (D8), Open Food Facts code, SEC accession (K/D9).
