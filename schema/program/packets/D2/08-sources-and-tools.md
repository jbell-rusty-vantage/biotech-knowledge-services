## What broke

1. **Python `-I` and Windows console.** `python -I` ignores PYTHONIOENCODING, so printing Greek or NBSP text crashed with cp1252 UnicodeEncodeError. Fix: `sys.stdout.reconfigure(encoding="utf-8")` inside the script.
2. **POSIX paths with native Windows interpreters.** Git Bash `/c/...` paths passed to Windows Python resolved to `C:\c\...` (file not found). Fix: use `C:/...` paths. This is the same class of problem as the model stage's print-schema fallback.
3. **Text derivation drift.** The GenAge HTML→text output differs between the research and fixtures stages (citation spacing), so offsets are only meaningful together with the derivation id and the derived-text digest. Both are recorded on every snapshot.
4. **Registry vs paper granularity.** The paper's two groups map onto four registry arms. The ClinicalTrials.gov MCP hides arm groups entirely.
5. **Identifier lookups that would otherwise have been guessed.** Dasatinib's ChEMBL parent is CHEMBL1421, not a remembered id. SRT1720 has no ChEMBL pref_name match (its pref_name is null); it resolves via the molecule search and its structure to CHEMBL257991 (free base; HCl CHEMBL4639328) and PubChem CID 25232708 (HCl). The fixtures stage stopped at the pref_name miss; the adversarial review resolved it.
6. **CRLF derived text (adversarial review).** `xml2txt.py` first wrote its output in Windows text mode, so the recorded jats-xml2txt/v1 digests covered CRLF bytes while the offsets index the LF text. Fix: `newline='\n'` in the rule, every digest recomputed over the UTF-8 LF text (intent.json `derivedTextHash`, locators.yaml `derivedText.contentHash`, source.md); all TEXT_QUOTE offsets re-select unchanged. html2txt/v1 already wrote LF.
7. **Script shells.** `agelessrx.com` returns a script shell to curl; Firecrawl rendered it (source S45 in 01).

## What needs custom tooling

- A **text-derivation registry**: a named rule plus a digest for the JATS→text and HTML→text projections, with offset bases, so SourceLocator offsets re-select. Each rule fixes its output encoding and newline convention (jats-xml2txt/v1 and html2txt/v1: UTF-8, LF; the digest is sha256 over those bytes; offsets are Unicode code points into the same text). This is the verifier's canonical projection (kernel `canonicalProjectionHash`).
- A **normalization profile** `nbsp-nnbsp-hyphen/v1`, shared with the verifier.
- A **value-based JSON selector** for arrays whose index drifts (UniProt cross-references, Reactome participants). One option is a JSON pointer plus a key predicate (`@displayName=…`), as `build_locators.py` already resolves.
- A **Reactome participant-role adapter**: per-reaction input, output and catalyst roles from the reaction-level endpoints, so participantRole is not always MEMBER.
- **Intent v1 extensions** for predicate-only Assertions and context attachment (G1, G2).
- A **projection runner** (`project.py`) promoted into the executor's PROJECTION Activity, with an `inputSetDigest`.
