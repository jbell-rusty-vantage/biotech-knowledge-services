## Model-stage changes (A4, 2026-10-08)

Question ids, wording and answer kinds are unchanged. The model changed where some answer-shape properties live; the rows above are read with these mappings:

- Cut: `StudyResult.isStatisticallySignificant` (duplicate of `statisticalConclusion`); `baselineValue`, `followupValue`, `absoluteChange`, `relativeChangePercent` (each is a separate StudyResult with its own `resultKind`, e.g. MEAN with comparisonKind ARM_DESCRIPTIVE, or PERCENT_CHANGE with WITHIN_ARM_CHANGE).
- `AE.*` in CQ-ST-06 → `StudyResult.*` (AdverseEventResult merged).
- Q-D3-17 and Q-D3-06 population fields → `StudyPopulation` (species as `ncbiTaxonId` + `strainOrLine`, no taxon node).
- Q-D3-08 roles: one typed edge `HAS_STUDY_ROLE` (Study → D7 Organization | Person | Award) with `roleKind` LEAD_SPONSOR, SPONSOR, COLLABORATOR, FUNDER, FUNDING_AWARD, MATERIAL_PROVIDER, CRO, SITE, PRINCIPAL_INVESTIGATOR, RESPONSIBLE_PARTY; authors are predicate-only `AUTHORED_BY` Assertions.
- Q-D3-10 also accepts a condition (D2 Condition via `INVESTIGATES`) as X, besides an intervention or a frontier; the question id and answer kind are unchanged.
- Q-D3-11 included-trial counts are the predicate-only `INCLUDED_STUDY_COUNT` on each review version; CQ-ST-10 authors' meaningfulness statement is the predicate-only `CLINICALLY_MEANINGFUL`.
- CQ-EV-04, CQ-ST-03, CQ-ST-09, CQ-ST-10, Q-D3-07, CQ-AX-24 read kernel `Assessment` nodes (kinds APPLICABILITY, EVIDENCE_SYNTHESIS, QUALITY, and requested ENDPOINT_CLASSIFICATION / RESULT_INTERPRETATION / dose translation) instead of the seven W10 node types.
- Every StudyResult and OutcomeDefinition filter property above is the only property of its type left filterable and sortable in the SDL; the rest carry `@filterable(byValue: false) @sortable(byValue: false)` (`06-node-register.yaml`).

## Adversarial-review changes (A4, 2026-10-08)

- CQ-ST-07 answer kind `materialized` → `retrieved`: the pattern streams the clusters per request and stores nothing (03); a published count is a D10 Report.
- `StudyResult.direction` and `statisticalConclusion` are neutral (above); Q-D3-05 reads harm with the event-risk rule `d3-event-risk-reading/v1` or a `D3.result-interpretation` Assessment with `effectDirection: HARM`.
