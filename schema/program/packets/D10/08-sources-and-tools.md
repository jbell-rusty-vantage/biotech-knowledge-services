## What was exercised, what broke, what needs custom tooling

Exercised in the fixtures stage (2026-10-08): curl re-fetch of every research capture used by a fixture (8 files byte-identical, including the 196 MB LiverTox archive); `tvly extract` re-extraction of five pages (four identical, Examine changed); new captures from the NIH DSLD API (3 labels) and openFDA (1 label); `pdftotext -layout -enc UTF-8`; two scratch scripts that compute every locator from the fresh bytes (`gen_locators.py`: offsets, prefix/suffix, page, enclosing JATS `<sec>` or markdown heading, quote and content digests) and cross-check the fixtures (`verify_fixtures.py`: all refs resolve, every quote re-selects at its offsets, body digests match); `@bks/contracts` `IngestionIntent` (zod) to validate the five `intent.json` files (all valid).

Exercised in the adversarial-review stage (2026-10-08): curl re-fetch of the FDA letter (byte-identical, sha256:06bb4aff…) and its `pdftotext -layout -enc UTF-8` projection (identical, sha256:3908c8f9…); Firecrawl maxAge 0 scrapes of the Examine magnesium page and the FDA constituent update; `curl -I` of the LiverTox archive (Last-Modified Thu, 08 Oct 2026 06:40:21 GMT, unchanged); four openFDA FAERS count queries (new snapshots); a BM25 keyword retrieval over the JATS leaf sections (the question-to-chunk hop of the unstructured fixture, executed); the patched scratch generators and checkers (`gen_locators.py`, `verify_fixtures.py`, `gen_intents.py`, `validate_intents.mjs`, `check-edges.mjs`) and a body-to-ledger checker (`adv/tools/body_offsets.py`).

Broke or needed workarounds:

1. pdftotext's default encoding wrote the research-stage text layer in the console code page (curly quotes lost); the fixture uses a UTF-8 projection with its own digest.
2. Two Tavily extractions of the Examine page on the same day differed ("Last Updated" August 31 vs September 30, 2026; 22,957 vs 6,582 bytes). The fixtures stage read this as a same-day content change; the adversarial-review stage corrects it: a Firecrawl scrape with maxAge 0 shows "Last Updated: September 29, 2026" with an update history listing updates "9 days ago" and on "August 30, 2026", so on 2026-10-08 the page could not have shown August 31; the research-stage extraction was provider-cached (stale) content, not a NEW_VERSION or SILENT_CONTENT_CHANGE. Readiness finding: a tavily-extract `retrievedAt` does not certify the content date; when the date matters, fetch with Firecrawl maxAge 0 or record the provider's cache metadata. The quoted sentence is in both extractions, so the locator re-anchors exactly.
3. U.S. News ranking rows contain no-break spaces (`Score: 100`); a quote typed with a plain space does not match. Locators must be computed from bytes, never typed.
4. openFDA brand-name search returned NOT_FOUND for RAPAMUNE; generic-name searches return repackager labels; pin by `set_id`.
5. DSLD: no product-level grouping of label versions; the U.S. News sample product names do not match DSLD names exactly (Slow-Mag "Magnesium Muscle Support" vs DSLD "Slow-Mag Tablets").
6. Sourcing `.env` in Git Bash with `set -a; . ./.env` fails on unquoted values and echoes fragments of those lines to stderr; read single keys with a targeted parser instead (RUNLOG).
7. The harness refuses Write of files whose names look like reports (`report-*.md`); fixture report bodies are written as `composed-body*.txt` via scratch and `cp`.

Custom tooling D10 needs (priority order): (P1) `report.publish` intent + executor transaction for Report + ReportItems with body and ledger digests; (P1) the comparison engine that evaluates DecisionCriterion rules with BLOCK-before-SCORE and NOT_EVALUATED on unknown inputs; (P1) a locator compiler like `gen_locators.py` in the ingestion path (quotes from bytes, never from model output); (P1) LiverTox member-level cache over the litarch archive; (P2) `projection.write` intent and a projection job for Association records; (P2) `assessment.record` intent for Assessments (strength, harm causality, retelling fidelity, signal interpretation); (P2) an intent proposal kind for a predicate-only Assertion with an entity object (today only `edge.assert`, which implies a typed edge); (P3) GDS projections for SIMILARITY / LINK_PREDICTION Associations.
