## Readiness findings for D11

1. **NCBI Bookshelf HTML is reCAPTCHA-walled** for curl, Tavily and Firecrawl (2026-10-08). The litarch bulk archive is the reliable path; locators should be `nxml` section ids, not Bookshelf URLs with anchors.
2. **Wiley-hosted EFSA Journal** blocks Tavily, Firecrawl and curl (Cloudflare "Just a moment…", HTTP 403); Crossref has no abstract. EFSA opinions need the Wiley TDM API or a browser; for this run they are not capturable.
3. **AI answer engines (Consensus, Elicit results) are login-walled**; their answers are not capturable sources and are not reproducible artifacts. Their *documentation* is capturable and is used here only to describe their methods.
4. **Examine.com** renders grades and effects as images or client-side widgets; extracted markdown has empty Grade/Effect cells and collapsed FAQ answers; safety and interaction tables are partly paywalled ("Full safety information is available to Examine Clinician Edition members.").
5. **Labdoor** product reviews are JS-rendered (only the overall score is in the extracted text); the ranking list and the scoring-method page are fully capturable.
6. **Open Targets** is the best-shaped association source seen: GraphQL with a release version (`dataVersion`), a per-datatype and per-datasource score breakdown, and markdown method docs. Field renames between releases (`maximumClinicalTrialPhase` → `maximumClinicalStage`) mean a stored query shape must carry the API version.
7. Windows tooling: `tvly` crashes on non-cp1252 characters when printing to the console; native `curl` does not understand Git-Bash paths in `@file` arguments.
