## What broke

- **Firecrawl markdown drift.** Re-scraping 13 pages ~45 minutes after the research captures gave byte-identical markdown for 9 and different bytes for 4, all of them vendor-hosted (TruDiagnostic TruAge, Jinfiniti, WHOOP community thread, InsideTracker blog); the 6 non-vendor pages (Labcorp, Quest, LOINC, NGSP ×2, FDA) were identical. Every quote was still present; the fixtures cite the fresh capture's digest and offsets and record the research-stage digest. A locator on a markdown projection is only as stable as the projection.
- **API documents are not byte-stable either.** WHOOP's OpenAPI JSON returned the same value with a different property order on two fetches (adversarial-review pass); JSON_POINTER locators survive this, raw-byte digests do not.
- **Missed primary source.** The research and fixtures stages inferred WHOOP's HRV method from a field name in an example payload; the OpenAPI document states it. Lesson for the action space: for a vendor API, fetch the machine-readable spec before the rendered page.
- **MCP outputs are not snapshots.** The PubMed MCP full text cannot be stored as hashable bytes; NCBI BioC JSON was fetched with curl as the snapshot.
- **Gated content.** Quest LOINC codes and performing lab require choosing a service area; the comparability verdict is UNKNOWN partly because of this.
- **Image-only content.** InsideTracker's panel composition is published only as an image.
- **Contract gaps** found while writing intents: no `assertionKind`/`claimType` in `AssertionCore`, no assessment proposal kind, no asserter for `edge.structural`, no `derivationRule`; locator `ref` must be lower-case.
- **Repo MCP servers** (pubmed, pubchem, clinicaltrialsgov, edgartools from `.mcp.json`) are not loaded in this session; curl to the public APIs was used instead.

## What needs custom tooling (priority order)

1. **Selector builder + verifier** (P1): derive text by a named, versioned rule (XML → text, PDF → text with pages, markdown), emit `CHARACTER_POSITION`/`PDF_TEXT`/`JSON_POINTER` selectors with exact/prefix/suffix and quoteHash, and re-select on re-capture (prototype: scratch `bin/gen.py`).
2. **Byte-faithful capture** (P1): store raw HTTP bytes beside the Firecrawl markdown so the snapshot digest does not depend on the markdown converter.
3. **Gated-section capture** (P2): Firecrawl interact or a browser profile for service-area selectors (Quest), recorded as a readiness finding when used.
4. **Panel composition extraction** (P2): OCR for image-only biomarker lists, or vendor partnership feeds.
5. **LOINC resolution** (P2): licensed LOINC table or FHIR access to map vendor metric names to LOINC (the RESOLUTION assessment in consumer-panel-and-blood-clock is name-only).
