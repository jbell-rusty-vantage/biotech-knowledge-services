## What was exercised, what broke, what needs custom tooling

- **Exercised in the fixtures stage** (details in `_notes/tool-log.md`, rows F1–F16): NCBI E-utilities (6 PubMed records, 1 PMC JATS), Crossref REST (2 works), Wikidata (entity, pinned revisions), curl raw captures (3 web pages), Internet Archive availability/CDX/raw replay, Firecrawl CLI scrape (1 success, 1 failure), Tavily CLI extract (1 failure), the local verification.v1 benchmark corpus, `@bks/contracts` (7 intents validated). Every research-stage API capture re-fetched byte-identical; the two dynamic web pages did not (token-only differences).
- **Broke:** PubMed web UI (curl challenge page, Firecrawl "All scraping engines failed", Tavily "Error fetching content"); Wayback CDX "Temporarily Offline" (2 of 3); Wayback timestamp redirect; dynamic pages' raw digests unstable. Nothing required the browser fallback.
- **Needs custom tooling (priority P1):** (1) a selector resolver that reports occurrence counts and grows prefix/suffix until unique — verification.v1's `resolved` status requires exactly one occurrence, and two fixture quotes needed 512-character context or element anchoring (the archived page repeats the abstract in two meta tags); (2) snapshot ordering by `coalesce(observedAt, retrievedAt)` for archive captures (03 Q-K-10 / Q-K-17 amended); (3) a retraction watcher over Crossref `updated-by` + PubMed `CommentsCorrections` with one HAS_REVISION_STATUS Assertion per authority; (4) intent kinds for claims, assessments, adjudication ingest and report publication, plus `asserterRef` on `identifier.attach`; (5) the entity-link projection; (6) a canonical-projection hash (Firecrawl markdown or normalized text) beside the raw digest so token-only page changes are recognised as non-content changes.
- **Readiness findings for D11:** E-utilities, Crossref, Wikidata and Bioregistry are agent-ready (3) with byte-stable responses; PubMed's web UI is blocked (0); the Internet Archive is the only route to "what a page said before" and is intermittently unavailable (2); free full text remains per publisher.
