# Open questions: schema candidate v2 (fast-track synthesis, 2026-10-09)

Written by the S team's open-questions stage. It merges every packet's `11-open-questions.md` (K, D1–D13) with the owner decisions of `final/decision-report.md` and the issues the module editors and the integrator raised after the rulings (`final/_runlog/module-*.md`, `integrate.md`). Nothing here is final until the owner accepts it on measurements and fixtures.

How to read an entry:

- **id** is stable for this file. `OD` = decision the owner must make, `KN` = kernel, `EX` = executor (`packages/kg-ops`, `packages/contracts`, capture adapters), `BM` = biotech-meta (ontology-lab backlog), `MD` = a domain module, `FX` = fixture or coverage gap, `FU` / `TL` = synthesis follow-up or tooling that blocks acceptance.
- **owner** is one of owner, kernel, a module id, biotech-meta, executor. "with" names who supplies evidence.
- **status** is `open` or `resolved-in-synthesis` with its ruling id (section 8). An `OD` entry built on a ruling says which option the ruling proposes; it stays open until the owner decides.
- **priority** is computed, not judged: the lowest `value` (in `packets/*/02-questions.md`, R-08 rule for shared ids) among the questions in the **blocks** column. P1 = blocks a value-1 question, P2 = value 2 at best, P3 = value 3 at best, `none` = no packet question is blocked (catalog-only ids are shown but carry no packet value). `gate` = blocks a step of acceptance or re-pin (PLAN 5.5, 03-SYNTHESIS) whatever the question value. Where a packet counted the questions a tooling gap serves (D11 #52), the entry cites that count and takes value 1 if it includes value-1 questions.
- **blocks** lists the questions whose answer is missing, wrong or unverified until the entry is resolved; for an owner decision on a ruling it is the ruling's deciding question.
- **from** lists the packet items merged into the entry (`<packet> <item>`), then any synthesis source.

## 10. How this file was built
