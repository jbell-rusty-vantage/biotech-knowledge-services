## Conventions (final SDL)

The packet macros are written out inline, so each block runs as printed.

- **Parameters.** `$vt` is the valid-time instant and `$rt` the recorded-time instant (default `datetime()`), as in the packet.
- **`REC(e)`** on a recorded-only asserted edge (`AssertedRecordedProperties`, `ComponentLineProperties`): `e.recordedFrom <= $rt AND (e.recordedTo IS NULL OR e.recordedTo > $rt)`.
- **`EP(e)`** on an episode edge (`ContentEdgeProperties` of MATERIAL_CONTAINS, `IdentifierLinkProperties` of HAS_IDENTIFIER): `REC(e)` plus `(e.validFrom IS NULL OR e.validFrom <= $vt) AND (e.validTo IS NULL OR e.validTo > $vt)`.
- **Verbatim text (R-30).** `ComponentLineProperties` no longer has `declaredNameVerbatim` or `formVerbatim`. The printed name and form are qualifiers on the line's own `DECLARES_COMPONENT` Assertion (`d.assertionUid`): `declaredName:<text>` and `form:<text>`, as written in the re-pathed fixtures (`final/fixtures/D10/mg-rankings-criteria-comparison`, `final/fixtures/cross-domain/product-comparison`). They are read with `[q IN decl.qualifiers WHERE q STARTS WITH 'declaredName:' | substring(q, 13)][0]` and `[q IN decl.qualifiers WHERE q STARTS WITH 'form:' | substring(q, 5)][0]`. The locator's `exact` text in TRACE is the authority.
- **Record kind.** Kind columns use `[l IN labels(x) WHERE l <> 'Entity'][0]` instead of `labels(x)[0]`, because the final nodes carry two labels (`IngredientMaterial`, `Entity`) whose order is not guaranteed.
- **TRACE.** The kernel provenance tail (directive 3.10) is kept as a scoped `CALL (…) { … }` subquery: Assertion → `DERIVED_FROM*0..4` to the non-CALCULATED leaves → `HAS_EVIDENCE` → `SourceLocator` ← `HAS_LOCATOR` ← `SourceSnapshot` ← `HAS_SNAPSHOT` ← `Source`, plus the asserter (`ASSERTED_BY`) and the open `Adjudication` that `ASSESSES` the leaf. Inner variables are prefixed `t` so they never shadow outer ones. The subquery aggregates, so a row with no evidence still returns, with an empty list. A row is publishable only when every leaf has a locator and a current `CAPTURE_FIDELITY` adjudication (kernel rule).

*Declared basis of each amount on a label version, and the calculated amounts that follow.* Kind: cypher (retrieved + materialized projection).

- **Ruling: R-30.** D6 `ComponentLineProperties.declaredNameVerbatim` and `.formVerbatim` are removed. The printed name and form move to the line Assertion's qualifiers `declaredName:` and `form:`, and to the locator's exact text.
- **What changed.**
  - `d.declaredNameVerbatim` → the `declaredName:` qualifier of `decl`. `d.formVerbatim` → the `form:` qualifier of `decl`. The packet already matched `decl` (the line's own Assertion, `d.assertionUid`), so no hop is added.
  - The other line fields (`amount`, `unitCode`, `amountReferent`, `massBasis`, `amountBasis`, `lineRole`) are on the final `ComponentLineProperties` unchanged. `dailyValuePercent` and `orderIndex` are added to the output.
  - The packet's TRACE note ("TRACE over `decl.uid` and each `calc.uid`") is written out. The subquery walks each CALCULATED Assertion's `DERIVED_FROM` inputs to the GSRS molecular-weight and authority-relation locators, and the line to its DSLD row locator.
  - `HAS_ACTIVE_MOIETY` and `COUNTS_TOWARD_NUTRIENT` get the `REC` filter that the packet's convention names for them. The packet block left it out.
- **How the question is answered now:** in full. Nothing is lost.

```cypher
// @id CQ-PF-01
// @param rt:datetime
MATCH (lv:LabelVersion {uid: $labelVersionUid})-[d:DECLARES_COMPONENT]->(target)   // D6 asserted line; target IngredientMaterial|Constituent|FoodItem
WHERE d.recordedFrom <= $rt AND (d.recordedTo IS NULL OR d.recordedTo > $rt)
OPTIONAL MATCH (target:IngredientMaterial)-[rs:REALIZES_SUBSTANCE]->(form:ChemicalSubstance)
WHERE rs.recordedFrom <= $rt AND (rs.recordedTo IS NULL OR rs.recordedTo > $rt)
OPTIONAL MATCH (form)-[hm:HAS_ACTIVE_MOIETY]->(moiety:ChemicalSubstance)
WHERE hm.recordedFrom <= $rt AND (hm.recordedTo IS NULL OR hm.recordedTo > $rt)
OPTIONAL MATCH (form)-[cn:COUNTS_TOWARD_NUTRIENT]->(nut:Constituent)
WHERE cn.recordedFrom <= $rt AND (cn.recordedTo IS NULL OR cn.recordedTo > $rt)
// the line's own Assertion: R-30 verbatim qualifiers, and the projection's DERIVED_FROM input for this line
MATCH (decl:Assertion {uid: d.assertionUid})
OPTIONAL MATCH (calc:Assertion {basisKind: 'CALCULATED'})-[:DERIVED_FROM]->(decl)
WHERE calc.recordedTo IS NULL AND (calc)-[:HAS_SUBJECT]->(lv)
WITH lv, d, target, form, moiety, nut, decl,
     collect(DISTINCT calc {.uid, .predicate, value: calc.valueNumber, unit: calc.unitCode, rule: calc.derivationRule}) AS calculated
CALL (decl, calculated) {
  UNWIND [decl.uid] + [c IN calculated | c.uid] AS tu
  MATCH (ta:Assertion {uid: tu})
  MATCH (ta)-[:DERIVED_FROM*0..4]->(tleaf:Assertion) WHERE tleaf.basisKind IS NULL OR tleaf.basisKind <> 'CALCULATED'
  OPTIONAL MATCH (tleaf)-[tev:HAS_EVIDENCE]->(tloc:SourceLocator)<-[:HAS_LOCATOR]-(tsnap:SourceSnapshot)<-[:HAS_SNAPSHOT]-(tsrc:Source)
  OPTIONAL MATCH (tleaf)-[:ASSERTED_BY]->(twho)
  OPTIONAL MATCH (tadj:Adjudication)-[:ASSESSES]->(tleaf) WHERE tadj.recordedTo IS NULL
  RETURN collect(DISTINCT {assertion: ta.uid, rule: ta.derivationRule, leaf: tleaf.uid, status: tleaf.status, asserter: twho.uid,
                           role: tev.role, selectorKind: tloc.selectorKind, exact: tloc.exact, start: tloc.startOffset, end: tloc.endOffset,
                           page: tloc.page, snapshot: tsnap.uid, contentHash: tsnap.contentHash, retrievedAt: tsnap.retrievedAt,
                           source: tsrc.canonicalUri, adjudicationKind: tadj.adjudicationKind, verdict: tadj.verdict}) AS citations
}
RETURN [q IN decl.qualifiers WHERE q STARTS WITH 'declaredName:' | substring(q, 13)][0] AS declaredAs,   // R-30 (was d.declaredNameVerbatim)
       [q IN decl.qualifiers WHERE q STARTS WITH 'form:' | substring(q, 5)][0] AS formAsPrinted,         // R-30 (was d.formVerbatim)
       [l IN labels(target) WHERE l <> 'Entity'][0] AS targetKind, target.uid AS targetUid, target.name AS targetName,
       d.orderIndex AS orderIndex, d.amount AS amount, d.unitCode AS unitCode, d.amountReferent AS amountReferent,
       d.massBasis AS massBasis, d.amountBasis AS amountBasis, d.lineRole AS lineRole, d.dailyValuePercent AS dailyValuePercent,
       form.name AS form, moiety.name AS moiety, nut.name AS nutrient, decl.uid AS declaration, decl.status AS declarationStatus,
       calculated, citations
ORDER BY orderIndex
```

## CQ-ID-03

*Does a declaration name a substance, a material that realizes it, or a constituent the material provides?* Kind: cypher (retrieved).

- **Ruling: R-30.** `ComponentLineProperties.declaredNameVerbatim` is removed. The declared name is the `declaredName:` qualifier of the line Assertion (`d.assertionUid`) and the exact text of its locator.
- **What changed.**
  - A hop to the line Assertion `decl` is added. `d.declaredNameVerbatim` → its `declaredName:` qualifier. The `form:` qualifier is returned too.
  - `labels(t)[0]` → the non-`Entity` label (final nodes carry `Entity` as a second label).
  - The packet's MATERIAL_CONTAINS filter (`recordedTo IS NULL`, `validTo > $vt`) is completed to the packet's own `EP` (recorded at `$rt`, `validFrom <= $vt`).
  - The TRACE note (line, `rs.assertionUid`, each content uid) is written out as a subquery.
- **How the question is answered now:** in full. Nothing is lost.

```cypher
// @id CQ-ID-03
// @param rt:datetime
// @param vt:datetime
MATCH (lv:LabelVersion {uid: $lvUid})-[d:DECLARES_COMPONENT]->(t)
WHERE d.recordedFrom <= $rt AND (d.recordedTo IS NULL OR d.recordedTo > $rt)
MATCH (decl:Assertion {uid: d.assertionUid})                        // R-30: the line's own Assertion holds the verbatim text
OPTIONAL MATCH (t:IngredientMaterial)-[rs:REALIZES_SUBSTANCE]->(s:ChemicalSubstance)
WHERE rs.recordedFrom <= $rt AND (rs.recordedTo IS NULL OR rs.recordedTo > $rt)
OPTIONAL MATCH (t:IngredientMaterial)-[c:MATERIAL_CONTAINS]->(k)
WHERE c.recordedFrom <= $rt AND (c.recordedTo IS NULL OR c.recordedTo > $rt)
  AND (c.validFrom IS NULL OR c.validFrom <= $vt) AND (c.validTo IS NULL OR c.validTo > $vt)
WITH lv, d, t, decl, s, rs,
     collect(DISTINCT CASE WHEN c IS NULL THEN null ELSE
       {target: k.name, targetKind: [l IN labels(k) WHERE l <> 'Entity'][0], kind: c.statementKind, q: c.quantity,
        cmp: c.comparator, unit: c.unitCode, uid: c.assertionUid} END) AS contents
CALL (decl, rs, contents) {
  UNWIND [decl.uid, rs.assertionUid] + [x IN contents | x.uid] AS tu
  WITH tu WHERE tu IS NOT NULL
  MATCH (ta:Assertion {uid: tu})
  OPTIONAL MATCH (ta)-[tev:HAS_EVIDENCE]->(tloc:SourceLocator)<-[:HAS_LOCATOR]-(tsnap:SourceSnapshot)<-[:HAS_SNAPSHOT]-(tsrc:Source)
  OPTIONAL MATCH (ta)-[:ASSERTED_BY]->(twho)
  OPTIONAL MATCH (tadj:Adjudication)-[:ASSESSES]->(ta) WHERE tadj.recordedTo IS NULL
  RETURN collect(DISTINCT {assertion: ta.uid, predicate: ta.predicate, status: ta.status, asserter: twho.uid, role: tev.role,
                           selectorKind: tloc.selectorKind, exact: tloc.exact, snapshot: tsnap.uid, contentHash: tsnap.contentHash,
                           retrievedAt: tsnap.retrievedAt, source: tsrc.canonicalUri,
                           adjudicationKind: tadj.adjudicationKind, verdict: tadj.verdict}) AS citations
}
RETURN [l IN labels(t) WHERE l <> 'Entity'][0] AS declares, t.uid AS declaredUid, t.name AS declaredRecord,
       s.name AS realizes, contents,
       [q IN decl.qualifiers WHERE q STARTS WITH 'declaredName:' | substring(q, 13)][0] AS declaredAs,   // R-30 (was d.declaredNameVerbatim)
       [q IN decl.qualifiers WHERE q STARTS WITH 'form:' | substring(q, 5)][0] AS formAsPrinted,
       d.lineRole AS lineRole, d.assertionUid AS line, rs.assertionUid AS realizesAssertion, citations
ORDER BY d.orderIndex
```

- trace: `citations` covers the label line (`d.assertionUid`; DSLD row), `rs.assertionUid` (DSLD form `uniiCode` / GSRS) and each content `uid` (DSLD notes span).

## CQ-ID-04

*Which identifiers support a substance match, with the authority snapshot, and where do sources disagree?* Kind: cypher (retrieved).

- **Ruling: R-42.** One (scheme, issuer, normalized value) identifies at most one Subjectable, and the executor enforces it (`vocabularies/identifier-schemes.yaml` `rules.uniqueness`; EX-01). Cross-type joins through a shared Identifier are not a modeling pattern. The same (scheme, value) from two issuers is two Identifiers and never establishes identity (`rules.identity`). A bridge or match that BellLabs infers is a `RESOLUTION` or `EQUIVALENCE` Assessment until adjudicated (`rules.bridges`).
- **What changed.** The owner already fixed the direction (`(s)-[:HAS_IDENTIFIER]->(i)`, FU-04 item 1). What remained was the disagreement branch `(other)-[l2:HAS_IDENTIFIER]->(i)`, a join of two holders through one Identifier node. Under R-42 a second current holder of `i` cannot be written, so that branch is removed. The disagreement is read from two records that R-42 keeps:
  1. `sameValueElsewhere`: another Identifier with the same scheme and normalized value but a different issuer, held by another record. This is a value comparison between two Identifier nodes, not a shared-node join. It is reported as an ambiguity to review, never as identity.
  2. `judgments`: the `RESOLUTION` / `EQUIVALENCE` Assessments about `s` (kernel; the executor's `mention.stage` writes a RESOLUTION Assessment when a match is rejected or ambiguous, EX-01). These are the same judgments Q-D1-06 reads.
- The link episode is now read with the full `EP` (valid time at `$vt`) because `IdentifierLinkProperties` is an episode. The packet's `l.isPrimary` and `l.assertionUid` are unchanged. The packet's TRACE over `l.assertionUid` is written out, so the authority snapshot (`contentHash`, `retrievedAt`, record locator) comes back per identifier.
- **How the question is answered now:** in full, with one narrowing. The packet's `alsoAssignedTo` column (same Identifier node on another record) cannot occur under R-42 and is not returned. Same-scheme competing values *on s itself* stay with Q-D1-06. No open question is needed: R-42 and identifier-schemes `rules.identity` / `rules.bridges` decide it.

```cypher
// @id CQ-ID-04
// @param rt:datetime
// @param vt:datetime
MATCH (s:ChemicalSubstance {uid: $sUid})
MATCH (s)-[l:HAS_IDENTIFIER]->(i:Identifier)            // kernel: Subjectable -> Identifier (Identifier.identifies is IN), IdentifierLinkProperties episode
WHERE l.recordedFrom <= $rt AND (l.recordedTo IS NULL OR l.recordedTo > $rt)
  AND (l.validFrom IS NULL OR l.validFrom <= $vt) AND (l.validTo IS NULL OR l.validTo > $vt)
// R-42: i identifies s only. A disagreement is the same (scheme, normalized value) from another issuer, held by another record:
// two Identifier nodes compared by value, reported for review, never identity.
CALL (s, i) {
  OPTIONAL MATCH (other)-[ol:HAS_IDENTIFIER]->(oi:Identifier)
  WHERE oi.scheme = i.scheme AND oi.value = i.value AND oi.issuer <> i.issuer AND other <> s AND ol.recordedTo IS NULL
  RETURN collect(DISTINCT CASE WHEN oi IS NULL THEN null ELSE
           {holder: other.uid, holderKind: [lb IN labels(other) WHERE lb <> 'Entity'][0], issuer: oi.issuer, link: ol.assertionUid} END) AS sameValueElsewhere
}
// TRACE over the identifier link assertion: the authority record and snapshot that assign i to s
CALL (l) {
  OPTIONAL MATCH (ta:Assertion {uid: l.assertionUid})
  OPTIONAL MATCH (ta)-[tev:HAS_EVIDENCE]->(tloc:SourceLocator)<-[:HAS_LOCATOR]-(tsnap:SourceSnapshot)<-[:HAS_SNAPSHOT]-(tsrc:Source)
  OPTIONAL MATCH (ta)-[:ASSERTED_BY]->(twho)
  OPTIONAL MATCH (tadj:Adjudication)-[:ASSESSES]->(ta) WHERE tadj.recordedTo IS NULL
  RETURN collect(DISTINCT CASE WHEN ta IS NULL THEN null ELSE
           {assertion: ta.uid, status: ta.status, asserter: twho.uid, role: tev.role, selectorKind: tloc.selectorKind, exact: tloc.exact,
            snapshot: tsnap.uid, contentHash: tsnap.contentHash, retrievedAt: tsnap.retrievedAt, source: tsrc.canonicalUri,
            adjudicationKind: tadj.adjudicationKind, verdict: tadj.verdict} END) AS authority
}
WITH s, collect({scheme: i.scheme, issuer: i.issuer, value: i.value, normalizationRule: i.normalizationRule, isPrimary: l.isPrimary,
                 link: l.assertionUid, validFrom: l.validFrom, authority: authority, sameValueElsewhere: sameValueElsewhere}) AS identifiers
// RESOLUTION / EQUIVALENCE judgments about s (rejected or disputed matches; R-42 rules.bridges)
CALL (s) {
  OPTIONAL MATCH (asmt:Assessment)-[:ASSESSES]->(s)
  WHERE asmt.assessmentKind IN ['RESOLUTION', 'EQUIVALENCE'] AND asmt.recordedTo IS NULL
  RETURN collect(DISTINCT asmt {.uid, .assessmentKind, .assessmentSubkind, .verdict, .status}) AS judgments
}
RETURN s.uid AS substance, s.name AS name, identifiers, judgments
```

- EXPLAIN: ok on Neo4j 5.26.31 community (1/1 statement); final-SDL static check clean (labels, types, pairs, properties, enum values, predicates)
- trace: `authority` per identifier gives the kernel chain of the HAS_IDENTIFIER Assertion (GSRS `codes[]` JSON_POINTER; PubChem property record; DSLD form `uniiCode`). Each `judgments` entry is an Assessment with its own `HAS_EVIDENCE` locators. `sameValueElsewhere.link` is the other holder's link Assertion, to TRACE on demand.
- index note: on `bks-neo4j-synth` the planner serves `sameValueElsewhere` from the uniqueness constraint `identifier_key` on `Identifier(scheme, issuer, value)`. It seeks on `scheme` only and then filters `value` and `issuer`, so the cost grows with the number of Identifiers in that scheme (for example every UNII). An index on `Identifier(scheme, value)` would make it a point seek. That is DDL for the kernel operations file (EX-01), not an SDL change.
- bitemporal episode needed on: kernel HAS_IDENTIFIER (already an episode).

```cypher
// @id Q-D1-16
// @param vt:datetime
MATCH (p:ProductVariant {uid: $pUid})-[:HAS_PACKAGE]->(:Package)-[:HAS_LABEL_VERSION]->(:LabelVersion)-[:DECLARES_COMPONENT]->(m:IngredientMaterial)
WHERE m.brandName IS NOT NULL
WITH DISTINCT p, m
OPTIONAL MATCH (a:Assertion)-[:HAS_SUBJECT|HAS_OBJECT]->(m)
WHERE a.predicate IN ['MARKETED_UNDER_MARK', 'SUPPLIES_MATERIAL', 'MANUFACTURES']    // R-68: MANUFACTURES_MATERIAL -> MANUFACTURES (D7 set)
  AND a.recordedTo IS NULL
  AND (a.validFrom IS NULL OR a.validFrom <= $vt) AND (a.validTo IS NULL OR a.validTo > $vt)
OPTIONAL MATCH (a)-[:HAS_SUBJECT|HAS_OBJECT]->(org:Organization)                  // mark owner (object), supplier / manufacturer (subject)
CALL (a) {
  OPTIONAL MATCH (a)-[tev:HAS_EVIDENCE]->(tloc:SourceLocator)<-[:HAS_LOCATOR]-(tsnap:SourceSnapshot)<-[:HAS_SNAPSHOT]-(tsrc:Source)
  OPTIONAL MATCH (a)-[:ASSERTED_BY]->(twho)
  OPTIONAL MATCH (tadj:Adjudication)-[:ASSESSES]->(a) WHERE tadj.recordedTo IS NULL
  RETURN collect(DISTINCT CASE WHEN tloc IS NULL AND twho IS NULL THEN null ELSE
           {asserter: twho.uid, role: tev.role, selectorKind: tloc.selectorKind, exact: tloc.exact, snapshot: tsnap.uid,
            contentHash: tsnap.contentHash, retrievedAt: tsnap.retrievedAt, source: tsrc.canonicalUri,
            adjudicationKind: tadj.adjudicationKind, verdict: tadj.verdict} END) AS trace
}
RETURN m.uid AS materialUid, m.brandName AS brandName, m.name AS material,
       a.predicate AS predicate,
       CASE a.predicate WHEN 'MARKETED_UNDER_MARK' THEN 'MARK_OWNER' WHEN 'SUPPLIES_MATERIAL' THEN 'SUPPLIER'
                        WHEN 'MANUFACTURES' THEN 'MANUFACTURER' END AS role,
       org.uid AS organizationUid, org.name AS organization, a.qualifiers AS qualifiers,   // SUPPLIES_MATERIAL: exclusivity=, buyer=
       a.validFrom AS validFrom, a.validTo AS validTo, a.status AS status, a.uid AS assertion, trace
ORDER BY brandName, role, validFrom
```
