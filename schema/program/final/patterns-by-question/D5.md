## Q-D5-13

Which protocol authors or clinics have a financial interest in the means their protocol prescribes, and did that interest change between editions?

- **Rulings that changed it:**
  - **R-80.** One authorship predicate, `AUTHORED_BY`, is registered by D3. Its subject is `Publication | Protocol | ProtocolEdition` and its object is `Person | Organization`. The D5 predicate `PROTOCOL_AUTHORED_BY` is retired (`predicates.yaml`: `alias-of:AUTHORED_BY`, fixtureEdit "re-key").
  - The final pattern also accepts authorship asserted on the current edition, because R-80 admits `ProtocolEdition` as a subject.
  - R-78 (HOLDS_ROLE / HOLDS_STAKE / RECEIVES_VALUE_FROM, Shape B) and R-94 were already applied by the owner.
- **Final-SDL changes against the packet block:**
  - `PROTOCOL_AUTHORED_BY` → `AUTHORED_BY`, with subject Protocol or the current ProtocolEdition.
  - `author` is restricted to `Person | Organization`, the R-80 object types.
  - HAS_EDITION is `AssertedEdgeProperties` in the final SDL, so `recordedFrom` / `recordedTo` / `validFrom` / `validTo` exist unchanged.
  - TRACE of the interest's authorizing Assertion is inlined.
- **How it is answered now:** the same as the packet. No ruling removed a needed element.

```cypher
// @id Q-D5-13
MATCH (p:Protocol {uid: $protocolUid})-[he:HAS_EDITION]->(e:ProtocolEdition)
WHERE he.recordedFrom <= $asOf AND he.recordedTo IS NULL
// R-80: AUTHORED_BY (registrar D3), subject Protocol | ProtocolEdition, object Person | Organization
UNWIND [p, e] AS authored
MATCH (aa:Assertion {predicate: 'AUTHORED_BY'})-[:HAS_SUBJECT]->(authored),
      (aa)-[:HAS_OBJECT]->(author:Person|Organization)
WHERE aa.recordedTo IS NULL
CALL (author, he) {
  // (1) D7 interest episodes (R-78 Shape B): RoleEdgeProperties.roleKind, StakeEdgeProperties.stakeKind,
  //     ValueEdgeProperties.valueKind; an unbounded episode's observation date is the authorizing Assertion's validObservedAt
  MATCH (author)-[i:HOLDS_ROLE|HOLDS_STAKE|RECEIVES_VALUE_FROM]->(org:Organization)
  WHERE i.recordedTo IS NULL
    AND (i.validFrom IS NULL OR he.validTo IS NULL OR i.validFrom < he.validTo)
    AND (i.validTo IS NULL OR he.validFrom IS NULL OR he.validFrom < i.validTo)
  OPTIONAL MATCH (ia:Assertion {uid: i.assertionUid})
  RETURN org, type(i) AS interestType, coalesce(i.roleKind, i.stakeKind, i.valueKind) AS interestKind,
         i.validFrom AS validFrom, i.validTo AS validTo, ia.validObservedAt AS observedAt, i.assertionUid AS assertionUid,
         'POSITIVE' AS polarity
  UNION
  // (2) stated non-interests: NEGATIVE assertions authorize no episode
  MATCH (n:Assertion {polarity: 'NEGATIVE'})-[:HAS_SUBJECT]->(author), (n)-[:HAS_OBJECT]->(org:Organization)
  WHERE n.predicate IN ['HOLDS_ROLE', 'HOLDS_STAKE', 'RECEIVES_VALUE_FROM'] AND n.recordedTo IS NULL
  RETURN org, n.predicate AS interestType, 'DENIED' AS interestKind, n.validFrom AS validFrom, n.validTo AS validTo,
         n.validObservedAt AS observedAt, n.uid AS assertionUid, 'NEGATIVE' AS polarity
}
// means in the edition that the counterparty owns (brand) or sells (seller of record): D6 typed paths
OPTIONAL MATCH (e)-[:HAS_STEP]->(:ProtocolStep)-[:STEP_USES]->(prod:Product)
  WHERE EXISTS { (prod)-[:BRANDED_AS]->(:Brand)<-[:OWNS_BRAND]-(org) }
     OR EXISTS { (prod)-[:HAS_VARIANT]->(:ProductVariant)-[:HAS_PACKAGE]->(:Package)<-[:LISTING_FOR]-(:MerchantListing)
                 -[:HAS_OFFER]->(:Offer)-[:SELLER_OF_RECORD]->(org) }
WITH e, he, aa, author, org, interestType, interestKind, polarity, validFrom, validTo, observedAt, assertionUid,
     collect(DISTINCT prod.name) AS meansOwnedOrSoldByCounterparty
// TRACE(interest Assertion): the disclosure span on the protocol snapshot
OPTIONAL MATCH (ta:Assertion {uid: assertionUid})
CALL (ta) {
  OPTIONAL MATCH (ta)-[ev:HAS_EVIDENCE]->(loc:SourceLocator)<-[:HAS_LOCATOR]-(snap:SourceSnapshot)<-[:HAS_SNAPSHOT]-(src:Source)
  OPTIONAL MATCH (adj:Adjudication)-[:ASSESSES]->(ta)
    WHERE adj.recordedAt <= $asOf AND (adj.recordedTo IS NULL OR adj.recordedTo > $asOf)
  OPTIONAL MATCH (ta)-[:ASSERTED_BY]->(who)
  OPTIONAL MATCH (ta)-[:WAS_GENERATED_BY]->(act:Activity)
  RETURN collect(DISTINCT {assertedBy: who.uid, role: ev.role, locator: loc.uid, exact: loc.exact,
                           contentHash: snap.contentHash, retrievedAt: snap.retrievedAt, uri: src.canonicalUri,
                           verdict: adj.verdict, missionId: act.missionId, runId: act.runId}) AS trace
}
RETURN e.uid AS edition, he.validFrom AS editionFrom, he.validTo AS editionTo, aa.uid AS authorshipAssertion,
       author.name AS author, org.name AS counterparty, interestType, interestKind, polarity, validFrom, validTo,
       observedAt, assertionUid, meansOwnedOrSoldByCounterparty, trace
```

- EXPLAIN: ok on Neo4j 5.26.31 community (1/1 statement); final-SDL static check clean (labels, types, pairs, properties, enum values, predicates)

- trace: TRACE of the interest's authorizing Assertion gives the disclosure locator on the protocol snapshot. TRACE(aa) is the authorship span, e.g. the fixture `D5/pregnancy-magnesium-upper-limit` m02 locators `l02-signature`, `l01-protocol-title`, and it is reached the same way from `aa.uid`. Overlap is computed, and unknown bounds are returned as null (UNKNOWN). Denied interests come back with polarity NEGATIVE and no interval.

## Q-D5-17

Which clinics and telehealth services offer intervention I for target T, with what screening, monitoring and price?

- **Rulings that changed it:**
  - **R-80.** The monitoring program's authorship reads `AUTHORED_BY`, not `PROTOCOL_AUTHORED_BY`.
  - **R-94 (D5) / R-52.** `OFFERS_INTERVENTION` is predicate-only, registered by D6, with subject `Offer | Organization | Product` and object `Intervention`. The typed pair D6.Offer → D5.Intervention is cut. `questions-catalog.md` marks the question **CUT R-94, R-52**, with the predicate route left as `OFFERS_INTERVENTION`.
- **How it is answered now:** by the predicate route. The packet pattern already read `OFFERS_INTERVENTION` as an Assertion, so the cut pair loses nothing.
  - When the Assertion's subject is an `Offer`, the offering organization is that Offer's open `SELLER_OF_RECORD` episode.
  - The price, which the packet only described in a comment ("D6 Offer / PriceObservation"), is now concrete. `PriceObservation` does not exist in the final SDL. A displayed price is a kernel Assertion with subject Offer and predicate `OFFER_PRICE_<KIND>` (registered by D6). Its value is in `valueNumber` and `unitCode` (`iso4217:<CODE>`), and its observation date in `validObservedAt`.
  - Screening and monitoring are unchanged: `USE_CONSTRAINED_IN` asserted by the offerer, and MEASURE steps of a protocol the offerer authored.
- **Not answered:** a price for an offer asserted directly on an Organization or a Product, with no Offer. No final-SDL path joins such a price to the intervention, so those rows return `prices = []`.

```cypher
// @id Q-D5-17
MATCH (i:Intervention {uid: $interventionUid})
// R-94 / R-52: OFFERS_INTERVENTION is predicate-only (registrar D6): subject Offer | Organization | Product
MATCH (o:Assertion {predicate: 'OFFERS_INTERVENTION'})-[:HAS_OBJECT]->(i), (o)-[:HAS_SUBJECT]->(subj:Offer|Organization|Product)
WHERE o.recordedTo IS NULL
OPTIONAL MATCH (subj)-[sr:SELLER_OF_RECORD]->(seller:Organization) WHERE sr.recordedTo IS NULL
WITH i, o, subj, coalesce(seller, subj) AS offerer
OPTIONAL MATCH (tg:Assertion)-[:HAS_SUBJECT]->(i), (tg)-[:HAS_OBJECT]->(t:Target {key: $targetKey})
  WHERE tg.recordedTo IS NULL
OPTIONAL MATCH (c:Assertion {predicate: 'USE_CONSTRAINED_IN'})-[:HAS_SUBJECT]->(i)
  WHERE c.recordedTo IS NULL AND EXISTS { (c)-[:ASSERTED_BY]->(offerer) }
// monitoring: the offerer's program as a Protocol whose current edition has MEASURE steps; R-80 AUTHORED_BY
OPTIONAL MATCH (prog:Protocol)-[he:HAS_EDITION]->(pe:ProtocolEdition)-[:HAS_STEP]->(ms:ProtocolStep {stepKind: 'MEASURE'})
  WHERE he.recordedTo IS NULL
    AND EXISTS { MATCH (prog)<-[:HAS_SUBJECT]-(:Assertion {predicate: 'AUTHORED_BY'})-[:HAS_OBJECT]->(offerer) }
// price: D6 price Assertions on the Offer (OFFER_PRICE_<KIND>; no PriceObservation node in the final SDL)
OPTIONAL MATCH (pr:Assertion)-[:HAS_SUBJECT]->(subj:Offer)
  WHERE pr.predicate STARTS WITH 'OFFER_PRICE_' AND pr.recordedTo IS NULL
WITH i, o, subj, offerer, t, tg, c, ms, pr
CALL (o) {
  OPTIONAL MATCH (o)-[ev:HAS_EVIDENCE]->(loc:SourceLocator)<-[:HAS_LOCATOR]-(snap:SourceSnapshot)<-[:HAS_SNAPSHOT]-(src:Source)
  OPTIONAL MATCH (adj:Adjudication)-[:ASSESSES]->(o)
    WHERE adj.recordedAt <= $asOf AND (adj.recordedTo IS NULL OR adj.recordedTo > $asOf)
  OPTIONAL MATCH (o)-[:ASSERTED_BY]->(who)
  OPTIONAL MATCH (o)-[:WAS_GENERATED_BY]->(act:Activity)
  RETURN collect(DISTINCT {assertedBy: who.uid, role: ev.role, locator: loc.uid, exact: loc.exact,
                           contentHash: snap.contentHash, retrievedAt: snap.retrievedAt, uri: src.canonicalUri,
                           verdict: adj.verdict, missionId: act.missionId, runId: act.runId}) AS offeringTrace
}
RETURN offerer.uid AS offerer, offerer.name AS offererName, labels(subj)[0] AS offeredVia, o.uid AS offeringAssertion,
       collect(DISTINCT tg.predicate) AS targetPredicates,
       collect(DISTINCT c.valueString) AS screeningLevels, collect(DISTINCT c.uid) AS screeningAssertions,
       collect(DISTINCT ms.stepKey) AS monitoring,
       collect(DISTINCT {predicate: pr.predicate, amount: pr.valueNumber, currency: pr.unitCode,
                         observedAt: pr.validObservedAt, assertion: pr.uid}) AS prices,
       offeringTrace
```

- EXPLAIN: ok on Neo4j 5.26.31 community (1/1 statement); final-SDL static check clean (labels, types, pairs, properties, enum values, predicates)

- trace: TRACE(o) is inlined. TRACE(c) and TRACE(pr) are reached the same way from the returned assertion uids. Price rows carry their own observation date (`validObservedAt`) and D6 locator.
- bitemporal episode needed on: none in D5. SELLER_OF_RECORD is a D6 episode (AssertedEdgeProperties), and the current one is read (`recordedTo IS NULL`).

## Q-D5-20

Do reported adverse effects of X overlap with worsening of the very target X is used for (e.g. insomnia reports for a sleep aid), and how does the source frame causality?

- **Rulings that changed it:**
  - **R-42.** One (scheme, issuer, normalized value) identifies at most one Subjectable. Cross-type joins through a shared Identifier are not a modeling pattern, so the packet's join `(effect)-[:HAS_IDENTIFIER]->(id)<-[:HAS_IDENTIFIER]-(measure)` (OQ-D5-45) is ruled out.
  - **R-70.** The condition-to-target join becomes a typed member. `union TargetMeasure = Biomarker | Metric | Outcome | Condition`, and `Target -OPERATIONALIZED_BY-> Condition` means "incidence of this condition measures the target". The direction of the measure lives in D5's vocab-targets rule. R-70 says "Q-D5-20 (v3) uses the same join".
- **How it is answered now:** the adverse-effect Condition must itself be an OPERATIONALIZED_BY member of the target that X is intended for or claimed to improve. OPERATIONALIZED_BY is `AssertedRecordedProperties`, so its open episode is read.
  - The causality framing is read from CAUTIONS-speech-act Assertions evidenced on the same source snapshot as the adverse-effect report, such as CAERS or FAERS disclaimers.
- **Narrowed:** an effect Condition that relates to the target only through an Outcome, Metric or Biomarker returns no row. No typed Condition → Outcome edge exists (OQ-D5-45, closed by R-42 / R-70), and the shared-Identifier route is ruled out. Such rows need a curated `Target -OPERATIONALIZED_BY-> Condition` episode. `targets.yaml` `relatedConditions` are names only and are not traversed.
  - The fixture for this pair is still requested under R-70 / R-06 (ASPREE hemorrhage or dementia → a target).
  - The question is not lost: rows exist exactly where the target's Condition measures are curated.

```cypher
// @id Q-D5-20
MATCH (x:Subjectable {uid: $xUid})
MATCH (ai:Assertion)-[:HAS_SUBJECT]->(x), (ai)-[:HAS_OBJECT]->(t:Target)
WHERE ai.predicate IN ['INTENDED_FOR_TARGET', 'IMPROVES_TARGET'] AND ai.recordedTo IS NULL
MATCH (ae:Assertion {predicate: 'CAUSES_ADVERSE_EFFECT'})-[:HAS_SUBJECT]->(x), (ae)-[:HAS_OBJECT]->(effect:Condition)
WHERE ae.recordedTo IS NULL
// R-70: Condition is a TargetMeasure member; R-42: no join through a shared Identifier
MATCH (t)-[op:OPERATIONALIZED_BY]->(effect)
WHERE op.recordedTo IS NULL
CALL (ae) {
  // TRACE(ae) + the causality framing: CAUTIONS assertions evidenced on the same snapshot as the report
  OPTIONAL MATCH (ae)-[ev:HAS_EVIDENCE]->(loc:SourceLocator)<-[:HAS_LOCATOR]-(snap:SourceSnapshot)<-[:HAS_SNAPSHOT]-(src:Source)
  OPTIONAL MATCH (adj:Adjudication)-[:ASSESSES]->(ae)
    WHERE adj.recordedAt <= $asOf AND (adj.recordedTo IS NULL OR adj.recordedTo > $asOf)
  OPTIONAL MATCH (ae)-[:ASSERTED_BY]->(who)
  OPTIONAL MATCH (ae)-[:WAS_GENERATED_BY]->(act:Activity)
  OPTIONAL MATCH (cv:Assertion {speechAct: 'CAUTIONS'})-[:HAS_EVIDENCE]->(cloc:SourceLocator)<-[:HAS_LOCATOR]-(snap)
    WHERE cv.recordedTo IS NULL
  RETURN collect(DISTINCT {assertedBy: who.uid, role: ev.role, locator: loc.uid, exact: loc.exact,
                           contentHash: snap.contentHash, retrievedAt: snap.retrievedAt, uri: src.canonicalUri,
                           verdict: adj.verdict, missionId: act.missionId, runId: act.runId}) AS trace,
         collect(DISTINCT {assertion: cv.uid, exact: cloc.exact}) AS causalityCaveats
}
RETURN t.key AS target, ai.predicate AS intendedVia, effect.name AS adverseEffect, op.assertionUid AS measureAssertion,
       ae.valueString AS frequencyOrCount, ae.qualifiers AS qualifiers, ae.uid AS adverseEffectAssertion,
       trace, causalityCaveats
```

- EXPLAIN: ok on Neo4j 5.26.31 community (1/1 statement); final-SDL static check clean (labels, types, pairs, properties, enum values, predicates)

- trace: TRACE(ae) is inlined, with the causality-caveat locators. The target-measure link carries its authorizing Assertion (`op.assertionUid`). Report counts appear only as values of the adverse-effect Assertion (input only) with the publisher's causality caveat.
- bitemporal episode needed on: none. OPERATIONALIZED_BY is recorded-only (AssertedRecordedProperties).
