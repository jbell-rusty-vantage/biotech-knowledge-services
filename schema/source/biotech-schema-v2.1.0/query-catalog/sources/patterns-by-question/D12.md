## Conventions (final SDL)

- **AS_OF** is written out inline, as the packet defines it. On an asserted edge `r` it reads `r.recordedFrom <= $asOf AND (r.recordedTo IS NULL OR r.recordedTo > $asOf)`, plus the optional valid-time point `$validAt` on edges that carry valid time. An Assertion uses `recordedAt` in place of `recordedFrom`.
- **Verbatim text (R-30).** `ComponentLineProperties` has no `declaredNameVerbatim`, `formVerbatim` or `statementVerbatim`. The verbatim line text is on the line's own `DECLARES_COMPONENT` Assertion (`dc.assertionUid`), in the qualifiers `declaredName:`, `form:` and `statement:`, and in the exact text of its locator. The fixtures write the prefixes both with and without a space after the colon (`statement: numerator 1 mg …` in `fixtures/D11/sirolimus-spl-boxed-warning`, `statement:NR - TMG …` in `fixtures/cross-domain/product-comparison`), so the value is read with `trim(substring(q, <prefix length>))`.
- **TRACE.** A scoped `CALL (decl) { … }` subquery over the line Assertion (inner variables prefixed `t`), as in the packet's TRACE macro.

## Q-D12-18

*Does a product's declared composition meet the regulatory condition of the health claim it implies?* Kind: assessment (stored kernel Assessment, subkind `D12.claim-threshold-comparison`, conclusionCode MET | NOT_MET | NOT_COMPARABLE), with this query as its input reader.

- **Ruling: R-30.** D6 `ComponentLineProperties.statementVerbatim` is removed. The verbatim line text moves to the line Assertion's `statement:` qualifier and to the locator's exact text.
- **What changed.**
  - A hop to the line Assertion `decl` (`dc.assertionUid`) is added. `dc.statementVerbatim` becomes its `statement:` qualifier, and the `declaredName:` qualifier is returned next to it. A full TRACE of `decl` is returned.
  - The claim condition is bound to the claim being tested. The packet matched every `HAS_CLAIM_CONDITION` Assertion in the graph with no link to the product, a cross product, and read the regulated measurand through `HAS_OBJECT`. In the final registry `HAS_CLAIM_CONDITION` (registrar D8, R-93) is a literal predicate with no object type. Its subject is the authorizing RegulatoryRecord, or the kernel Claim for a product-class condition (`fixtures/D10/fda-qhc-magnesium-disconfirmation` a-350-condition). The condition and the measurand it names are in `valueNumber`, `unitCode`, `valueString` and the qualifiers. So the rewrite takes `$conditionSubjectUids` (the RegulatoryRecord or Claim uids of the implied claim) and reads the condition from those fields.
  - `AS_OF` is written out on `HAS_LABEL_VERSION` (valid time) and on `DECLARES_COMPONENT` (recorded time only).
  - The Assessment's inputs are kept as uids.
- **How the question is answered now:** in full. The packet's `regulatedMeasurand` column (the condition's HAS_OBJECT node) is replaced by the condition's own value fields, which name the measurand as the source states it. Nothing the fixtures record is lost.

```cypher
// @id Q-D12-18
// @param asOf:datetime
// @param validAt:datetime
// @param measurandUids:strings
// @param conditionSubjectUids:strings
MATCH (p:Product {uid: $productUid})-[:HAS_VARIANT]->(:ProductVariant)-[:HAS_PACKAGE]->(:Package)-[lve:HAS_LABEL_VERSION]->(lv:LabelVersion)
WHERE lve.recordedFrom <= $asOf AND (lve.recordedTo IS NULL OR lve.recordedTo > $asOf)
  AND ($validAt IS NULL OR ((lve.validFrom IS NULL OR lve.validFrom <= $validAt) AND (lve.validTo IS NULL OR lve.validTo > $validAt)))
MATCH (lv)-[dc:DECLARES_COMPONENT]->(c)                                        // D6 ComponentLineProperties: amount, unitCode, amountBasis
WHERE c.uid IN $measurandUids AND dc.recordedFrom <= $asOf AND (dc.recordedTo IS NULL OR dc.recordedTo > $asOf)
MATCH (decl:Assertion {uid: dc.assertionUid})                                  // R-30: the line's own Assertion holds the verbatim text
// the regulatory condition of the implied claim (D8 HAS_CLAIM_CONDITION, R-93; literal, subject RegulatoryRecord or kernel Claim)
CALL (lv) {
  OPTIONAL MATCH (cond:Assertion {predicate: 'HAS_CLAIM_CONDITION'})-[:HAS_SUBJECT]->(cs)
  WHERE cs.uid IN $conditionSubjectUids AND cond.recordedAt <= $asOf AND (cond.recordedTo IS NULL OR cond.recordedTo > $asOf)
  RETURN collect(DISTINCT CASE WHEN cond IS NULL THEN null ELSE
           {condition: cond.uid, subject: cs.uid, subjectKind: [l IN labels(cs) WHERE l <> 'Entity'][0], value: cond.valueNumber,
            unit: cond.unitCode, statedAs: cond.valueString, qualifiers: cond.qualifiers, validFrom: cond.validFrom} END) AS conditions
}
OPTIONAL MATCH (ass:Assessment {assessmentSubkind: 'D12.claim-threshold-comparison'})-[:ASSESSES]->(p)
WHERE ass.recordedTo IS NULL
OPTIONAL MATCH (ass)-[:DERIVED_FROM]->(input:Assertion)
WITH p, lv, c, dc, decl, conditions, ass, collect(DISTINCT input.uid) AS inputs
CALL (decl) {
  OPTIONAL MATCH (decl)-[tev:HAS_EVIDENCE]->(tloc:SourceLocator)<-[:HAS_LOCATOR]-(tsnap:SourceSnapshot)<-[:HAS_SNAPSHOT]-(tsrc:Source)
  WHERE tev.role IN ['SUPPORTS', 'QUALIFIES']
  OPTIONAL MATCH (decl)-[:ASSERTED_BY]->(twho)
  OPTIONAL MATCH (tadj:Adjudication {adjudicationKind: 'CAPTURE_FIDELITY'})-[:ASSESSES]->(decl) WHERE tadj.recordedTo IS NULL
  RETURN collect(DISTINCT CASE WHEN tloc IS NULL THEN null ELSE
           {assertion: decl.uid, asserter: twho.uid, role: tev.role, selectorKind: tloc.selectorKind, exact: tloc.exact, page: tloc.page,
            contentHash: tsnap.contentHash, retrievedAt: tsnap.retrievedAt, source: tsrc.uid, verdict: tadj.verdict} END) AS trace
}
RETURN lv.uid AS labelVersion, c.uid AS declaredMeasurandUid, c.name AS declaredMeasurand,
       dc.amount AS amount, dc.unitCode AS unitCode, dc.amountBasis AS amountBasis,
       [q IN decl.qualifiers WHERE q STARTS WITH 'statement:' | trim(substring(q, 10))][0] AS statementAsPrinted,   // R-30 (was dc.statementVerbatim)
       [q IN decl.qualifiers WHERE q STARTS WITH 'declaredName:' | trim(substring(q, 13))][0] AS declaredAs,
       conditions, ass.uid AS assessment, ass.conclusionCode AS conclusionCode, ass.rationale AS rationale, inputs, trace
```

## OD-10-option-a

*Not a question section.* These two statements are what Q-D12-03 and Q-D12-06 would read if the owner chooses **option (a)** of R-95 (OD-10). Under that option the FDA survey row acr-03 is re-keyed from `QualityResult -QUALITY_RESULT_FOR-> Product` to the D1 predicate `MEASURED_CONTENT_IN_PRODUCT`: a registered relationship-kind predicate, subject `Product | ProductVariant`, object `ChemicalSubstance`, with the value on the Assertion. They are validated so the owner can weigh option (a) against option (b), reinstating the Product member, which changes the SDL. The questions catalog does not count them: the section id is not a question id, and `fixtures/D12/acrylamide-fried-potato-harm` acr-03 is still written the option (b) way (FU-03 / OD-10).

What both drafts read:
- A lot-identified measurement is a D8 QualityResult: `(qr)-[:QUALITY_RESULT_FOR]->(:Lot)-[:LOT_OF]->(product)` (R-73).
- A survey row that names no lot is a current `MEASURED_CONTENT_IN_PRODUCT` Assertion (R-73's fallback).
- The sampling window is the valid time of the Assertion that authorizes the row.

```cypher
// @id Q-D12-03#option-a
// @param asOf:datetime
// @param validAt:datetime
// @param prep:string
MATCH (h:Assertion {predicate: 'FORMS_DURING_PREPARATION'})-[:HAS_SUBJECT]->(cmp:ChemicalSubstance)
MATCH (h)-[:HAS_OBJECT]->(food)                                                    // FoodItem | FoodCategory
WHERE h.recordedAt <= $asOf AND (h.recordedTo IS NULL OR h.recordedTo > $asOf)
  AND ($prep IS NULL OR ('preparationMethod:' + $prep) IN h.qualifiers)
CALL (cmp) {
  // lot-identified results (D8, R-73)
  MATCH (qr:QualityResult)-[ma:MEASURES_ANALYTE]->(cmp)
  MATCH (qr)-[rf:QUALITY_RESULT_FOR]->(lot:Lot)-[lo:LOT_OF]->(p)
  WHERE ma.recordedTo IS NULL AND rf.recordedTo IS NULL AND lo.recordedTo IS NULL
  MATCH (rfa:Assertion {uid: rf.assertionUid})
  RETURN p, 'LOT_RESULT' AS basis, qr.value AS value, qr.unitCode AS unit, qr.reportingLimit AS reportingLimit,
         lot.lotCode AS lot, rfa.validFrom AS sampledFrom, rfa.validTo AS sampledTo, rfa.uid AS cites
  UNION
  // survey row with no lot (D1 MEASURED_CONTENT_IN_PRODUCT, R-73 fallback; OD-10 option a)
  MATCH (m:Assertion {predicate: 'MEASURED_CONTENT_IN_PRODUCT'})-[:HAS_OBJECT]->(cmp)
  WHERE m.recordedTo IS NULL AND m.status <> 'REJECTED'
  MATCH (m)-[:HAS_SUBJECT]->(p)
  RETURN p, 'SURVEY_ROW' AS basis, m.valueNumber AS value, m.unitCode AS unit,
         toFloat([q IN m.qualifiers WHERE q STARTS WITH 'reportingLimit:' | trim(substring(q, 15))][0]) AS reportingLimit,
         null AS lot, m.validFrom AS sampledFrom, m.validTo AS sampledTo, m.uid AS cites
}
OPTIONAL MATCH (p)-[hr:HAS_REFERENCE_FOOD]->(fi:FoodItem)
WHERE hr.recordedFrom <= $asOf AND (hr.recordedTo IS NULL OR hr.recordedTo > $asOf)
  AND ($validAt IS NULL OR ((hr.validFrom IS NULL OR hr.validFrom <= $validAt) AND (hr.validTo IS NULL OR hr.validTo > $validAt)))
WITH h, cmp, food, collect(DISTINCT {product: p.uid, productName: p.name, basis: basis, value: value, unit: unit, reportingLimit: reportingLimit,
                                     lot: lot, sampledFrom: sampledFrom, sampledTo: sampledTo, cites: cites, referenceFood: fi.descriptionVerbatim}) AS levels
OPTIONAL MATCH (hz:Assertion {predicate: 'CAUSES_ADVERSE_EFFECT'})-[:HAS_SUBJECT]->(cmp)
WHERE hz.recordedAt <= $asOf AND (hz.recordedTo IS NULL OR hz.recordedTo > $asOf)
OPTIONAL MATCH (hz)-[:HAS_OBJECT]->(effect)
RETURN cmp.name AS compound, [l IN labels(food) WHERE l <> 'Entity'][0] AS formedIn, food.name AS food, h.uid AS formation,
       [q IN h.qualifiers WHERE q STARTS WITH 'preparationMethod:'] AS preparation, levels,
       collect(DISTINCT CASE WHEN hz IS NULL THEN null ELSE {effect: effect.name, qualifiers: hz.qualifiers, assertion: hz.uid} END) AS hazard;

// @id Q-D12-06#option-a
// @param asOf:datetime
// @param contaminantUids:strings
// @param contaminants:strings
CALL () {
  MATCH (qr:QualityResult)-[:MEASURES_ANALYTE]->(an)
  WHERE an.uid IN $contaminantUids OR qr.analyteVerbatim IN $contaminants
  MATCH (qr)-[rf:QUALITY_RESULT_FOR]->(lot:Lot)-[lo:LOT_OF]->(p)
  WHERE rf.recordedTo IS NULL AND lo.recordedTo IS NULL
  RETURN p, an, 'LOT_RESULT' AS basis, qr.value AS value, qr.unitCode AS unit, toString(qr.sampleKind) AS sampleKind, lot.lotCode AS lot, qr.uid AS cites
  UNION
  MATCH (m:Assertion {predicate: 'MEASURED_CONTENT_IN_PRODUCT'})-[:HAS_OBJECT]->(an:ChemicalSubstance)
  WHERE an.uid IN $contaminantUids AND m.recordedTo IS NULL AND m.status <> 'REJECTED'
  MATCH (m)-[:HAS_SUBJECT]->(p)
  RETURN p, an, 'SURVEY_ROW' AS basis, m.valueNumber AS value, m.unitCode AS unit, null AS sampleKind, null AS lot, m.uid AS cites
}
WITH p, an, basis, value, unit, sampleKind, lot, cites,
     CASE WHEN p:Product THEN p ELSE COLLECT { MATCH (pv:ProductVariant)<-[:HAS_VARIANT]-(vp:Product) WHERE pv = p RETURN vp }[0] END AS prod   // a ProductVariant row reports under its Product
OPTIONAL MATCH (org:Organization)-[ob:OWNS_BRAND]->(:Brand)<-[ba:BRANDED_AS]-(prod)
WHERE ob.recordedTo IS NULL AND ba.recordedTo IS NULL
OPTIONAL MATCH (prod)-[hr:HAS_REFERENCE_FOOD]->(f:FoodItem)
WHERE hr.recordedFrom <= $asOf AND (hr.recordedTo IS NULL OR hr.recordedTo > $asOf)
OPTIONAL MATCH (lvl:Assertion {predicate: 'HAS_ACTION_LEVEL'})-[:HAS_SUBJECT]->(an) WHERE lvl.recordedTo IS NULL
RETURN p.uid AS product, p.name AS productName, org.name AS brandOwner, f.descriptionVerbatim AS referenceFood, an.name AS contaminant,
       basis, value, unit, sampleKind, lot, cites,
       collect(DISTINCT CASE WHEN lvl IS NULL THEN null ELSE {level: lvl.valueNumber, unit: lvl.unitCode, authorityAndStatus: lvl.qualifiers, assertion: lvl.uid} END) AS referenceLevels
```
