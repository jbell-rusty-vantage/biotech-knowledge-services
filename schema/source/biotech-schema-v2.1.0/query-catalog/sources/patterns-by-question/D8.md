## CQ-MF-01

Who manufactures, supplies, contract-manufactures, or only markets ingredient or product X, according to which source and when? (investor, value 1)

- **Rulings that changed it:**
  - **R-68.** Manufacturer, supplier and distributor roles stay predicate-only under one set registered by D7: MANUFACTURES (Organization → Product | IngredientMaterial), CONTRACT_MANUFACTURES_FOR (Organization → Organization, qualifier `product=`), SUPPLIES_MATERIAL (Organization → IngredientMaterial, qualifiers `exclusivity=SOLE|NON_EXCLUSIVE|UNSTATED` and `buyer=`), MANUFACTURER_UNNAMED (literal on the brand owner, qualifier `manufacturingKind=`), DISTRIBUTES (moved from D8, for distributor statements that do not come from a label). D8 SUPPLIES_INGREDIENT and EXCLUSIVE_SUPPLIER_OF are retired into SUPPLIES_MATERIAL (`exclusivity=SOLE` for the latter). A label's distributor is the D6 typed edge NAMES_RESPONSIBLE_PARTY.
- **Final-SDL changes against the packet block:**
  - predicate list `MANUFACTURES, CONTRACT_MANUFACTURES_FOR, SUPPLIES_INGREDIENT, EXCLUSIVE_SUPPLIER_OF, DISTRIBUTES` → `MANUFACTURES, SUPPLIES_MATERIAL, DISTRIBUTES` with X as object;
  - CONTRACT_MANUFACTURES_FOR no longer has X as object: it is found through X's brand owner (the client Organization, the Assertion's object) and kept when its `product=` qualifier names X or names no product (flagged `productScoped`);
  - added MANUFACTURER_UNNAMED (fixture `D7/niagen-ownership-brand-history` n-20: "third-party, FDA-registered contract manufacturers … (unnamed)"; never a node) and the label's NAMES_RESPONSIBLE_PARTY (role in `LabelVersion.responsiblePartyRole`);
  - `exclusivity=` / `buyer=` / `manufacturingKind=` / `product=` qualifiers returned; TRACE inlined.
- **How it is answered now:** as the packet, with the R-68 names; no needed element was removed.

```cypher
// @id CQ-MF-01
// $uid = X (a D6 Product or a D1 IngredientMaterial); $V = valid time; $R = recorded time (default now)
MATCH (x {uid: $uid}) WHERE x:Product OR x:IngredientMaterial
CALL (x) {
  // R-68 (D7 set): MANUFACTURES -> Product | IngredientMaterial; SUPPLIES_MATERIAL -> IngredientMaterial; DISTRIBUTES -> Product
  MATCH (a:Assertion)-[:HAS_OBJECT]->(x)
  WHERE a.predicate IN ['MANUFACTURES', 'SUPPLIES_MATERIAL', 'DISTRIBUTES']
  RETURN a
  UNION
  // R-68: CONTRACT_MANUFACTURES_FOR is Organization -> client Organization; the product is the qualifier product=<uid>
  MATCH (x)-[:BRANDED_AS]->(:Brand)<-[:OWNS_BRAND]-(:Organization)<-[:HAS_OBJECT]-(a:Assertion {predicate: 'CONTRACT_MANUFACTURES_FOR'})
  RETURN a
  UNION
  // R-68: MANUFACTURER_UNNAMED, the brand owner's statement that its makers are unnamed (an explicit unknown, never a node)
  MATCH (x)-[:BRANDED_AS]->(:Brand)<-[:OWNS_BRAND]-(:Organization)<-[:HAS_SUBJECT]-(a:Assertion {predicate: 'MANUFACTURER_UNNAMED'})
  RETURN a
  UNION
  // R-68: a label's distributor / manufacturer line is the D6 typed edge NAMES_RESPONSIBLE_PARTY (its authorizing Assertion)
  MATCH (x)-[:HAS_VARIANT]->(:ProductVariant)-[:HAS_PACKAGE]->(:Package)-[:HAS_LABEL_VERSION]->(:LabelVersion)
        -[n:NAMES_RESPONSIBLE_PARTY]->(:Organization)
  WHERE n.recordedTo IS NULL
  MATCH (a:Assertion {uid: n.assertionUid})
  RETURN a
}
WITH x, a
WHERE a.recordedTo IS NULL
  AND (a.validFrom IS NULL OR a.validFrom <= $V) AND (a.validTo IS NULL OR $V < a.validTo)
OPTIONAL MATCH (a)-[:HAS_SUBJECT]->(subj)
OPTIONAL MATCH (a)-[:HAS_OBJECT]->(obj)
OPTIONAL MATCH (a)-[:HAS_SUBJECT]->(lv:LabelVersion)
WITH x, a, subj, obj, lv,
     [q IN coalesce(a.qualifiers, []) WHERE q STARTS WITH 'exclusivity=' OR q STARTS WITH 'buyer='
        OR q STARTS WITH 'manufacturingKind=' OR q STARTS WITH 'product='] AS roleQualifiers,
     [q IN coalesce(a.qualifiers, []) WHERE q STARTS WITH 'product='] AS productQualifiers
WHERE a.predicate <> 'CONTRACT_MANUFACTURES_FOR' OR size(productQualifiers) = 0
   OR any(q IN productQualifiers WHERE q STARTS WITH 'product=' + x.uid)
// TRACE(a): the 10-K sentence, GRAS letter manufacturing paragraph, recall recalling_firm field, label panel line
CALL (a) {
  OPTIONAL MATCH (a)-[ev:HAS_EVIDENCE]->(loc:SourceLocator)<-[:HAS_LOCATOR]-(snap:SourceSnapshot)<-[:HAS_SNAPSHOT]-(src:Source)
  OPTIONAL MATCH (adj:Adjudication)-[:ASSESSES]->(a)
    WHERE adj.recordedAt <= $R AND (adj.recordedTo IS NULL OR adj.recordedTo > $R)
  OPTIONAL MATCH (a)-[:ASSERTED_BY]->(who)
  OPTIONAL MATCH (a)-[:WAS_GENERATED_BY]->(act:Activity)
  RETURN who.name AS asserter,
         collect(DISTINCT {role: ev.role, locator: loc.uid, exact: loc.exact, contentHash: snap.contentHash,
                           retrievedAt: snap.retrievedAt, uri: src.canonicalUri, verdict: adj.verdict,
                           missionId: act.missionId, runId: act.runId}) AS trace
}
RETURN a.predicate AS role,
       CASE WHEN lv IS NOT NULL THEN obj.name ELSE subj.name END AS party,
       CASE WHEN a.predicate = 'CONTRACT_MANUFACTURES_FOR' THEN obj.name END AS contractClient,
       CASE WHEN a.predicate = 'CONTRACT_MANUFACTURES_FOR' THEN size(productQualifiers) > 0 END AS productScoped,
       lv.responsiblePartyRole AS labelRole,
       CASE WHEN a.predicate = 'MANUFACTURER_UNNAMED' THEN a.valueString END AS unnamedPartyText,
       roleQualifiers, asserter, a.validFrom, a.validTo, a.validObservedAt, a.uid AS assertionUid, trace
// also: recall / warning-letter addressees of X (RegulatoryRecord -ADDRESSED_TO-> Organization) as "named by the regulator" evidence
```

```cypher
// @id Q-D8-10
// $ingredientUid = the D1 IngredientMaterial X; $V = valid time; $R = recorded time
MATCH (m:IngredientMaterial {uid: $ingredientUid})
CALL (m) {
  MATCH (s:Assertion {predicate: 'SUPPLIES_MATERIAL'})-[:HAS_OBJECT]->(m)
  WHERE s.recordedTo IS NULL
  MATCH (s)-[:HAS_SUBJECT]->(o:Organization)
  RETURN count(DISTINCT o) AS supplierCount
}
// R-68: SUPPLIES_MATERIAL (Organization -> IngredientMaterial), qualifiers exclusivity= and buyer=
MATCH (a:Assertion {predicate: 'SUPPLIES_MATERIAL'})-[:HAS_OBJECT]->(m)
WHERE a.recordedTo IS NULL
MATCH (a)-[:HAS_SUBJECT]->(sup:Organization)
WITH m, supplierCount, a, sup,
     head([q IN coalesce(a.qualifiers, []) WHERE q STARTS WITH 'exclusivity=']) AS exclusivity,
     head([q IN coalesce(a.qualifiers, []) WHERE q STARTS WITH 'buyer=']) AS buyer
// R-73: a Patent CONCERNS a ChemicalSubstance (CONCERNS Patent -> IngredientMaterial cut); AS_OF on the ASSIGNED_TO episode
OPTIONAL MATCH (m)-[:REALIZES_SUBSTANCE]->(:ChemicalSubstance)<-[:CONCERNS]-(pt:Patent)-[h:ASSIGNED_TO]->(sup)
  WHERE (h.validFrom IS NULL OR h.validFrom <= $V) AND (h.validTo IS NULL OR $V < h.validTo)
    AND h.recordedFrom <= $R AND (h.recordedTo IS NULL OR $R < h.recordedTo)
WITH m, supplierCount, a, sup, exclusivity, buyer,
     collect(DISTINCT CASE WHEN pt IS NOT NULL THEN {patent: pt.office + pt.publicationNumber + coalesce(pt.kindCode, ''),
                                                      expiresAt: pt.expiresAt, assignmentAssertion: h.assertionUid} END) AS supplierPatents
// TRACE(a): the 10-K risk-factor sentence (its exact text is the verbatim risk statement)
CALL (a) {
  OPTIONAL MATCH (a)-[ev:HAS_EVIDENCE]->(loc:SourceLocator)<-[:HAS_LOCATOR]-(snap:SourceSnapshot)<-[:HAS_SNAPSHOT]-(src:Source)
  OPTIONAL MATCH (adj:Adjudication)-[:ASSESSES]->(a)
    WHERE adj.recordedAt <= $R AND (adj.recordedTo IS NULL OR adj.recordedTo > $R)
  OPTIONAL MATCH (a)-[:ASSERTED_BY]->(who)
  OPTIONAL MATCH (a)-[:WAS_GENERATED_BY]->(act:Activity)
  RETURN who.name AS asserter,
         collect(DISTINCT {role: ev.role, exact: loc.exact, contentHash: snap.contentHash, publishedAt: snap.publishedAt,
                           retrievedAt: snap.retrievedAt, uri: src.canonicalUri, verdict: adj.verdict,
                           missionId: act.missionId, runId: act.runId}) AS trace
}
RETURN m.name AS ingredient, supplierCount, sup.name AS supplier, exclusivity, buyer,
       exclusivity STARTS WITH 'exclusivity=SOLE' AS soleSource,
       a.validTo AS termEnd, a.validToBasis, a.validObservedAt AS statedAsOf, a.proposition,
       supplierPatents, asserter, a.uid AS assertionUid, trace
```

## Q-D8-13

When does the protection around ingredient X end: latest relevant patent expiry, regulatory data-protection end date, exclusive-supply term? (investor, value 2)

- **Rulings that changed it:**
  - **R-68.** EXCLUSIVE_SUPPLIER_OF is retired: an exclusive supply term is SUPPLIES_MATERIAL with the qualifier `exclusivity=SOLE`; its end is the Assertion's `validTo`.
  - Applied alongside: **R-73** (Patent CONCERNS a ChemicalSubstance only): when X is an IngredientMaterial the patent leg goes through `REALIZES_SUBSTANCE`; when X is a ChemicalSubstance the supply leg goes through the materials that realize it (SUPPLIES_MATERIAL objects are IngredientMaterials).
- **Final-SDL changes against the packet block:** `Assertion {predicate:'EXCLUSIVE_SUPPLIER_OF'}` → SUPPLIES_MATERIAL filtered on `exclusivity=SOLE`; X may be the material or the substance; the EXCLUSIVITY standing is read on X and on its substance (LegalStatusSubject = ChemicalSubstance | IngredientMaterial | Product | Patent); patent PATENT_EXPIRED / PATENT_LAPSED statuses returned beside `expiresAt`; TRACE kept as assertion uids per row.
- **How it is answered now:** as the packet; no needed element was removed.

```cypher
// @id Q-D8-13
// $ingredientUid = X (a D1 IngredientMaterial or ChemicalSubstance); $V = valid time; $R = recorded time
MATCH (x {uid: $ingredientUid}) WHERE x:IngredientMaterial OR x:ChemicalSubstance
OPTIONAL MATCH (x)-[:REALIZES_SUBSTANCE]->(xs:ChemicalSubstance)
WITH x, collect(DISTINCT xs) AS realized
OPTIONAL MATCH (xm:IngredientMaterial)-[:REALIZES_SUBSTANCE]->(x)
WITH x, realized, collect(DISTINCT xm) AS realizers
WITH x, CASE WHEN x:ChemicalSubstance THEN [x] ELSE realized END AS substances,
        CASE WHEN x:IngredientMaterial THEN [x] ELSE realizers END AS materials
// patents (R-73: CONCERNS -> ChemicalSubstance), with their expiry or lapse statuses as of V
CALL (substances) {
  UNWIND substances AS cs
  MATCH (pt:Patent)-[:CONCERNS]->(cs)
  OPTIONAL MATCH (pt)<-[ps:STATUS_OF]-(pst:LegalStatus)
    WHERE pst.statusKind IN ['PATENT_EXPIRED', 'PATENT_LAPSED']
      AND (ps.validFrom IS NULL OR ps.validFrom <= $V) AND ps.recordedFrom <= $R AND (ps.recordedTo IS NULL OR $R < ps.recordedTo)
  RETURN max(pt.expiresAt) AS latestPatentExpiry,
         collect(DISTINCT {patent: pt.uid, expiresAt: pt.expiresAt, expiryBasis: pt.expiryBasis,
                           endedBy: pst.statusKind, endedAt: ps.validFrom, statusAssertion: ps.assertionUid}) AS patents
}
// regulatory data protection / market exclusivity episodes on X or its substance
CALL (x, substances) {
  UNWIND [x] + substances AS subj
  MATCH (subj)<-[r:STATUS_OF]-(s:LegalStatus {statusFamily: 'EXCLUSIVITY'})
  WHERE r.recordedFrom <= $R AND (r.recordedTo IS NULL OR $R < r.recordedTo)
  RETURN collect(DISTINCT {kind: s.statusKind, jurisdiction: s.jurisdiction, ends: r.validTo, endsPrecision: r.validToPrecision,
                           statusAssertion: r.assertionUid}) AS dataProtection
}
// R-68: supply exclusivity = SUPPLIES_MATERIAL with exclusivity=SOLE on the material
CALL (materials) {
  UNWIND materials AS mm
  MATCH (a:Assertion {predicate: 'SUPPLIES_MATERIAL'})-[:HAS_OBJECT]->(mm)
  WHERE a.recordedTo IS NULL AND any(q IN coalesce(a.qualifiers, []) WHERE q STARTS WITH 'exclusivity=SOLE')
  MATCH (a)-[:HAS_SUBJECT]->(sup:Organization)
  RETURN max(a.validTo) AS supplyExclusivityEnds,
         collect(DISTINCT {supplier: sup.name, ends: a.validTo, endsBasis: a.validToBasis, supplyAssertion: a.uid}) AS supplyTerms
}
RETURN x.name AS ingredient, latestPatentExpiry, patents, dataProtection, supplyExclusivityEnds, supplyTerms
```

- bitemporal episode needed on: STATUS_OF.

## Q-D8-18

For a person pursuing target T, which products for T should be avoided on quality or legal grounds — open recall, warning letter, failed independent label-claim test, counterfeit reports, or no lawful standing in the person's jurisdiction? (biohacker, value 2, harm)

- **Rulings that changed it:**
  - **R-73.** `QUALITY_RESULT_FOR → Product` is cut; `QualityResult.resultFor` is typed `Lot` (a lot-identified measurement). A survey row that names no lot stays the D1 predicate MEASURED_CONTENT_IN_PRODUCT or CONTAINS_UNDECLARED_SUBSTANCE (subject Product | ProductVariant, object ChemicalSubstance). An undeclared drug is also a D8 record with `violationCategories` UNDECLARED_DRUG_INGREDIENT.
- **Final-SDL changes against the packet block:** failed-test signals are read on the Lots of the product and of its variants (`LotOfTarget = Product | ProductVariant`) and recalls on those lots; lot-less survey rows are returned from the D1 predicates on the product or its variants (CONTAINS_UNDECLARED_SUBSTANCE is a signal; MEASURED_CONTENT_IN_PRODUCT rows are returned with value and unit for the answer layer to compare with the label claim); the standing branch is unchanged (STATUS_OF Product, its declared IngredientMaterial and ChemicalSubstance).
- **How it is answered now:** the same signals through the Lot path (R-73) plus the D1 survey predicates; nothing lost. The list is an answer (Report kind ANSWER if published), never a stored flag (00-DIRECTIVE 3.2).

```cypher
// @id Q-D8-18
// $targetUid = D5 Target T; $J = the person's jurisdiction; $V = valid time; $R = recorded time
MATCH (ta:Assertion {predicate: 'INTENDED_FOR_TARGET'})-[:HAS_OBJECT]->(:Target {uid: $targetUid})
MATCH (ta)-[:HAS_SUBJECT]->(p:Product)
WHERE ta.recordedTo IS NULL
OPTIONAL MATCH (rec:RegulatoryRecord {recordFamily: 'ENFORCEMENT'})-[ec:CONCERNS]->(p)
WITH p, collect(DISTINCT CASE WHEN rec IS NOT NULL THEN {record: rec.recordNumber, kind: rec.recordKind, issuedAt: rec.issuedAt,
                                                        assertionUid: ec.assertionUid} END) AS enforcement
OPTIONAL MATCH (p)-[:HAS_VARIANT]->(pv:ProductVariant)
WITH p, enforcement, collect(DISTINCT pv) AS variants
// R-73: lots of the product or of its variants carry recalls and lot-identified QualityResults
CALL (p, variants) {
  UNWIND [p] + variants AS lotTarget
  MATCH (lot:Lot)-[:LOT_OF]->(lotTarget)
  OPTIONAL MATCH (rr:RegulatoryRecord {recordKind: 'RECALL'})-[rc:CONCERNS]->(lot)
  OPTIONAL MATCH (q:QualityResult)-[qf:QUALITY_RESULT_FOR]->(lot)
    WHERE q.valueQualifier = 'NOT_DETECTED' OR q.percentOfLabelClaimStated < 50 OR q.statedVerdict = 'DOES_NOT_CONFORM'
  RETURN collect(DISTINCT CASE WHEN rr IS NOT NULL THEN {record: rr.recordNumber, lot: lot.lotCode, recallClass: rr.recallClass,
                                                          recallStatus: rr.recallStatus, assertionUid: rc.assertionUid} END) AS recalls,
         collect(DISTINCT CASE WHEN q IS NOT NULL THEN {result: q.uid, lot: lot.lotCode, analyte: q.analyteVerbatim,
                                                         value: q.valueVerbatim, pctOfClaim: q.percentOfLabelClaimStated,
                                                         assertionUid: qf.assertionUid} END) AS failedLotTests
}
// R-73: survey rows that name no lot stay D1 predicates on the Product | ProductVariant
CALL (p, variants) {
  UNWIND [p] + variants AS sampled
  MATCH (sa:Assertion)-[:HAS_SUBJECT]->(sampled)
  WHERE sa.predicate IN ['CONTAINS_UNDECLARED_SUBSTANCE', 'MEASURED_CONTENT_IN_PRODUCT'] AND sa.recordedTo IS NULL
  MATCH (sa)-[:HAS_OBJECT]->(cs:ChemicalSubstance)
  RETURN collect(DISTINCT {predicate: sa.predicate, substance: cs.name, value: sa.valueNumber, unit: sa.unitCode,
                           qualifiers: sa.qualifiers, assertionUid: sa.uid}) AS surveyRows
}
// standing is often held by the ingredient or substance (NMN: STATUS_OF the D1 ChemicalSubstance), so read it on the product
// AND on what its current label declares (D6 -> D1, read only)
OPTIONAL MATCH (p)-[:HAS_VARIANT]->(:ProductVariant)-[:HAS_PACKAGE]->(:Package)-[lv:HAS_LABEL_VERSION]->(:LabelVersion)
               -[:DECLARES_COMPONENT]->(m:IngredientMaterial)
  WHERE lv.recordedTo IS NULL AND (lv.validTo IS NULL OR $V < lv.validTo)
OPTIONAL MATCH (m)-[:REALIZES_SUBSTANCE]->(cs2:ChemicalSubstance)
WITH p, enforcement, recalls, failedLotTests, surveyRows, [p] + collect(DISTINCT m) + collect(DISTINCT cs2) AS subjects
UNWIND subjects AS subj
OPTIONAL MATCH (subj)<-[r:STATUS_OF]-(s:LegalStatus {jurisdiction: $J})
  WHERE s.statusKind IN ['NOT_AUTHORISED', 'EXCLUDED_FROM_DEFINITION', 'REVOKED', 'WITHDRAWN']
    AND (r.validFrom IS NULL OR r.validFrom <= $V) AND (r.validTo IS NULL OR $V < r.validTo)
    AND r.recordedFrom <= $R AND (r.recordedTo IS NULL OR $R < r.recordedTo)
WITH p, enforcement, recalls, failedLotTests, surveyRows,
     collect(DISTINCT CASE WHEN s IS NOT NULL THEN {subject: subj.name, status: s.statusKind, assertionUid: r.assertionUid} END) AS standingSignals
// TRACE: each signal's assertionUid; the intended-for-target link is TRACE on the D5 Assertion
```

## Q-D8-19

Rank or compare products of ingredient X on quality evidence (independent measured content vs claim, certification scope and currency, enforcement history), with the criteria and their versions shown. (biohacker, value 3)

- **Rulings that changed it:**
  - **R-73.** `QUALITY_RESULT_FOR → Product` is cut (QualityResult → Lot only); a lot-less survey row is the D1 predicate MEASURED_CONTENT_IN_PRODUCT on the Product | ProductVariant. R-73 keeps `COVERS → ProductVariant` (CertificationCoverageTarget = Product | ProductVariant | Lot; FX-02 fixture request).
- **Final-SDL changes against the packet block:** measured rows = MEASURED QualityResults on the Lots of the product and of its variants, plus MEASURED_CONTENT_IN_PRODUCT survey Assertions; certification coverage read on the product, its variants and their lots with AS_OF on COVERS (the packet read COVERS → Product only and without AS_OF); enforcement count unchanged.
- **How it is answered now:** the input rows are retrieved here; the ranking is still a published kernel Report (`reportKind` COMPARISON) under a D10 DecisionCriterion version, DERIVED_FROM the row Assertions. Nothing lost.

```cypher
// @id Q-D8-19
// $productUids = the products of ingredient X being compared; $V = valid time; $R = recorded time
MATCH (p:Product) WHERE p.uid IN $productUids
OPTIONAL MATCH (p)-[:HAS_VARIANT]->(pv:ProductVariant)
WITH p, collect(DISTINCT pv) AS variants
// R-73: measured content of a sold product = MEASURED QualityResults on its lots (or its variants' lots)
CALL (p, variants) {
  UNWIND [p] + variants AS lotTarget
  MATCH (lot:Lot)-[:LOT_OF]->(lotTarget)
  MATCH (q:QualityResult {resultBasis: 'MEASURED'})-[qf:QUALITY_RESULT_FOR]->(lot)
  OPTIONAL MATCH (q)-[:ISSUED_BY]->(lab:Organization)
  RETURN collect(DISTINCT {result: q.uid, lot: lot.lotCode, analyte: q.analyteVerbatim, value: q.value, unit: q.unitCode,
                           labelClaim: q.labelClaimValue, pctOfClaim: q.percentOfLabelClaimStated, lab: lab.name,
                           testedAt: q.testedAt, assertionUid: qf.assertionUid}) AS lotMeasurements
}
// R-73: lot-less survey rows stay the D1 predicate MEASURED_CONTENT_IN_PRODUCT (subject Product | ProductVariant)
CALL (p, variants) {
  UNWIND [p] + variants AS sampled
  MATCH (sa:Assertion {predicate: 'MEASURED_CONTENT_IN_PRODUCT'})-[:HAS_SUBJECT]->(sampled)
  WHERE sa.recordedTo IS NULL
  MATCH (sa)-[:HAS_OBJECT]->(cs:ChemicalSubstance)
  RETURN collect(DISTINCT {substance: cs.name, value: sa.valueNumber, unit: sa.unitCode, qualifiers: sa.qualifiers,
                           assertionUid: sa.uid}) AS surveyMeasurements
}
// certification coverage as of V on the product, its variants or their lots (CertificationCoverageTarget)
CALL (p, variants) {
  UNWIND [p] + variants AS covered
  OPTIONAL MATCH (covLot:Lot)-[:LOT_OF]->(covered)
  WITH covered, [covered] + collect(covLot) AS coverTargets
  UNWIND coverTargets AS ct
  MATCH (cl:CertificationListing)-[cv:COVERS]->(ct)
  WHERE (cv.validFrom IS NULL OR cv.validFrom <= $V) AND (cv.validTo IS NULL OR $V < cv.validTo)
    AND cv.recordedFrom <= $R AND (cv.recordedTo IS NULL OR $R < cv.recordedTo)
  RETURN collect(DISTINCT {listing: cl.uid, programme: cl.programme, standard: cl.standard, scope: cl.scopeVerbatim,
                           validFrom: cv.validFrom, validTo: cv.validTo, assertionUid: cv.assertionUid}) AS certifications
}
OPTIONAL MATCH (rec:RegulatoryRecord {recordFamily: 'ENFORCEMENT'})-[:CONCERNS]->(p)
RETURN p.uid, p.name, lotMeasurements, surveyMeasurements, certifications, count(DISTINCT rec) AS enforcementCount
// published: (rep:Report {reportKind: 'COMPARISON'})-[:DERIVED_FROM]->(the row Assertions), under a D10 DecisionCriterion version
```

## Q-D8-23

What is the FDA standing of device model D as of date V — cleared (510(k)), authorised (De Novo), approved (PMA), emergency-use, or none — and which recalls or safety communications concern it? (biohacker, investor, value 1, harm)

- **Rulings that changed it:**
  - **R-72.** One Device path: regulatory acts concern the D6 Product, which DELIVERS the D4 Device. Device left RegulatoryRecordTopic (now ChemicalSubstance | IngredientMaterial | Product | Lot) and LegalStatusSubject (now ChemicalSubstance | IngredientMaterial | Product | Patent). D8 answers Q-D8-23 as `STATUS_OF Product -DELIVERS-> Device` (OQ-D8-29, OQ-D8-32 closed by the union change; FU-04 item 3).
  - **R-94** (seam hygiene): CONCERNS has no Device member (the D4 and D6 seam rows follow R-72).
- **Final-SDL changes against the packet block:** `(d)<-[:STATUS_OF]-(:LegalStatus)` → `(d)<-[:DELIVERS]-(p:Product)<-[:STATUS_OF]-(:LegalStatus)`; `(rec)-[:CONCERNS]->(d)` → CONCERNS the Product or a Lot of the product or of its variants (the D4 fixture `noninvasive-glucose-cgm-recall` recall Z-1020-2026 concerns the Product; affected lots stay `lotCodesVerbatim` until a lot resolves); AS_OF written out; a device with no delivering Product still returns one row (no authorisation record found).
- **How it is answered now:** through the delivering Product; nothing lost. Where several Products deliver one Device model, standing is per Product (per maker / kit); the answer layer must not merge a clearance of one kit into another.

```cypher
// @id Q-D8-23
// $deviceUid = D4 Device model D; $V = valid time; $R = recorded time
MATCH (d:Device {uid: $deviceUid})
// R-72: the D6 Product that DELIVERS the device carries D8 standing and records
OPTIONAL MATCH (p:Product)-[dl:DELIVERS]->(d)
  WHERE dl.recordedFrom <= $R AND (dl.recordedTo IS NULL OR $R < dl.recordedTo)
WITH d, collect(DISTINCT p) AS products
UNWIND CASE WHEN size(products) = 0 THEN [null] ELSE products END AS p
CALL (p) {
  OPTIONAL MATCH (p)<-[r:STATUS_OF]-(s:LegalStatus {jurisdiction: 'US'})-[f:STATUS_FROM]->(clr:RegulatoryRecord)
    WHERE (r.validFrom IS NULL OR r.validFrom <= $V) AND (r.validTo IS NULL OR $V < r.validTo)
      AND r.recordedFrom <= $R AND (r.recordedTo IS NULL OR $R < r.recordedTo)
  RETURN collect(DISTINCT CASE WHEN s IS NOT NULL THEN {statusKind: s.statusKind, pathway: s.pathway, recordKind: clr.recordKind,
                                                        recordNumber: clr.recordNumber, issuedAt: clr.issuedAt,
                                                        validFrom: r.validFrom, validFromBasis: r.validFromBasis,
                                                        statusAssertion: r.assertionUid, fromAssertion: f.assertionUid} END) AS standing
}
// R-72 / R-94: recalls and safety communications CONCERN the Product or one of its (or its variants') Lots, never the Device
CALL (p) {
  OPTIONAL MATCH (p)-[:HAS_VARIANT]->(pv:ProductVariant)
  WITH p, [p] + collect(DISTINCT pv) AS lotTargets
  UNWIND lotTargets AS lt
  OPTIONAL MATCH (lot:Lot)-[:LOT_OF]->(lt)
  WITH p, [p] + collect(DISTINCT lot) AS topics
  UNWIND topics AS topic
  OPTIONAL MATCH (rec:RegulatoryRecord)-[c:CONCERNS]->(topic)
    WHERE rec.recordKind IN ['RECALL', 'SAFETY_COMMUNICATION', 'WARNING_LETTER']
      AND c.recordedFrom <= $R AND (c.recordedTo IS NULL OR $R < c.recordedTo)
  RETURN collect(DISTINCT CASE WHEN rec IS NOT NULL THEN {kind: rec.recordKind, number: rec.recordNumber, issuedAt: rec.issuedAt,
                                                          class: rec.recallClass, status: rec.recallStatus, reason: rec.reasonVerbatim,
                                                          lots: rec.lotCodesVerbatim, assertionUid: c.assertionUid} END) AS harmRecords
}
RETURN d.uid AS device, d.name AS deviceName, p.uid AS product, p.name AS productName, standing, harmRecords
// no standing row: "no authorisation record found in sources S as of V" (never "not authorised" unless a record says so)
```

- trace: TRACE on `statusAssertion` and `fromAssertion` for the clearance (510(k) record JSON pointer); TRACE on each `harmRecords[].assertionUid` (openFDA device/recall JSON pointer; D4 fixture `noninvasive-glucose-cgm-recall`: Z-1020-2026, "Open, Classified"); the DELIVERS hop cites its own `dl.assertionUid` (fixture c04). The safety communication's scope sentence is TRACE_NODE(rec). The device-level error statement stays the D4 predicate-only Assertion of that fixture (REPORTED_MEASUREMENT_ERROR, subject the Device).
