## Q-D2-10

*For biohacking target T, which mechanisms are proposed to mediate it, and which compounds act on those mechanisms in the opposite (harmful) direction?* Answer kind: retrieved.

- **Ruling: R-59 (direction vocabularies).** D2's `MechanismDirection` is deleted. `MechanismProjectionProperties.direction` is now D3 `EstimateDirection` (`INCREASED`, `DECREASED`, `NO_CHANGE`, `MIXED`, `UNKNOWN`). The packet filter `r.direction = 'DECREASES'` is not a value of that enum, so it becomes `'DECREASED'`.
- `MEDIATES_TARGET` is still registered in `vocabularies/predicates.yaml`: subject Mechanism, object Target, registrar D2. R-83 admits it with a Mechanism subject.
- The modulator label is written out because the final pairs of AFFECTS_MECHANISM are `ChemicalSubstance|Intervention → Mechanism`.
- The mediation Assertion gets the AS-OF / status filter of the packet's ASOF fragment.
- The packet reads "opposite direction" for a POSITIVE mediation only: higher mechanism activity supports T, so a DECREASED projection works against T. The rewrite keeps that.
  - `polarity: NEGATIVE` is not an inverse mediation. It means the source denies that the mechanism mediates T (the D2 null rule). Those rows are excluded.
  - An `EstimateDirection` of `MIXED` is not counted as harmful. A reader who wants it adds `'MIXED'` to the IN list.
- The answer stays retrieved. The weighed harm conclusion is still a kernel `Assessment` with `effectDirection: HARM` about the Target (D5/D10), and it cites these rows.

```cypher
// @id Q-D2-10
MATCH (t:Target {key: $targetKey})<-[:HAS_OBJECT]-(med:Assertion {predicate: 'MEDIATES_TARGET'})-[:HAS_SUBJECT]->(m:Mechanism)
WHERE med.recordedAt <= $asOf AND (med.recordedTo IS NULL OR med.recordedTo > $asOf)
  AND med.status IN ['ACCEPTED', 'DISPUTED']
  AND med.polarity = 'POSITIVE'                      // higher mechanism activity supports T
MATCH (mod:ChemicalSubstance|Intervention)-[r:AFFECTS_MECHANISM]->(m)
WHERE r.direction IN ['DECREASED']                   // R-59: EstimateDirection (was MechanismDirection 'DECREASES')
RETURN t.key AS target, t.label AS targetLabel, m.uid AS mechanismUid, m.name AS mechanism, med.uid AS mediationAssertion,
       mod.uid AS modulatorUid, mod.name AS modulator,
       [lbl IN labels(mod) WHERE NOT lbl IN ['Entity', 'Occurrence', 'InformationArtifact', 'EvidenceAssessment']][0] AS modulatorKind,
       r.direction AS direction, r.bestBasis AS bestBasis, r.humanMeasured AS humanMeasured, r.highestSetting AS highestSetting,
       r.nContexts AS nContexts, r.nHumanContexts AS nHumanContexts, r.viaParticipant AS viaParticipant, r.derivationRule AS method,
       COLLECT { MATCH (med)-[ev:HAS_EVIDENCE]->(loc:SourceLocator)<-[:HAS_LOCATOR]-(snap:SourceSnapshot)<-[:HAS_SNAPSHOT]-(src:Source)
                 RETURN {role: ev.role, selectorKind: loc.selectorKind, exact: loc.exact, contentHash: snap.contentHash,
                         retrievedAt: snap.retrievedAt, uri: src.canonicalUri} } AS mediationTrace,
       COLLECT { MATCH (adj:Adjudication)-[:ASSESSES]->(med) WHERE adj.recordedTo IS NULL
                 RETURN adj {.uid, .adjudicationKind, .verdict} } AS mediationAdjudications,
       COLLECT { MATCH (inp:Assertion) WHERE inp.uid IN r.derivedFromAssertionUids
                 MATCH (inp)-[ev:HAS_EVIDENCE]->(loc:SourceLocator)<-[:HAS_LOCATOR]-(snap:SourceSnapshot)<-[:HAS_SNAPSHOT]-(src:Source)
                 RETURN {assertion: inp.uid, predicate: inp.predicate, basis: inp.basisKind, exact: loc.exact,
                         contentHash: snap.contentHash, uri: src.canonicalUri} } AS projectionTrace
ORDER BY m.name, r.humanMeasured DESC, r.nContexts DESC
```

- EXPLAIN: ok on Neo4j 5.26.31 community (1/1 statement); final-SDL static check clean (labels, types, pairs, properties, enum values, predicates)
- trace: `mediationTrace` and `mediationAdjudications` give TRACE on `med`. `projectionTrace` gives TRACE on each input Assertion of the projection, through `r.derivedFromAssertionUids`.
- fixture: `packets/D2/07-fixtures/metformin-exercise-harm`. Its `questions.md` names metformin as acting against endurance with direction DECREASES (human, measured); under R-59 the projected value is `DECREASED`. The fixture says `MEDIATES_TARGET` is not asserted, so the query returns no rows on it until that Assertion is added.
- bitemporal episode needed on: none.

## Q-D2-18

*Which compounds have the most independent measured support for modulating mechanism M across settings (ranking)?* Answer kind: materialized.

- **Ruling: R-47 (option b).**
  - `AFFECTS_MECHANISM` stays as an unscored facet shortcut. `score` stays null and the executor validates that.
  - `MechanismProjectionProperties` drops `nNoChangeContexts`.
  - The Q-D2-18 ranking reads D10 `Association` records: `associationKind: EVIDENCE_AGGREGATE`, one per modulator × mechanism, with `anchorUid` set to the modulator's uid. This is the `edit-pattern` op in `_work/rulings.yaml`.
- **R-59** retypes `direction` to `EstimateDirection`. This pattern only returns it.
- **What changed.**
  - The rank key moves from `r.score` (always null now) to `assoc.score`.
  - The packet's filter `bestBasis = 'DIRECT_MEASUREMENT'` stays on the facet edge, so only modulators with measured support are ranked.
  - `nNoChangeContexts` is no longer stored. It is counted at query time as the distinct `MechanismEvidenceContext`s of the Association's `NO_CHANGE_IN` inputs with `basisKind: DIRECT_MEASUREMENT`. That count is complete only while the Association keeps its input edges, which holds up to 5,000 inputs. Above that only `inputSetDigest` is kept and the count is returned null-safe as 0.
  - Stale records (`staleAfter` before `$asOf`) are flagged, not dropped.
- **Method name.** The score method is the support score that the packet's 09-reasoning defines for `d2.affects-mechanism/v1`. No ruling names the `Association.methodVersion` string for it, so the pattern takes `$methodVersion` and ranks within one method only. The G-1 method in `query-patterns.md`, `bl-assoc/evidence-aggregate@1`, is a candidate. The string has to be fixed by D2 with D10; this is a naming choice, not an SDL change.
- **Publication.** A published ranking is still a kernel `Report` (reportKind COMPARISON) under a D10 `DecisionCriterion` version. A ranking is never a stored edge between modulators.

```cypher
// @id Q-D2-18
MATCH (m:Mechanism {uid: $mechanismUid})<-[:ASSOCIATES]-(assoc:Association {associationKind: 'EVIDENCE_AGGREGATE'})-[:ASSOCIATES]->(mod:ChemicalSubstance|Intervention)
WHERE assoc.anchorUid = mod.uid                      // oriented from the modulator (Association.anchorUid)
  AND assoc.methodVersion = $methodVersion
  AND assoc.recordedAt <= $asOf AND (assoc.recordedTo IS NULL OR assoc.recordedTo > $asOf)
MATCH (mod)-[r:AFFECTS_MECHANISM]->(m)               // R-47: unscored facet shortcut (score null)
WHERE r.derivationRule = 'd2.affects-mechanism/v1' AND r.bestBasis = 'DIRECT_MEASUREMENT'
RETURN mod.uid AS modulatorUid, mod.name AS modulator,
       [lbl IN labels(mod) WHERE NOT lbl IN ['Entity', 'Occurrence', 'InformationArtifact', 'EvidenceAssessment']][0] AS modulatorKind,
       assoc.score AS score, assoc.components AS scoreComponents, assoc.inputCount AS inputCount,
       assoc.methodVersion AS method, assoc.computedAt AS computedAt, assoc.inputSetDigest AS inputSetDigest,
       coalesce(assoc.staleAfter < $asOf, false) AS stale,
       r.direction AS direction, r.highestSetting AS highestSetting, r.humanMeasured AS humanMeasured,
       r.nContexts AS nContexts, r.nHumanContexts AS nHumanContexts,
       size(COLLECT { MATCH (assoc)-[:DERIVED_FROM]->(nc:Assertion {predicate: 'NO_CHANGE_IN'})-[:OBSERVED_IN_CONTEXT]->(ctx:MechanismEvidenceContext)
                      WHERE nc.basisKind = 'DIRECT_MEASUREMENT'
                      RETURN DISTINCT ctx.uid AS c }) AS nNoChangeContexts,   // R-47: no longer stored on the edge
       COLLECT { MATCH (assoc)-[:DERIVED_FROM]->(inp:Assertion)-[ev:HAS_EVIDENCE]->(loc:SourceLocator)<-[:HAS_LOCATOR]-(snap:SourceSnapshot)<-[:HAS_SNAPSHOT]-(src:Source)
                 RETURN {assertion: inp.uid, predicate: inp.predicate, basis: inp.basisKind, role: ev.role, exact: loc.exact,
                         contentHash: snap.contentHash, uri: src.canonicalUri,
                         verdict: COLLECT { MATCH (adj:Adjudication)-[:ASSESSES]->(inp) WHERE adj.recordedTo IS NULL RETURN adj.verdict }}
                 LIMIT 25 } AS trace,
       COLLECT { MATCH (assoc)-[:WAS_GENERATED_BY]->(act:Activity) RETURN act {.runId, .activityKind, .methodVersion} } AS projectionRun
ORDER BY score DESC, nHumanContexts DESC
```

- EXPLAIN: ok on Neo4j 5.26.31 community (1/1 statement); final-SDL static check clean (labels, types, pairs, properties, enum values, predicates)
- trace: each row goes from `Association.inputs` (kernel `DERIVED_FROM`) to the input Assertions and their TRACE, shown with up to 25 inputs per row. The full citation set is `inputSetDigest` or a P-01b call per input. Lineage is `WAS_GENERATED_BY` the PROJECTION Activity (R-48). A published ranking's `Report` is `DERIVED_FROM` the same Assertions.
- data requirement: the projection job has to write one EVIDENCE_AGGREGATE Association per (modulator, mechanism) pair that has an AFFECTS_MECHANISM edge. That is the G-0 write shape in `query-patterns.md`. Until it does, the pattern returns no rows. No D2 fixture writes such an Association yet.
- bitemporal episode needed on: none. Association recorded time is covered by the AS-OF filter.
