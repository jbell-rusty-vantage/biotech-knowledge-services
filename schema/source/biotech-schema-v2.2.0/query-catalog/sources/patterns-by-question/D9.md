**Conventions** (the packet's, restated against the final SDL).

- **Occurrence** = `Assertion {assertionKind: 'CLAIM'}` with `OCCURRENCE_OF → Claim`, one `ASSERTED_BY`, one `OCCURS_IN → MediaWork` (R-19: every Assertion whose evidence is in a MediaWork has exactly one OCCURS_IN), and located spans by `HAS_EVIDENCE`. Current records: `o.recordedTo IS NULL`.
- **Recommendation** (R-83): speechAct `RECOMMENDS`, predicate `RECOMMENDS_USE` (or `RECOMMENDS_AGAINST`), both registered by D9; the subject is the recommended means, never a Target; a goal is the qualifier `target:<key>`. The packet's "D5 target predicate with a Target object" form is gone. No RECOMMENDS edge is stored.
- **Correction and qualification** (R-20, closes D9 K-2 / K-3): a correction is an occurrence with predicate `CORRECTS` plus `DERIVED_FROM` the corrected occurrence; a qualification is `HAS_EVIDENCE {role: 'QUALIFIES'}` plus qualifier prefixes; an assessment of one occurrence `ASSESSES` the Claim (and the speaker) and is `DERIVED_FROM` the judged occurrence, facets `occurrence=`, `retelling=`, `original=`.
- **Statement time T** (R-19): `publishedAt` of the OCCURS_IN MediaWork; the snapshot's `publishedAt` / `observedAt` only when there is no container. OVERLAP reads the authorizing Assertion's `validObservedAt` through `r.assertionUid`.
- **TRACE** (the kernel provenance chain, kept on every row): `(a)-[:HAS_EVIDENCE]->(SourceLocator)<-[:HAS_LOCATOR]-(SourceSnapshot)<-[:HAS_SNAPSHOT]-(Source)`, the Source's `RENDITION_OF` work, and the current CAPTURE_FIDELITY `Adjudication` that `ASSESSES` the Assertion. It is the macro `TRACE(x)` below (expanded by the validator before EXPLAIN; inner variables are prefixed `t` so they never capture an outer variable).
- **OVERLAP(EP, OBS, AT)** (D7's rule, which D9 adopts): `UNKNOWN` when AT is null or when a bound at YEAR / MONTH / DAY precision equals AT truncated to that precision; `DISJOINT` / `OVERLAPS` as in the packet; a null bound is unknown, never ongoing. Its value is the `temporalOverlap` facet of the CONFLICT_RELEVANCE Assessment (R-55, registrar D7); the query value is a retrieval aid.
- **DISCLOSURES(SPK, ORG, CW, ST, FAM)**: the holder's own interest Assertion (predicate = the interest edge type) or a `DISCLOSES_INTEREST` Assertion (R-82; registered by D9; a NEGATIVE-polarity denial is not a disclosure), each with its timing against T: in a rendition of the container (`Source -RENDITION_OF-> w`, R-19) at or before T, in a later revision, elsewhere at or before T, or elsewhere later. The `disclosureFinding` facet values are the Assessment's (R-55); the hint names here are retrieval aids.

```cypher-macros
// TRACE(OCC): located span -> snapshot -> source (+ the work it renders) and the current capture-fidelity verdicts of OCC
TRACE(OCC) = COLLECT { MATCH (OCC)-[tEv:HAS_EVIDENCE]->(tLoc:SourceLocator)<-[:HAS_LOCATOR]-(tSnap:SourceSnapshot)<-[:HAS_SNAPSHOT]-(tSrc:Source)
      WHERE tEv.role IN ['SUPPORTS', 'QUALIFIES']
      OPTIONAL MATCH (tSrc)-[:RENDITION_OF]->(tRw:MediaWork)
      RETURN {role: tEv.role, selectorKind: tLoc.selectorKind, exact: tLoc.exact, startOffset: tLoc.startOffset, endOffset: tLoc.endOffset,
              mediaStartSeconds: tLoc.mediaStartSeconds, mediaEndSeconds: tLoc.mediaEndSeconds, speakerLabel: tLoc.speakerLabelInSource,
              contentHash: tSnap.contentHash, retrievedAt: tSnap.retrievedAt, captureCompleteness: tSnap.captureCompleteness,
              uri: tSrc.canonicalUri, genre: tSrc.genre, renditionOfWork: tRw.uid,
              captureFidelity: COLLECT { MATCH (tAdj:Adjudication {adjudicationKind: 'CAPTURE_FIDELITY'})-[:ASSESSES]->(OCC) WHERE tAdj.recordedTo IS NULL
                                         RETURN tAdj {.uid, .verdict, .policyOutcome} }} }
// OVERLAP(EP, OBS, AT) -> 'OVERLAPS' | 'DISJOINT' | 'UNKNOWN' (EP: episode edge or predicate-only Assertion; OBS: validObservedAt; AT: statement time T)
OVERLAP(EP, OBS, AT) = CASE
      WHEN AT IS NULL THEN 'UNKNOWN'
      WHEN CASE WHEN EP.validFromPrecision IN ['YEAR', 'MONTH', 'DAY'] AND EP.validFrom IS NOT NULL      // CASE guards: truncate(null) is a runtime error
                THEN datetime.truncate(toLower(EP.validFromPrecision), EP.validFrom) = datetime.truncate(toLower(EP.validFromPrecision), AT) ELSE false END
        OR CASE WHEN EP.validToPrecision IN ['YEAR', 'MONTH', 'DAY'] AND EP.validTo IS NOT NULL
                THEN datetime.truncate(toLower(EP.validToPrecision), EP.validTo) = datetime.truncate(toLower(EP.validToPrecision), AT) ELSE false END THEN 'UNKNOWN'
      WHEN (EP.validTo IS NOT NULL AND EP.validTo <= AT) OR (EP.validFrom IS NOT NULL AND EP.validFrom > AT) THEN 'DISJOINT'
      WHEN EP.validFrom IS NOT NULL AND EP.validFrom <= AT AND (EP.validTo > AT OR (EP.validTo IS NULL AND OBS >= AT)) THEN 'OVERLAPS'
      ELSE 'UNKNOWN' END
// DISCLOSURES(SPK, ORG, CW, ST, FAM): disclosures of SPK's interest FAM in ORG, timed against container CW and statement time ST
DISCLOSURES(SPK, ORG, CW, ST, FAM) = COLLECT { MATCH (dDa:Assertion)-[:HAS_OBJECT]->(ORG)
      WHERE dDa.recordedTo IS NULL
        AND ((dDa.predicate = FAM AND EXISTS { (dDa)-[:ASSERTED_BY]->(SPK) })
             OR (dDa.predicate = 'DISCLOSES_INTEREST' AND coalesce(dDa.polarity, 'POSITIVE') <> 'NEGATIVE'
                 AND (EXISTS { (dDa)-[:HAS_SUBJECT]->(SPK) } OR EXISTS { (dDa)-[:HAS_SUBJECT]->(CW) })))
      MATCH (dDa)-[:HAS_EVIDENCE]->(:SourceLocator)<-[:HAS_LOCATOR]-(dSnap:SourceSnapshot)<-[:HAS_SNAPSHOT]-(dSrc:Source)
      WITH dDa, dSrc, coalesce(dSnap.publishedAt, dSnap.observedAt) AS dAt, EXISTS { (dSrc)-[:RENDITION_OF]->(CW) } AS dInContainer
      RETURN {disclosure: dDa.uid, predicate: dDa.predicate, at: dAt, source: dSrc.canonicalUri,
              timing: CASE WHEN dAt IS NULL OR ST IS NULL THEN 'TIMING_UNKNOWN'
                           WHEN dInContainer AND dAt <= ST THEN 'DISCLOSED_IN_CONTAINER'
                           WHEN dInContainer THEN 'DISCLOSED_IN_LATER_REVISION'
                           WHEN dAt <= ST THEN 'DISCLOSED_ELSEWHERE_AT_TIME'
                           ELSE 'DISCLOSED_ELSEWHERE' END} }
```

## CQ-CL-04

*Retelling-fidelity assessments for a retelling.*

- **Ruling: F-05**, and **R-20** (closes D9 K-1 / K-3 / K-4 as kernel conventions): the `RETELLING_FIDELITY` Assessment `ASSESSES` the Claim (and the speaker), is `DERIVED_FROM` the judged occurrences, and carries the facets `retelling=<uid>`, `original=<uid>`, `occurrence=<uid>`. The packet's interim shape is now the convention; the pattern adds the facet test for the retelling and returns the assessed Claim and speaker.
- An Assessment cannot `ASSESS` an Assertion in the final SDL (`Assessment.about` targets Subjectable), so the occurrences are reached only through `DERIVED_FROM`.

```cypher
// @id CQ-CL-04
MATCH (ret:Assertion {uid: $retellingUid, assertionKind: 'CLAIM'})<-[:DERIVED_FROM]-(fa:Assessment {assessmentKind: 'RETELLING_FIDELITY'})
WHERE fa.recordedTo IS NULL AND fa.status = 'ACCEPTED'
  AND ('retelling=' + ret.uid) IN coalesce(fa.facets, [])
MATCH (fa)-[:DERIVED_FROM]->(orig:Assertion) WHERE orig <> ret
RETURN fa.uid AS assessment, fa.methodVersion, fa.facets, fa.conclusionCode, fa.summary,
       ('original=' + orig.uid) IN coalesce(fa.facets, []) AS namedOriginal, orig.uid AS original, orig.proposition,
       COLLECT { MATCH (fa)-[:ASSESSES]->(c:Claim) RETURN c.uid } AS claims,
       COLLECT { MATCH (fa)-[:ASSESSES]->(spk) WHERE spk:Person OR spk:Organization OR spk:Channel RETURN spk.uid } AS speakers,
       COLLECT { MATCH (fa)-[fev:HAS_EVIDENCE]->(floc:SourceLocator) RETURN {role: fev.role, exact: floc.exact} } AS comparedSpans,
       TRACE(ret) AS retellingTrace, TRACE(orig) AS originalTrace
```

*Was the speaker's interest in an organization behind the statement valid at the time of the statement, and was it disclosed?* (Packet: reads D7 episodes; the judgment is a kernel CONFLICT_RELEVANCE assessment.)

The packet's owner fix removed `CYPHER 25`.
- The packet's `/* OVERLAP(…) */ null` placeholders are now the OVERLAP macro, so each interest, operator and sponsor row carries its verdict. The D7 rewrite of the same catalog id (`patterns-by-question/D7.md`, CQ-CL-05) reads the interest side in more depth (PARENT_OF hops, basis hint); this D9 form keeps D9's three branches: (a) speaker interests, (b) channel operators, (c) sponsors.

```cypher
// @id CQ-CL-05
MATCH (o:Assertion {uid: $occUid, assertionKind: 'CLAIM'})-[:ASSERTED_BY]->(p)
OPTIONAL MATCH (o)-[:OCCURS_IN]->(w:MediaWork)
OPTIONAL MATCH (w)<-[:PUBLISHES]-(ch:Channel)
OPTIONAL MATCH (o)-[:HAS_EVIDENCE]->(:SourceLocator)<-[:HAS_LOCATOR]-(osnap:SourceSnapshot)
WITH o, p, w, ch, min(coalesce(osnap.publishedAt, osnap.observedAt)) AS snapT
WITH o, p, w, ch, CASE WHEN w IS NULL THEN snapT ELSE w.publishedAt END AS T,
     CASE WHEN w IS NULL THEN 'SNAPSHOT_FALLBACK' ELSE 'OCCURS_IN_MEDIAWORK' END AS tBasis
RETURN o.uid AS occurrence, w.uid AS container, ch.uid AS channel, T, tBasis,
  COLLECT {                                                     // (a) speaker interests: never filtered on null bounds
    MATCH (p)-[i:HOLDS_ROLE|HOLDS_STAKE|RECEIVES_VALUE_FROM]->(org:Organization) WHERE i.recordedTo IS NULL
    OPTIONAL MATCH (ia:Assertion {uid: i.assertionUid})
    RETURN {org: org.uid, orgName: org.name, family: type(i), kind: coalesce(i.roleKind, i.stakeKind, i.valueKind),
            validFrom: i.validFrom, validTo: i.validTo, bases: [i.validFromBasis, i.validToBasis], interestAssertion: i.assertionUid,
            temporalOverlap: OVERLAP(i, ia.validObservedAt, T),
            disclosures: DISCLOSURES(p, org, w, T, type(i)),
            interestTrace: TRACE(ia)}
  } AS interests,
  COLLECT {                                                     // (b) channel operators: predicate-only Assertions (R-79)
    MATCH (ch)<-[:HAS_SUBJECT]-(opA:Assertion {predicate: 'OPERATED_BY'})-[:HAS_OBJECT]->(operator)
    WHERE opA.recordedTo IS NULL
    RETURN {operator: operator.uid, name: operator.name, operatorAssertion: opA.uid, temporalOverlap: OVERLAP(opA, opA.validObservedAt, T)}
  } AS operators,
  COLLECT {                                                     // (c) sponsors of the work (episode edge)
    MATCH (w)-[sp:CONTENT_SPONSORED_BY]->(sponsor) WHERE sp.recordedTo IS NULL
    OPTIONAL MATCH (spa:Assertion {uid: sp.assertionUid})
    RETURN {sponsor: sponsor.uid, name: sponsor.name, validFrom: sp.validFrom, validTo: sp.validTo, qualifiers: spa.qualifiers,
            temporalOverlap: OVERLAP(sp, spa.validObservedAt, T)}
  } AS sponsors,
  COLLECT { MATCH (cr:Assessment {assessmentKind: 'CONFLICT_RELEVANCE'})-[:DERIVED_FROM]->(o) WHERE cr.recordedTo IS NULL
            RETURN {assessment: cr.uid, subkind: cr.assessmentSubkind, level: cr.conclusionCode, facets: cr.facets} } AS judgments,
  TRACE(o) AS statementTrace
```

## CQ-CL-06

*How many independent asserters does claim C have (first-hand vs echoes)?* Answer kind: materialized.

- **Ruling: F-05** (label). **R-21**: an explicit retelling is the kernel edge `DERIVED_FROM` (basisKind CITED_FROM_PRIOR_WORK); the `derivedFrom=` qualifier is not registered. **R-20**: a BellLabs-matched retelling is the RETELLING_FIDELITY Assessment with `retelling=<uid>`.
- **R-49 (materialization changes).** The packet wrote the count monthly as an Assessment (`DISCOURSE_METRIC`, interim `OTHER`). R-49 rules that form out: the metrics are projection-cache properties on the Claim (`discourseFirstHandCount`, `discourseRetellingCount`, `discourseRecutCount`, `discourseIndependentCount`, `discourseFirstOccurrenceAt`, `discourseMethodVersion`, `discourseDerivedAt`, added by F-01), written by a PROJECTION Activity (R-45). The pattern is the projection's source query, and returns the cached values next to the live counts so a stale cache shows.
- Test (c) (`w.republicationKind IS NOT NULL`) stays the fallback for occurrences extracted from a re-cut whose original is not in the graph.

```cypher
// @id CQ-CL-06
MATCH (c:Claim {uid: $claimUid})<-[:OCCURRENCE_OF]-(o:Assertion {assertionKind: 'CLAIM'})-[:OCCURS_IN]->(w:MediaWork)
WHERE o.recordedTo IS NULL
MATCH (o)-[:ASSERTED_BY]->(a)
WITH c, o, w, a,
     EXISTS { (o)-[:DERIVED_FROM]->(:Assertion) } AS explicitRetelling,                       // R-21
     EXISTS { MATCH (fa:Assessment {assessmentKind: 'RETELLING_FIDELITY'})-[:DERIVED_FROM]->(o)
              WHERE fa.recordedTo IS NULL AND ('retelling=' + o.uid) IN coalesce(fa.facets, []) } AS matchedRetelling,   // R-20
```
