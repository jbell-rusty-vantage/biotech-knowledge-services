## Statement

```cypher
// @id Q-D11-05
CALL () {
  // R-44 branch 1: identified notice (D3 REVISES, per asserter); renditions through RENDITION_OF (R-43), never a shared Identifier (R-42)
  MATCH (notice:Publication)-[rv:REVISES]->(pub:Publication)<-[ro:RENDITION_OF]-(src:Source)
  WHERE rv.recordedTo IS NULL AND ro.recordedTo IS NULL
    AND rv.revisionKind IN ['RETRACTION', 'EXPRESSION_OF_CONCERN', 'ERRATUM', 'CORRECTED_AND_REPUBLISHED', 'WITHDRAWAL']
  RETURN pub.uid AS work, src, 'REVISES' AS mechanism, toString(rv.revisionKind) AS revisionKind, notice.uid AS notice,
         toString(notice.publicationKind) AS noticeKind, rv.assertionUid AS revisionRecord, rv.recordedFrom AS knownSince
  UNION
  // R-44 branch 2: status flag with no identified notice (kernel HAS_REVISION_STATUS, one per authority):
  // a flag on one rendition taints every current rendition of the same work
  MATCH (hs:Assertion {predicate: 'HAS_REVISION_STATUS'})-[:HAS_SUBJECT]->(flagged:Source)
  WHERE hs.recordedTo IS NULL
    AND hs.valueString IN ['RETRACTION', 'EXPRESSION_OF_CONCERN', 'ERRATUM', 'CORRECTED_AND_REPUBLISHED', 'WITHDRAWAL']
  OPTIONAL MATCH (flagged)-[fro:RENDITION_OF]->(pub:Publication) WHERE fro.recordedTo IS NULL
  OPTIONAL MATCH (pub)<-[sro:RENDITION_OF]-(sibling:Source) WHERE sro.recordedTo IS NULL
  WITH hs, pub, flagged, collect(DISTINCT sibling) AS siblings
  WITH hs, pub, siblings + [flagged] AS renditions
  UNWIND renditions AS src
  WITH DISTINCT hs, pub, src
  RETURN pub.uid AS work, src, 'HAS_REVISION_STATUS' AS mechanism, hs.valueString AS revisionKind, null AS notice,
         null AS noticeKind, hs.uid AS revisionRecord, hs.recordedAt AS knownSince
}
MATCH (src)-[:HAS_SNAPSHOT]->(:SourceSnapshot)-[:HAS_LOCATOR]->(:SourceLocator)<-[:HAS_EVIDENCE]-(a:Assertion)
WHERE a.recordedTo IS NULL AND NOT a.predicate IN ['HAS_REVISION_STATUS', 'RENDITION_OF', 'REVISES']
OPTIONAL MATCH (dep)-[:DERIVED_FROM]->{1,4}(a)                      // assessments, reports, calculated assertions
RETURN work, src.canonicalUri AS rendition, mechanism, revisionKind, notice, noticeKind, revisionRecord, knownSince,
       a.uid AS assertion, a.predicate AS predicate,
       collect(DISTINCT [l IN labels(dep) WHERE l <> 'Entity'][0] + ':' + dep.uid) AS dependents
ORDER BY knownSince DESC
```

## Temporal notes

- bitemporal episode needed on: none with valid time. D3 `REVISES` and `RENDITION_OF` are recorded time only; `recordedFrom` is "since when do we know".

## Evidence and provenance notes

- trace: the tainted assertion's own TRACE plus the `revisionRecord` Assertion's TRACE (FC-2: retraction of PMID 12003802; REVISES per asserter: NLM `CommentsCorrections`, Crossref `/message/updated-by/0`, the publisher's notice). `Publication.revisionStatus` (the R-44 / R-45 work-level cache) stays a cheap pre-filter for answer composition.

## Notes

- **Rulings: R-42, R-43, R-44.** The packet joined the revised Publication to its renditions through `(pub)-[:HAS_IDENTIFIER]->(id)<-[:HAS_IDENTIFIER]-(src:Source)`. Under R-42 the DOI or PMID Identifier belongs to the Publication only, so that join returns nothing. R-43 replaces it with RENDITION_OF. R-44 makes Q-D11-05 read both revision mechanisms.
- **How the question is answered now:** in full. Nothing is lost. `knownSince` is the REVISES episode's `recordedFrom` (the packet's meaning), or the flag Assertion's `recordedAt`.
