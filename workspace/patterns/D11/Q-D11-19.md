## Statement

```cypher
// @id Q-D11-19
MATCH (pre:Publication)-[:HAS_IDENTIFIER]->(:Identifier {scheme: 'DOI', value: $preprintDoi})   // the one holder of the DOI (R-42)
OPTIONAL MATCH (jrnl:Publication)-[rv:REVISES]->(pre) WHERE rv.recordedTo IS NULL
OPTIONAL MATCH (pre)<-[pro:RENDITION_OF]-(preSrc:Source) WHERE pro.recordedTo IS NULL       // R-43, not a shared Identifier
OPTIONAL MATCH (occ:Assertion {assertionKind: 'CLAIM'})-[:HAS_EVIDENCE]->(:SourceLocator)<-[:HAS_LOCATOR]-(:SourceSnapshot)<-[:HAS_SNAPSHOT]-(preSrc)
WHERE occ.recordedTo IS NULL
OPTIONAL MATCH (occ)-[:OCCURRENCE_OF]->(claim:Claim)
OPTIONAL MATCH (claim)<-[:OCCURRENCE_OF]-(occ2:Assertion {assertionKind: 'CLAIM'})-[:HAS_EVIDENCE]->(:SourceLocator)<-[:HAS_LOCATOR]-(:SourceSnapshot)<-[:HAS_SNAPSHOT]-(jSrc:Source)
WHERE occ2.recordedTo IS NULL AND EXISTS { MATCH (jSrc)-[jro:RENDITION_OF]->(jrnl) WHERE jro.recordedTo IS NULL }
RETURN DISTINCT pre.uid AS preprint, jrnl.uid AS journalVersion, rv.revisionKind AS revisionKind, rv.assertionUid AS revisionRecord,
       claim.uid AS claim, occ.uid AS preprintOccurrence, occ.proposition AS preprintWording,
       occ2.uid AS journalOccurrence, occ2.proposition AS journalWording
```

Under R-42 those Identifiers belong to the Publications only. R-43 replaces the joins with RENDITION_OF.
