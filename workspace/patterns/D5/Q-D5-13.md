## Statement

```cypher
// @id Q-D5-13
MATCH (p:Protocol {uid: $protocolUid})-[he:HAS_EDITION]->(e:ProtocolEdition)
WHERE he.recordedFrom <= $asOf AND he.recordedTo IS NULL
// R-80: AUTHORED_BY (registrar D3), subject Protocol | ProtocolEdition, object Person | Organization
UNWIND [p, e] AS authored
MATCH (aa:Assertion {predicate: 'AUTHORED_BY'})-[:HAS_SUBJECT]->(authored),
      (aa)-[:HAS_OBJECT]->(author:Person|Organization)
WHERE aa.recordedTo IS NULL
CALL (author, he) {
  // (1) D7 interest episodes (R-78 Shape B): RoleEdgeProperties.roleKind, StakeEdgeProperties.stakeKind,
  //     ValueEdgeProperties.valueKind; an unbounded episode's observation date is the authorizing Assertion's validObservedAt
  MATCH (author)-[i:HOLDS_ROLE|HOLDS_STAKE|RECEIVES_VALUE_FROM]->(org:Organization)
  WHERE i.recordedTo IS NULL
    AND (i.validFrom IS NULL OR he.validTo IS NULL OR i.validFrom < he.validTo)
    AND (i.validTo IS NULL OR he.validFrom IS NULL OR he.validFrom < i.validTo)
  OPTIONAL MATCH (ia:Assertion {uid: i.assertionUid})
  RETURN org, type(i) AS interestType, coalesce(i.roleKind, i.stakeKind, i.valueKind) AS interestKind,
         i.validFrom AS validFrom, i.validTo AS validTo, ia.validObservedAt AS observedAt, i.assertionUid AS assertionUid,
         'POSITIVE' AS polarity
  UNION
  // (2) stated non-interests: NEGATIVE assertions authorize no episode
  MATCH (n:Assertion {polarity: 'NEGATIVE'})-[:HAS_SUBJECT]->(author), (n)-[:HAS_OBJECT]->(org:Organization)
  WHERE n.predicate IN ['HOLDS_ROLE', 'HOLDS_STAKE', 'RECEIVES_VALUE_FROM'] AND n.recordedTo IS NULL
  RETURN org, n.predicate AS interestType, 'DENIED' AS interestKind, n.validFrom AS validFrom, n.validTo AS validTo,
         n.validObservedAt AS observedAt, n.uid AS assertionUid, 'NEGATIVE' AS polarity
}
// means in the edition that the counterparty owns (brand) or sells (seller of record): D6 typed paths
OPTIONAL MATCH (e)-[:HAS_STEP]->(:ProtocolStep)-[:STEP_USES]->(prod:Product)
  WHERE EXISTS { (prod)-[:BRANDED_AS]->(:Brand)<-[:OWNS_BRAND]-(org) }
     OR EXISTS { (prod)-[:HAS_VARIANT]->(:ProductVariant)-[:HAS_PACKAGE]->(:Package)<-[:LISTING_FOR]-(:MerchantListing)
                 -[:HAS_OFFER]->(:Offer)-[:SELLER_OF_RECORD]->(org) }
WITH e, he, aa, author, org, interestType, interestKind, polarity, validFrom, validTo, observedAt, assertionUid,
     collect(DISTINCT prod.name) AS meansOwnedOrSoldByCounterparty
// TRACE(interest Assertion): the disclosure span on the protocol snapshot
OPTIONAL MATCH (ta:Assertion {uid: assertionUid})
CALL (ta) {
  OPTIONAL MATCH (ta)-[ev:HAS_EVIDENCE]->(loc:SourceLocator)<-[:HAS_LOCATOR]-(snap:SourceSnapshot)<-[:HAS_SNAPSHOT]-(src:Source)
  OPTIONAL MATCH (adj:Adjudication)-[:ASSESSES]->(ta)
    WHERE adj.recordedAt <= $asOf AND (adj.recordedTo IS NULL OR adj.recordedTo > $asOf)
  OPTIONAL MATCH (ta)-[:ASSERTED_BY]->(who)
  OPTIONAL MATCH (ta)-[:WAS_GENERATED_BY]->(act:Activity)
  RETURN collect(DISTINCT {assertedBy: who.uid, role: ev.role, locator: loc.uid, exact: loc.exact,
                           contentHash: snap.contentHash, retrievedAt: snap.retrievedAt, uri: src.canonicalUri,
                           verdict: adj.verdict, missionId: act.missionId, runId: act.runId}) AS trace
}
RETURN e.uid AS edition, he.validFrom AS editionFrom, he.validTo AS editionTo, aa.uid AS authorshipAssertion,
       author.name AS author, org.name AS counterparty, interestType, interestKind, polarity, validFrom, validTo,
       observedAt, assertionUid, meansOwnedOrSoldByCounterparty, trace
```

## Temporal notes

- bitemporal episode needed on: HAS_EDITION (AssertedEdgeProperties) and the D7 interest edges (Role/Stake/ValueEdgeProperties).

## Evidence and provenance notes

- trace: TRACE of the interest's authorizing Assertion gives the disclosure locator on the protocol snapshot. TRACE(aa) is the authorship span, e.g. the fixture `D5/pregnancy-magnesium-upper-limit` m02 locators `l02-signature`, `l01-protocol-title`, and it is reached the same way from `aa.uid`. Overlap is computed, and unknown bounds are returned as null (UNKNOWN). Denied interests come back with polarity NEGATIVE and no interval.
